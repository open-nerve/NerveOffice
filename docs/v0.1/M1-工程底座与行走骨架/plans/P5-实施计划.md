- [x] 1. `.dockerignore`：排除 `node_modules`、各 `dist`、`.git`、`.claude/`、`refer/`、`spikes/`、测试输出、`.env*`。
- [x] 2. `deploy/Dockerfile`：`base`、`manifests`、`build`、`prod-deps`、`runtime` 五个阶段；非 root、exec 形式的命令、Node 的健康检查、OCI 标签。pnpm 的全局安装要执行它自己的安装脚本（放好原生二进制；否则开了 shellEmulator 的脚本里启动 pnpm 得到 Exec format error）。
- [x] 3. 服务端许可清单：`tools/src/deploy/server-licenses.ts` 与单元测试；镜像构建时生成；缺正文的 5 个包补进 `apps/api/third-party-licenses/`；`licenses` 门禁提前核对。
- [x] 4. `pins` 门禁：Dockerfile 的 Node 标签等于 `.node-version`、pnpm 版本等于 `packageManager`、镜像带摘要、同一个镜像各处一样；单元测试。
- [x] 5. 本机构建（linux/arm64）；容器连开发库迁移、启动、就绪；只读根文件系统、去掉全部 capabilities、`init` 下正常，SIGTERM 优雅退出（退出码 0）；体积在 S4 的编排脚本里记录。
