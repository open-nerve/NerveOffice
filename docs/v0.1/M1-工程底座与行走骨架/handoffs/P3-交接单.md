## 与设计的偏差

都已回写到 P3 设计、ADR 或架构总览。

- **控制器取当前用户**：设计写的是 `@CurrentUser()`，实现为 `@CurrentPrincipal()`（用户、会话标识与派生的 CSRF 令牌），另有 `@SessionCookieJar()`（会话 Cookie 的读取、写入、清除），控制器不接触请求与响应对象。
- **`/api` 以外的 404**：Nest 的"找不到路由"只挂在全局前缀 `/api` 下，托管也没处理的请求会得到 Express 的 HTML 页面；管线里加了 `notFoundOutsideApi()`，统一成错误响应。
- **`AppError` 可以带响应头**：429 的 `Retry-After`。
- **TransactionRunner**（P2 的代码）：pg 在 ReadyForQuery 更新事务状态之前就回调了出错的语句，按状态判断"事务已中止"有竞争；改为提交前执行一次 `SELECT 1` 探测。
- **表定义的公共写法**：`db/schema/common` 的 `stringLiteral`、`oneOf`、`lengthBetween` 与 `bytea` 类型。
- **zod 与 CSP**：设计原来只提到 JIT 探测；实际有探测与编译器两段，jitless 必须由入口的第一个导入设置（审查 B1、B3，ADR-008）。
- **登录限流**（审查 A1、A2）：由"先查锁定、验证、记失败"改为"先占用名额、再验证"；清理移到事务之外。迁移 `0005` 放宽计数的 CHECK。
- **会话结束**（审查 B7）：由"单页里清空缓存、切换路由"改为整页转到登录页；另加多标签页的处理（审查 B6）。
- **契约的响应结构改为宽松**（审查 B18）：客户端丢弃不认识的字段；服务端只发契约里的字段，集成测试按原文核对（`parseExact`）。
- **新错误码 `USERNAME_TAKEN`**（409）：初始化管理员时用户名已被普通账户占用；M2 创建账户时沿用。
- **新配置 `NERVE_PASSWORD_HASH_CONCURRENCY`**（审查 A5）与 Argon2 参数的强度下限（审查 A12）。
- ADR 的编号：ADR-007（会话、CSRF 与登录限流）在 S2 实现后确定，与 ADR-008 一起在 S4 写入。

## 下一个 Phase 须知

**新增一个需要登录的接口**：
1. 默认就需要登录（全局的会话守卫）。确实不需要登录的，标 `@Public()`，并在审查时说明原因。
2. 状态变更的接口自动检查 Origin 与 `X-CSRF-Token`，前端的请求层会带上令牌。
3. 控制器用 `@CurrentPrincipal()` 取当前用户；需要客户端地址等审计来源时用 `@RequestOrigin()`。
4. 文档类的接口经 `DocumentAccessPolicy` 判断权限：没有权限与不存在返回同一个 `NOT_FOUND`，两条路径做同样的查询（参考 `DocumentsService.get`）。
5. 响应的结构放在 contracts，写成宽松的 `z.object`（请求写 `z.strictObject`）；集成测试用 `parseExact` 解析响应。

**新增一个前端页面**：
1. 放在对应的功能模块（`features/*`），对外只经 `index.ts`；路由加进 `app/routes.ts`，放在需要登录的外层（`RequireSession`）之下；界面文字加进 `shared/i18n/zh-cn.ts`。
2. 服务端数据经请求层与 TanStack Query 取得；每个数据视图处理加载中、空、失败、无权限四种状态；骨架屏各有自己的名称（E2E 按名称区分）。
3. 进行中的按钮用 `aria-disabled`，不用 `disabled`（焦点会丢到 body）。
4. E2E 的用例从 `tests/e2e/support/fixtures.ts` 引用 `test` 与 `expect`：每个用例结束时断言页面没有 CSP 违规。

**给 P4 的备注**：
- **编辑器入口**：
  - 入口 `entries/editor/main.tsx` 只写副作用导入，第一个导入 `shared/lib/zod-jitless.ts`（lint 规则 `nerve/web-app-entries` 强制）；
  - 用到 zod 的 Worker 同样先关掉 JIT；
  - 两个入口共用 contracts 时，打包器可能调整模块的执行顺序：P4 加入口后，用 E2E 的违规收集确认两个页面都没有违规，再决定是否开启 `strictExecutionOrder`（实验数据见 ADR-008：开启多约 3.5 KiB）；
  - 在门禁 `budgets` 里加上编辑器入口的预算。
- **托管**：`web-hosting.ts` 的 `ENTRY_PAGES` 里把编辑器的路径映射到编辑器页（本 Phase 为空）。
- **产物扫描**：Univer 的产物进来之后，门禁 `artifacts` 的语法树扫描会看到更多写法（任何对象上名为 eval、Function 的属性、恰好是这两个名字的字符串都算引用）：报出来的逐个核对来源，确认不执行动态代码的登记为已知项并写明原因；地址识别的补全见 DEF-016。
- **会话结束**：编辑器页是独立入口，会话结束（401、退出）时同样整页转到登录页，并带上原地址；多标签页的消息沿用 `shared/lib/session-channel.ts`。要向服务端确认会话时用 `requestSession()`（不改动请求层的 CSRF 令牌），确认是同一个人之后才换上新令牌（复验 S2）。
- **页面路由的最后一段不带点**：托管把带扩展名的路径当作文件（找不到时 404），不回退到入口页（设计 §3.8）。
- **E2E**：
  - 补上 US-M1-08 的编辑器部分与 US-M1-09 的编辑器部分；DEF-001 在 CI 的 Edge 上通过后关闭；
  - 测试数据的辅助（`tests/e2e/support/database.ts` 的 `createDocument`、集成测试的 `support/documents.ts`）要随 P4 给 `documents` 加的列（修订号、`unitId`、插件档案、内容表）一起更新。
- **文档接口**：新建与读取沿用 `DocumentAccessPolicy`；新建文档与审计放在同一个事务里（P2 交接单）。

**给 P5 的备注**：
- `NERVE_PUBLIC_ORIGIN` 必须是 HTTPS 的公开地址（配置只允许本机调试用 HTTP）；会话 Cookie 随之变成 `__Host-nerve_session` 并带 `Secure`。
- `NERVE_TRUST_PROXY` 按反向代理配置（DEF-014）：配错时所有人按代理的地址计数，50 次失败就锁住所有人。部署后用两个不同的客户端地址验证；可以考虑在公开地址是 HTTPS、请求却不是 HTTPS 时记一条告警（说明代理没被信任）。
- 反向代理对 `POST /api/auth/login` 再加一层按地址的速率限制：服务端的限流挡的是猜密码，挡不住单纯的请求洪水，哈希的排队会越来越长（DEF-015）。
- Argon2id 的参数按部署机器的基准测试确认（配置校验要求内存 × 迭代次数不低于 35840）；调大 `UV_THREADPOOL_SIZE` 时，`NERVE_PASSWORD_HASH_CONCURRENCY` 一并调大，不超过一半（配置校验会检查；`UV_THREADPOOL_SIZE` 不是 1–1024 的整数时启动失败）。
- 镜像里设置 `NERVE_WEB_ROOT` 指向前端的**生产构建**（`apps/web/dist`），不是带 CSP 探针的测试构建（`dist-e2e`）。
- 初始化管理员在容器里用一次性任务执行：`node dist/cli/init-admin.js --username <用户名> --password-stdin`，密码从管道传入；标准输入是终端时 `--password-stdin` 会被拒绝，改为按提示输入。
- 对容器化部署跑 E2E（`E2E_BASE_URL`）：Origin 已取它的源，测试库的地址与管理员账户还要另行提供（测试数据直接写库），P5 恢复这个模式时处理。

**已知的坑**：
- **入口的导入顺序**：antfu 的导入排序规则把副作用导入排在普通导入之后，提交钩子的 `eslint --fix` 会把"第一个导入"悄悄挪下去；所以入口只写副作用导入，代码放进 `mount.tsx`。
- **浏览器不把 CSP 违规写进控制台**：被 try/catch 接住的 `new Function` 探测，三个浏览器都不写。只看控制台的检查会漏掉，要监听 `securitypolicyviolation`（E2E 夹具已经这样做）。Worker 里的违规夹具收不到，靠阳性对照与产物扫描。
- **macOS 的监听队列只有 128**：集成测试或探针里同时打开超过约 128 个连接时，多出的连接会被重置（`ECONNRESET`）。并发测试要控制同时打开的连接数。
- **zsh**：变量里的空格不会自动分词，`"$B:path"` 里的 `:a` 等会被当成修饰符（写成 `"${B}:path"`）；循环文件列表时用 bash 脚本。
- **E2E 的端口**：每次运行由操作系统分配；单独启动服务脚本时要自己设 `E2E_PORT` 与 `E2E_DATABASE_URL`。后端日志在 `tests/e2e/test-results/e2e-server.log`。
- **登录限流的计数**：`failures` 包括正在验证的尝试，成功时退回，所以可以是 0；手工清理时直接删行即可。
- **`UV_THREADPOOL_SIZE`**：要么不设，要么是 2–1024 的整数，否则启动失败。libuv 把空值、非数字与 0 当作 1 个线程，编排文件里 `UV_THREADPOOL_SIZE=` 这种写法不要出现。
- **测试模块的引用**：测试与测试辅助只能被测试静态引用；确需在 `vi.mock` 的工厂里动态导入测试辅助时，写带理由的 `eslint-disable-next-line`，经审查。
