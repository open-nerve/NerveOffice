# v0.1 延期事项登记

> 文档编号：02｜所属版本：v0.1

这里登记所有被推迟处理的需求与问题，是延期事项的**唯一来源**。各 Phase 交接单中提到的延期项，都必须先登记在这里；每个 M 结束时复核一次。

**规则**

- 只能延期功能，不能延期质量门槛。
- 触及 00 号计划书的范围或上线门槛（A01–A20）的延期，必须走范围变更，并更新 00 号计划书的修订记录。
- "目标"一栏只能填两类：v0.1 中的某个 M，或者 v0.2。
- 状态分为：待处理、已排期、已完成、已取消（需写明原因）。
