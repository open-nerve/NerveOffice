## Review Focus

- API 批量事实、权限快照和会话失效原因必须来自同一真实来源；旧回包、同人重登、换人及主动取消不能借新许可删除。
- IDB v2 会话资格、原件观察、镜像比对、条件删除、墓碑与 Worker 资格需形成完整栅栏；存储失败、未知/较新格式、迟到写入不可被当作 absent/cleared。
- 草稿页的预览和动作、启动维护、当前编辑页及前台草稿页的所有权不能重复接手、清理或上传；异步结果不得把旧账户标题/正文带到新账户。
- 明确退出与确证停用才删除；普通过期/重置保留。服务端退出与本机清理结果分开，原操作失效后不得借新 CSRF 或代次重试。
- 保留期同时覆盖主库、独有镜像、墓碑和提示；读取不确定保留，时间异常不误删。
- SDK 存储在实际 UI 注入点按实例替换；旧库 blocked 与私有 sessionStorage 边界如实说明；用户记号的匹配及 Storage 枚举删除不能漏删或扩大范围。
- 计划覆盖不等于真实质量：核对测试前提、反向分支、实际公开用户链路、恢复/崩溃回归、原预算和文档事实。逐条列出考虑后未评价的行为及理由。
