# P3-S4 自动重载与标签页接手：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans，由当前实现者在唯一 P3 worktree 逐任务执行；沿用既有独立审查者，不拆 Task 分支。

**Goal:** 原标签页在充分证明后自动恢复本机修改，同浏览器交接在固定 20 秒总时限后由服务端裁决并接上实际正文。

**Architecture:** 非敏感记号与严格实例锁负责身份；独立 Reader 只预检原件归属；自动约束交给 S3 的统一恢复准备再次核对。实际持久写入通知记号，页面负责主动退出/换人与重载生命周期；交接沿原状态机修正截止时刻。

**Tech Stack:** TypeScript、现有 Web Locks/sessionStorage、Vitest、Playwright 三浏览器；不加依赖或后端接口。

**Spec:** `../specs/P3-S4-自动重载与标签页接手.md`，基线 `a77cb6f6`。

## 全局约束

- 唯一分支 `codex/m4-p3-recovery`，主目录 main 不动。整个 Phase 验收后 no-ff 合并，仅推 main；Step 内不另开分支或 worktree。
- PG 53522，不设置 CI；检查运行期间不编辑源码/测试/文档或提交，浏览器独立于其他检查运行。真实 Safari 留 S5。
- 原平台 180 KiB/2 文件、发件箱 Worker 15 KiB 预算不提高；S3 Worker 已为 15,332 字节，本 Step 无需改 Worker 协议。
- 20,000 ms 总交接时限从第一次请求算，3,000 ms 无回应早退保留；公式等待继续为 10,000 ms。
- 每个 Task 红灯→实现→定向复验；S4 全部完成后中文详细提交一次，保留全部首轮失败和最终证据。

## 审查重点

1. 复制页第一次 navigate 后再 reload：继承记号必须已经失效，不能等待原页关闭后冒充。归 Task 2/5。
2. 候选锁已申请、原件检查尚在等待时退出登录或新操作：迟到结果释放句柄，不重新记身份或自动申请。归 Task 2/4。
3. 预检后记录被替换，或旧回执已确认、清理后为空：自动尝试只能回阅读，不退成普通云端编辑。归 Task 3/4/5。
4. 持久来源在换钥/重登记后写入失败：不能把新 writer 记成旧原件的作者，也不丢失仍有效的旧持久记录归属。归 Task 4。
5. busy 接近截止后 ack、重复 ack 或下一次请求无回应：总时限不增加，取消与旧回包单次收尾。归 Task 1/5。
