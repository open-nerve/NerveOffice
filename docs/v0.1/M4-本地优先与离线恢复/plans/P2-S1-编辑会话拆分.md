# P2-S1 编辑会话拆分：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans 在当前会话逐任务实施；步骤用复选框追踪。

**Goal:** 将编辑会话资源和副本处理从 `edit-mode.ts` 拆出，保持 M3 的全部可见行为与 E2E 不变。

**Architecture:** `edit-mode.ts` 继续管理页面转移、编辑器槽位、跨流程的作废标识和读取页面状态。`editing-session.ts` 持有租约、本机锁、保存协调与自动保存，并集中建立/释放；`lost-copy-flow.ts` 处理失效后的捕获和副本结果归类，页面仍负责按结果重建。

**Tech Stack:** TypeScript、Vitest 的可控时钟与假编辑器、Playwright；沿用现有模块，不新增依赖。

**Spec:** `../02-P2-本地优先保存.md` §2、§3.1、§4；M4 总设计 §6.2 的先拆再接要求。

## Global Constraints

- 主项目目录 HEAD 始终为 `main`；工作目录为 `.codex/worktress/codex/m4-p2-local-first/`，进行中的分支不推送。
- S1 不接入发件箱、不改变序号/保存文案、不改变 sameSession 判定或请求时限；这些在后续 Step 实现。
- 同一个容器里至多一个编辑器；先建保存协调与调度，再撤掉交互屏障。
- 失去编辑权时立即停自动保存，在途保存仍由协调器收尾；不能因为销毁调度而抹掉未知结果。
- 退出/交接/释放行为与现有 5 秒、20 秒等待边界不变；锁争用仍以服务端核对为准。
- M3 E2E 文件原样保留；中文提交，不跳过门禁。

## Review Focus

- 旧锁核对晚于新会话建立：不得放弃新租约或抢回已释放的锁（任务 1）。
- 停捕获后仍有上传在途：未知结果和重放仍能完成，只有真正销毁保存协调时才释放其订阅（任务 1）。
- 编辑器已经创建、保存调度还未建立时得到不兼容/失效：屏障与 pendingBlock/pendingLoss 处理顺序不变（任务 1、3 的既有回归）。
- 副本保存成功后页面重建失败：保留已经创建的文档链接，不把成功改成保存失败；读不到原文档时同样保留成功事实（任务 2、3）。
- 单元格提交不了或捕获抛错：不能凭空声称快照包含最后输入，不销毁用户仍可复制的内容（任务 2）。

**Interfaces:**
- 消费既有 `EditLease`、`LocalLock`、`SaveCoordinator`、`Autosave`、`SameBrowser`、`LeaseClock`，不修改它们的协议。
- 产出 `createEditingSession(options: EditingSessionOptions): EditingSession`。
- 只读资源：`lease: EditLease | undefined`、`coordinator: SaveCoordinator | undefined`、`autosave: Autosave | undefined`；`baseRevision(): number` 读协调器的当前基准，否则读进入编辑时的基准。
- `acquire(intent?: AcquireIntent): Promise<LeaseAcquisition>` 沿用现有租约工厂与回调；`acceptLease(held: EditLease, revision: number): void` 在批准后登记资源；`setBaseRevision(revision: number): void` 更新进入编辑时取到的内容基准。
- `claim(held: EditLease): Promise<LockClaim>`、`holdsLock(): boolean`、`lossWithLocalEvidence(loss: LeaseLoss): LeaseLoss`、`locateTakeover(loss: LeaseLoss, waitMs: number): Promise<boolean>` 集中现有锁行为。
- `startSaving(editor: AutosaveEditor & SaveEditor, initial: { revision: number; snapshotBytes: number; formulasPending: boolean; blocked: Incompatibility | undefined }): void` 建保存协调→订阅→调度→订阅→观察者 attach；页面随后才 `slot.attach`。
- `stopCapturing(): void` 只销毁调度；`stopSaving(): void` 先停调度再销毁协调器；`detachLease(): void` 只忘记已经结束的租约，不误发释放；`releaseLease(): void` 尽力释放并放本机锁；`releaseLock(): void` 只放锁；`dispose(): void` 完整释放，重复调用无害。
- `EditingSessionOptions` 明确注入文档/页面标识、API 的租约/压缩/保存能力、时钟、本机锁能力、自动保存参数、会话失败钩子、错误上报和 `onLost/onIncompatible/onRequest/onChange`。页面视图和 `EditorSlot` 不传入。
