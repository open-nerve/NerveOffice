> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 S3 剩余页面、编排及实机证据，使真实暂停前的第三格已经本机持久保存，并覆盖请求保留期、十分钟后台取消与自然隐藏观察。

**Architecture:** 原生守护已通过 18 项自有进程校准。页面仍走既有编辑、自动保存、失权和另存副本流程；只在测试构建提取只读持久证据、恢复正常捕获节奏和记录状态。宿主用单独同源控制端点协调阶段，以数据库与 HTTP 时间线独立判定，控制消息不能直接选择 PID 或发信号。

**Tech Stack:** 既有 TypeScript/Vitest/Playwright、自检页面、Node HTTP 代理、真实 Safari 专用场景与 Swift 守护。

**Spec:** `specs/P6-S3-真实Safari暂停与请求恢复.md`。旧 `paused-holder` / `request-waiter` 和崩溃场景的语义、超时与报告保留。

## 实现前事实

- `holderPrelude` 的第三格写下时捕获期限仍为一小时，旧场景不能直接作为本机草稿恢复证据。
- `autosaveControl.resetLimits()` 恢复生产捕获节奏并通知调度，不会解除 timed upload 的 hold。新变体仅在第三格准备阶段调用它，不用 flush 把第三格上传。
- `createCrashWriteEvidence` 已按 Worker 实例和调用 ID 匹配回复，且能关联 OPFS 镜像；需增加对应具体 draft 身份的 IDB written 查询，不能以此前任意一次成功计数代替第三格。
- `watchForSelftest` 的安装在 `page.load()` 之前被 await。可在这个测试边界安装 Worker 观察，再使用原有自动进入编辑和场景，不必改生产保存管线。
- 旧请求方预算 600 秒不足以覆盖真实十分钟后台等待加准备收尾；新取消变体有独立预算，旧场景不放宽。

## 全局约束

- 仍在唯一 P6 worktree；主目录 main 保持不动。没有租约 TTL 修改、系统时间修改、产品身份继承或新自动恢复机制。
- 控制端只记录本轮测试身份、时刻、摘要与状态；不保存密钥、令牌、测试密码或用户页面内容。
- 在 STOP 前完成双重完整页面映射与原生检查；STOP 之后不再用 Apple Events 查询页面归属。独立守护先 ready，异常先恢复，再收尾。
- 第三格须以匹配的 Worker written 回包、IDB 原件及独立 AES-GCM 解密三者证明；云端仍仅前两格。先前保存、旧 seq 或错 writer 不可冒充本轮完成。
- 真实 Safari 期间解锁、开始前空闲 120 秒；活动、锁屏、监测或连续性失败使本轮作废，原件保留。
- Playwright 里的心跳拦截/虚拟时钟仅用于校准；实机分别真等 90 秒租约、两分钟保留期和十分钟后台取消。

## Task 5：自然隐藏观察与 S3 收尾

- 实施决定：复用已校准的 `paused-local-holder` 页面及旧 `runPausedHolder` 自然等候，不发 STOP、不拦心跳。自然观察只组合已有 boot/local-ready 严格校验，另行接收 `handed-over` / `lost-after-pause` 结果，不能调用或伪造原生暂停状态。每种窗口条件最多先观察 150 秒心跳，再走既有协作者请求链；未自行暂停就记录未复现。页面可能在后台交出后完成报告，隐藏时长同时保留页面截至报告时的下界与宿主恢复窗口时刻，不能编造返回可见事件。
