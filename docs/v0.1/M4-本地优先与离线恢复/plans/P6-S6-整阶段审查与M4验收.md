## 审查重点

1. 旧写入者、原件变动、迟到 ACK/清理遇上新草稿：保留后来内容，恢复前不自动申请或保存，恢复后只产生正确修订。
2. 测试驱动异常退出、PID 复用或窗口归属改变：只操作本次资源，暂停进程仍有独立恢复保障，失败不能记通过。
3. 网络切断与长轮次心跳先失败、在途请求：证据必须证明本轮应用失败且切断后无上游保存，控制通道失败不能充当离线。
4. 默认与生产目录、平台跳过、源码/构建或 CI SHA 不一致：禁止汇总成一次通过；缺项、重试和旧报告都能被验收审计拒绝。
5. 把 VM strict 零丢失、persist/API 存在、受控 SIGSTOP 误写成物理断电/永久保存/自主挂起保证：按原件与政策逐条核对，不扩大结论。
