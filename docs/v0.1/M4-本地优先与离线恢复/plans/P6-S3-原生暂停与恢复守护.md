# P6-S3 原生暂停与恢复守护：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为已被独立认定的专用 Safari 页面提供先就绪、后暂停、脱离 Node 仍能有界恢复的原生守护者。

**Architecture:** 保留 P3 的完整页面归属判断；Swift 守护者在新鲜内核/签名/桌面检查后发出一次 SIGSTOP，用独立的单调时钟与输入管道监测决定恢复。暂停期间不依赖 Apple Events、Node 或外部命令；恢复后才完成可能阻塞的日志落盘。单独的校准入口只能控制自己创建的空 sleep 子进程。

**Tech Stack:** 既有 Node 24 / TypeScript / Vitest；本机 Swift、Darwin、IOKit、Security 与已有 LaunchServices 身份接口。

**Spec:** `docs/v0.1/M4-本地优先与离线恢复/specs/P6-S3-真实Safari暂停与请求恢复.md` §2、§5。本计划只交付原生保障；页面准备、请求变体与真实 Safari 验收仍需后续 S3 计划，不因此关闭 DEF-069。

## Global Constraints

- 唯一 P6 worktree，主目录 main 不动；原生校准不使用真实 Safari、不接收外部 PID。
- 真实目标必须是既有专用场景的唯一 WebContent；临发完整映射不超过 2000 ms，桌面解锁且空闲至少 120 秒。
- 已经停止、退出、出生身份/UID/路径/父进程变化的目标拒绝；不得恢复他方先前暂停的进程。
- 守护者必须先 ready，才接受一次 stop；启动后等待控制最多 10000 ms，每次实际暂停最多 180000 ms，并受本轮绝对截止时间约束。
- 用户活动、锁屏、EOF、主驱动退出、SIGTERM/SIGINT/SIGHUP、期限或监测失败均恢复；未知/过大的控制输入同样恢复并记失败。
- 只对本次成功 SIGSTOP、内核出生身份仍相同且仍停止的目标发一次 SIGCONT。目标已退出/被外部恢复则记录事实，不能伪报本次正常恢复。
- 忽略 SIGPIPE；输出管道用非阻塞写，关闭或拥塞也先恢复。暂停期间不做 fsync 或等待子命令，恢复后写独立 JSONL 原件。
- 守护者自身 SIGKILL、宿主断电/内核失去调度不在保障内；不声称原生暂停等于 WebKit 自主挂起。

## Review Focus

- Node 被强制终止且 stdout 同时关闭：Task 3 必须用真实内核校准证明 EOF 仍恢复，写结果失败不得先杀死守护者。
- 目标在检查后退出或已被别人停止：Task 1/2 拒绝旧身份和初始 SSTOP；Task 3 核对未发送多余 CONT。
- 桌面读取失败或读到多会话：Task 2 只接受当前 UID 的唯一控制台会话；UID、onConsole、idle 缺失/歧义即拒绝或恢复。锁屏字段缺省在本机解锁状态下是正常表示，依据成对只读探针处理；字段存在但类型错误仍拒绝。
- 单调时间与墙上时间跳变：Task 1/2 固定期限，墙钟倒退或明显偏移令实验作废并恢复，不延长暂停。
- 日志、管道或清理抛错：Task 2/3 先处理已暂停目标，再写失败；没有 final receipt 不能判通过。
