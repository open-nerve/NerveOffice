# P5-S5 真实浏览器与性能复核：实施计划

> 状态：已完成｜日期：2026-10-17｜所属：M4-P5
> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `superpowers:executing-plans`，在当前唯一 Phase 工作区逐任务实施。

**Goal:** 用真实 Worker 故障和服务端正文验收公式退路，复核主线程销毁顺序，并以原始测量决定 Worker 让出间隔与 DEF-072 候选。

**Architecture:** 浏览器通过阻断实际脚本或在实际 Worker 内抛错触发故障，不替换页面的创建工厂。生产故事只观察页面、请求及服务端正文；探针故事单独标记。性能候选串行构建和测量，冷热对照不用路由拦截，保留真实 HTTP 缓存。

**Tech Stack:** 现有 Playwright、Univer、生产容器、TypeScript；零新依赖。

**Spec:** `../05-P5-公式Worker的退路.md` §3.4–§3.6、§4；M4 总设计 §6.8、US-M4-13；DEF-072。

## Global Constraints

- 基线 `57a674b5`；唯一 `codex/m4-p5-formula-fallback`，根目录保持干净 main。
- 不增加生产故障开关、URL 模式参数、SDK 补丁、第二份正文来源或租约申请。
- 保留原 20 秒握手、30 秒停止上限、浏览器矩阵、CSP/页面错误检查、产物预算；不增加跳过、重试、超时。
- 生产故事同时适用于 held、running 自动保存和生产容器；测试探针只在 `@test-build`。
- 真实故障必须证明实际 Worker 路径命中；terminate 本身不代表浏览器报告故障。
- 性能工作不与其他检查并行；每个源码候选先备份、记录源与产物散列，测后还原；禁止用路由替换脚本测缓存。
- Step 内不拆分支、不逐 Task 提交；全部验证后正常 hooks 中文提交一次。整 Phase 的独立审查和完整门禁在 S6。

## Review Focus

- 故障未真正触发而测试绿色：Task 1 断言脚本命中/实际 Worker、有限诊断与旧 Worker 消失；通过关闭退路的实际变异证明故事会失败。
- 恢复只保留已提交单元格：Task 1 在离线且当前单元格未提交时触发运行期故障，以重新联网后的服务端正文验收。
- 组字被屏障截断或面板防抖未完成：Task 2 在批注组字中触发故障，等待态不销毁，选定后保存中文；WebKit 合成输入的限制如实登记。
- 主线程自检失败被保存或重试丢原稿：Task 2 临时使用既有测试档案缺项，断言无不完整上传、清除后重试保留原内容。
- 性能改善来自缓存失效或未实际停止：Task 3 校验 cold/warm 缓存状态及真实 start/progress/stop/end 顺序，拒收前提不成立的样本。
