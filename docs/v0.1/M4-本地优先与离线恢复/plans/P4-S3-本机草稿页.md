# P4-S3 本机草稿页实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans 在唯一 P4 worktree 内联执行；沿用用户自主推进授权，Step 完整验证后一次中文提交。

**Goal:** 当前用户可找到并逐条处理本机草稿，存储和列表提示反映真实事实。

**Architecture:** 按需草稿页 + 共享目录/串行协调 + 现有 DocumentRecovery；固定 S2 会话许可和完整原件，所有编辑授权继续留在编辑器。

**Tech Stack:** TypeScript、React、TanStack Query、IndexedDB/OPFS、Vitest、Playwright；不新增依赖。

**Spec:** `../specs/P4-S3-本机草稿页.md`

## Global Constraints

- 主目录保持 main；唯一 Phase 分支 codex/m4-p4-drafts-cleanup；Step 全绿后一次中文提交，不推开发分支。
- 无 SDK 进入平台；180 KiB/2 首屏文件、2350 KiB 编辑器首屏、800 KiB 公式 Worker、15 KiB 草稿 Worker 原预算。
- 真实会话许可、只处理当前用户、完整原件条件删除；未知身份/网络/读取/较新格式保留；无恢复授权 URL。
- 三浏览器验证串行、workers=1、期间不改源码；只用隔离测试库 53522。
- 单元先 RED 再 GREEN；每 Task 使用 task-start/task-done 留证；独立整 Phase 审查仍在 S6。

## Review Focus

- 批量响应合法但少/多一条、服务端无权事实排队变旧：Task 1/2 校验集合并对 unavailable 重新核对。
- 只有未清镜像或主库读取失败：Task 1/3 仍有待处理说明，绝不空状态。
- 确认后同 seq 新原件、未知副本期间别页更新：Task 2/5 用完整观察及同 requestId 实证。
- 同用户换会话许可、不同用户切换后旧异步完成：Task 2/4 验证迟到结果不入新视图。
- 长列表删除焦点、未知副本内部导航、320px：Task 3/5 真实键盘/路由/视口检查。
