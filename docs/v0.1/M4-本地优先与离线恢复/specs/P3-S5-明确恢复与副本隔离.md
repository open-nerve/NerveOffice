# P3-S5 明确恢复与副本隔离

基线 ea87b761；2026-10-12 用户明确批准“接受方案 1，继续实施”。承接计划书 r23，沿唯一 P3 worktree，原实验和失败结论保留。

## 目标与边界

保持纯网页部署；无法证明原页身份时，重载页与副本都保持阅读，自动发现并提示本机修改，用户明确恢复/接手后找回最后持久正文。当前没有符合要求的原页前驱提供方，因此所有新 Document 都使用新的 clientInstanceId，不开启任何浏览器白名单。既有新建文档明确 editIntent 与活页的租约续期保持职责。副本零申请结论限定为没有新建 editIntent 的恢复与请求继承入口；可复制的 `?edit=new` 属于新建流程既有例外，不宣称已隔离该入口。

退出/换人、权限、认证原件、服务器修订、格式、公式、冲突、镜像和条件清理仍按 S1–S3。本人接管的 20 秒上限及服务端先裁决、本机文档锁后取得保持不变；不复用旧实例申请、不自动 takeover。旧版 reload sessionStorage 命名空间在应用装配时同步清除，存储异常不阻断阅读，另将 M3 请求编辑归属改为当前 Document 内存，仅迁移清理该文档旧 edit-request 记号；不动 pending-save、持久原件或镜像。刷新/复制后的页面不自动续期、撤回或接手之前的请求，重新点击既有“请求编辑”或“编辑”即可继续；当前活页已明确发出的请求仍正常等待、续期和获批进入。

## 实现取舍

移除已无合法提供方的自动身份继承链及其专用短期预检、页面实例锁、持久写入记号回调和自动恢复参数，避免用默认 false 开关保留不可达分支。保留服务端租约、本机文档锁、认证读取和 S3 原件竞争保护。页面使用原有 newId 初始化的 clientInstanceId，Mode 不再接收 reload 候选；旧记号仅保留迁移清理函数。

测试构建的只读诊断改为记录导航和清理前/后的旧记号，不包装已删除的资格/实例锁方法，也不生成替代身份。诊断仍不参与产品资格、不含正文/令牌/密钥，生产产物排除不变。

## 产品验收

- 真实刷新、navigate、back_forward、wasDiscarded 输入及延迟 opener/原生 Duplicate 首次脚本前重载：确认前阅读、无编辑权申请；旧记号清掉，原件保持，原页仍活着时不影响它。
- 明确恢复后用新实例进入，权限/租约正常裁决；有旧租约时使用既有“在此编辑”，未被占用时使用“恢复并编辑”；一次明确操作后不需再输入正文即可正确同步。
- 原页正常关闭和先崩溃、部署关闭本机写入、换钥、换人、退出、冲突、确认丢失、恢复期间原件竞争都继续有覆盖。浏览器真实继承用 opener 路径；原生 Duplicate 的协议捕获事实保留，不把复制 storage 的夹具称为原生 UI 复制。

## Safari 测试契约

实际结束已归属原页进程后，页面必须先报告稳定阅读、可见恢复/接手入口、持久正文仍与 ready 的独立摘要一致。驱动在允许模拟一次用户确认前，另以真实 HTTP/数据库核对 acquire/save 均为零、云端仍初始修订。页面不能自行授权跳到恢复。

只在此证据成立后，驱动发出独立确认命令；测试页点击当前真实产品入口一次，记录选择的入口和确认边界。后续必须用新 clientInstanceId，takeover 必须与入口吻合，最后持久正文和一次修订相符。报告明确标注 explicit-confirmation，不把测试点击写成自动恢复。协议拒绝提前/重复/错页确认、确认前申请、未知入口与在途请求；取消、错误、截止时限和诊断白名单仍失败关闭。

进程归属、双采集、原生单 PID 临发、空闲至少 120 秒、用户回来作废、claim 和自有资源清理保持原样。先三引擎普通刷新校准，再真实 Safari；真实确认前证据不足不得继续。当前测试脚本点击是受控模拟的明确操作，不要求用户在 120 秒空闲实验中亲自操作。

## 完成标准

单元、类型、lint、生产/测试构建、产物/预算、三浏览器产品回归与普通刷新校准、实际 Safari 和独立审查通过后，才能关闭 S5-F1/F2。S6 的 Phase 总门禁、容器、架构/ADR/交接和 no-ff main 不提前记完成。不降低数据完整性门槛、不删除此前失败证据。

### 恢复点击与原件竞争

恢复入口在等待会话确认、同浏览器交接或租约申请之前，固定已展示且经解密认证的原件来源（userId、documentId、writeEpoch、writerId、writtenBy）和会话代次。后续发现不能把旧点击改用于另一写入者；重新观察来源不同即停止本次恢复，在旧请求核对、清理或 SDK 安装之前保留新原件并回到阅读。会话暂停使旧点击失效。同一写入者在交接期间继续落盘的正文、序号及在途请求允许更新，恢复仍使用最终认证内容。已明确放弃且确认删除的当前原件不再约束下一次普通编辑，迟到的旧清理不能清除新候选的来源。
