# P3-S4 自动重载与标签页接手

> 2026-10-12 后续决策：用户已批准方案 1。本文保留原实现/实验的历史记录；自动继承相关设计与验收由 [S5 明确恢复规格](../specs/P3-S5-明确恢复与副本隔离.md) 和计划书 r23 取代。新规格本机验收已通过，见 [S5 最终验收](../reviews/P3-S5-审查报告.md)；以下旧设计、断点和失败证据作为历史保留，S6 整体验收尚未完成。

基线：`a77cb6f6`。遵循 M4 总设计 §6.3/6.4 与 P3 Phase 设计 §3.6，在唯一 P3 分支自主实施。S3 已完成，S5/S6 仍保留各自验收职责。

## 1. 意图与范围

同一标签页意外重载后，在能证明原页已结束、草稿归属匹配且服务端允许时，自动接上本机未同步修改。复制标签页、普通导航、换人、原页仍活着或事实不足时保持阅读与手动操作。本人在同一浏览器接管时，交接最多等 20 秒，随后由服务端裁决、取得本机锁并经 S3 接上原件。

不保存租约令牌、密钥、正文或观察凭证；不增加后端接口、依赖或第二套恢复流程。M3 的 pending-save/edit-request 记号继续履行原职责。默认完整门禁、生产容器和同 SHA CI 属于 S6，真实 Safari 崩溃事实属于 S5。

## 2. 最新代码事实与方案选择

- `EditorPage` 当前在创建时生成一次 clientInstanceId；确认 session 后创建恢复协调器，Mode 随后固定该身份。恢复身份必须在 Mode 创建前确定；早期 403/404 的独立清理仍需保留。
- S3 的 prepare 已核对最新租约/source、原件和公式/打开屏障；自动恢复只增加资格约束，正文仍走该入口。
- `SameBrowser` 的文档锁允许 steal，能力不足时可退化为未跟踪句柄。该退化不能证明原实例死亡，自动重载须用独立、严格失败关闭的实例锁。
- 持久来源已掌握每次实际写成的 writer 身份；在该边界通知页面记号即可，公共视图不暴露正文或内部凭证，也不改 Worker 协议。
- `askTabToHandOver` 当前 ack 重启 20 秒计时，busy 后再 ask 也可延长等待。固定从第一次请求起的总截止时刻；3 秒无回应的既有早退保留。

选择“非敏感记号 + 严格实例锁 + 认证原件匹配 + 原身份普通申请”。只看 sessionStorage 会把复制页当原页；用新身份自动 takeover:self 会抢走活页。独立 Reader 做短期归属检查并释放，实际采用时重新观察核对，避免把预检凭证长期传到页面。

## 3. 记号与存活证明

记号按 userId/documentId 隔离，带版本 1、clientInstanceId、writeEpoch 和 writerId。标识使用现有 UUID 约束，键与实例锁按规范小写一致比较（URL 接受大写 UUID），代次为正安全整数；未知版本、额外字段、损坏数据和存储异常均不能授予资格。值中不包含时间推测的租约有效期。

导航事实只接受浏览器明确报告的 reload，或 document.wasDiscarded 为 true。普通 navigate/back_forward/未知类型在页面组装时同步清除本标签页恢复命名空间的全部继承记号，不依赖会话或正文请求成功；因此复制页即使继承 sessionStorage，第一次打开也会使其后续刷新失去冒充路径。不同用户/文档的记号不能复用。真实 Safari 崩溃采用何种导航事实由 S5 实测，当前不放宽。

每个原实例有独立锁名，包含用户、文档及 clientInstanceId，与 nerve-doc 文档编辑锁分离。用 exclusive + ifAvailable 原子申请，从不 steal、从不排队等待。忙、API 不存在或拒绝时自动资格失败；不能使用 UNTRACKED 退路。成功后在页面生命周期内持有；迟到取得句柄但本轮已取消时立即释放。正常页面也为新身份取得实例锁，只有确实持有时才能写可用于下次恢复的记号。

先取得候选实例锁，再经独立 Reader 确认认证后的原件属于该 user/document/clientInstanceId/writeEpoch/writerId。必要时仅刷新一次过时密钥。不登记、不采用、不解压用于 SDK、不删除、不重放；读取失败不虚构不存在。原件格式或保留期已明确不合格时不自动申请。可能需要旧请求核对或租约 source 的候选，可进入后续普通申请，但不提前宣称可以恢复。

匹配失败或资格取消后，仅条件清除本轮观察到的旧身份，释放候选锁，使用新身份保持阅读；未取得任何身份的旧取消操作不按键清理。实际持久写成才更新清理的所有权，迟到清理不能删除同键后来写入的新身份。独立检查在 finally 关闭 Reader；实际恢复不使用它的旧 observation。

## 4. 普通申请与第二次核对

会话和文档已确认、联网、可编辑且当前页面支持该文档时才尝试自动恢复。确定原身份后，以原 clientInstanceId 发起普通 acquire，绝不附 takeover。原租约仍属于原页或已空闲才能成功；别的活页、另一会话或别人占用时由服务端拒绝，页面保持阅读。

自动尝试向统一恢复准备传入仅含身份的约束。本次登记之后重新观察，原件必须仍匹配该约束；只有 S1 的 fast-forward 或严格 own-revision 才安装。记录被替换、已空、存储未知、固定内存编辑退路、冲突或权限变化都不能变成自动编辑云端初值。部署关闭但原件可读且判定合法时，可沿 S3 的内存恢复保存；该路径仍不新建持久登记。

旧请求已确认时沿 S3 条件清理并重取最新云端，停在阅读，不为了完成自动流程又以空来源进入编辑。后续一次用户明确点击编辑不再受已经结束的自动尝试约束。取消/新操作使自动资格作废；SDK 打开、公式收齐、采用和保存调度沿 S3 原顺序，每个异步边界仍验证生命周期。

## 5. 记号生命周期

由实际持久捕获或采用成功通知已写成的 writer 身份，再更新记号；失败、纯内存来源和被取消的准备不产生可恢复记号。换钥/重新登记后只有新的实际持久写入才更新身份，避免把旧记录误配给新 writer。通知只传非敏感元数据，观察者抛错不能打断写入事实。

主动退出、明确放弃、正常交出、确定失去编辑权、撤权和切换账户时清除对应记号。暂时网络错误、仅隐藏和保存过程中状态变化不冒充主动退出。页面刷新/崩溃保留记号；pagehide 或资源销毁释放页面资源时不自动把它清成主动退出。取消一次退出后仍在编辑的，继续维持正确记号。

版本不兼容导致旧页停写、释放租约，不等同于原件归属失效。刷新后的新页面仍须完整核对原实例、当前权限、原件格式与修订；兼容原件可恢复，不能理解的原件保持原有保留路径。

会话确认失败立即停止自动尝试；确定换人/退出清理本页原身份记号并释放实例资格。迟到预检、锁回包或持久写入通知不得重建已清除的资格。详情权限仅采用最新请求轮次；自动选择因同用户确认取消后，只为后续明确进入补当前新实例锁，非自动补锁不因重复同用户确认失效。恢复提示继续沿 S3 文案及状态区，不新增技术身份 UI。

## 6. 20 秒交接与正文

第一次 handover-request 发出时固定截止时刻为 clock.now()+20,000 ms。ack、重复 ack、busy 重试及新的请求标识均不重置截止时刻；请求回应仍最多等 3,000 ms，且不能越过总截止。到期取消计时器、频道订阅和等锁请求；一次完成只产生一个结果，旧回包无效。

done、锁释放、failed、用户取消沿原语义结束等待；无回应仍可在 3 秒早退。到期后先向服务端申请并核对新代次，再处理本机锁；不把等待到期当作抢锁或写入许可。S3 已负责暂停旧来源、登记后重读、原子采用和旧写入栅栏。

浏览器证据必须制造旧页已持久但未上传的 A1：新页在固定截止前不申请，截止后取得新代次、实际恢复 A1，无额外输入也能上传；旧页迟到写入/确认不改新记录。新页另改 B1 后，服务器为 A1+B1，旧页副本不混入 B1。该链路与边界反例通过后才关闭 DEF-064。

## 7. 验证与交接

- 确定时钟测试：迟到 ack、重复 ack、busy→ack、busy→无回应、恰好截止、提前 done/释放/失败/取消，20 秒总预算不增加。
- 身份测试：记号损坏/异版本/额外字段、用户与文档隔离、存储拒绝、无锁/忙/拒绝/迟到锁、普通导航及复制后刷新；原件被替换、旧钥、来源取消均不能自动进入。
- 三浏览器真实页面：刷新/回收事实、原身份普通申请、无需额外输入的正文恢复、确认丢失、复制标签页与再次刷新、普通导航、原页存活、换人/重登录、记录竞争和 20 秒接手。核对请求身份、takeover 字段、草稿与云端正文/修订；不只断言提示。
- 全项目单元、类型/lint、生产构建与原预算；完整相关浏览器回归及独立审查。检查期间不编辑，浏览器独立运行，首次失败原件保留。Step 完成后一次中文提交，Phase 内不拆分支。
