## 3. 设计

### 3.1 验证边界与方案选择

保留已有单元、集成、普通浏览器、崩溃与容器套件，补三个缺口：真正暂停的 Safari 页面、客体 OS 突然停止、生产 HTTPS 下进程崩溃。宿主只保存测试证据、控制本次创建的资源；应用继续使用既有公开保存与恢复入口。

单独杀浏览器已经覆盖，不能回答客体 OS 页缓存中的数据是否丢失；重跑现有套件也不能代替这项。真实宿主断电会影响用户和证据，采用批准的专用 VM。浏览器 Worker 或定时器拦截不能证明 Safari 进程真的暂停，采用批准的精确页面 PID 暂停。

### 3.2 虚拟机断电实验

Linux 上运行官方 Chrome、Edge，macOS 上运行真正 Safari。镜像、浏览器版本、CPU 架构、客体文件系统、虚拟磁盘参数、工具版本与命令都进入报告。工具/镜像选择在 S2 根据实际可用版本和磁盘前提确定并锁定，不把未验证的 ARM 包或商业 CLI 当成已可用。

实验分两层：

1. 存储对照：专用来源连续写入序号、确定性正文与摘要，在同一事务完成事件后把 `runId / bootId / durability / seq / digest` 交给宿主。`strict` 与浏览器默认各 10 个独立突然停止轮次，按 strict/default 交替顺序，记录完成到停止的真实时间，不人为在停止前 sync 或退出浏览器。
2. 产品验证：正式 strict 发件箱 + OPFS 路径、真实加密草稿，在上报本机完成之后突然停止，原磁盘重开后经用户明确恢复入口核对正文和唯一修订，每个浏览器至少 3 轮。另有不停止的完整控制轮验证驱动本身能回读。

宿主收集器独立于 VM；只接收本次运行的有限结构、固定来源与一次性测试标识，不接收生产正文、密码或密钥。停止时冻结“宿主已经收到并落档”的最后完成序号，下次启动报告实际读回序号和摘要：序号更小、正文不符或读不出均为数据丢失；缺轮、错来源、重放和未确认的停止只能记未验证，不能记通过。后来的消息不能回填断电前证据。

只使用明确的立即停止/强制终止虚拟机进程，不用 ACPI 正常关机、保存状态或回滚快照。核对被停止的客体与本次登记相同，保留停止与重启记录。宿主保持运行，因而结论仅涉及客体 OS 突停，不覆盖宿主缓存、电源、硬盘缓存和物理损坏。`strict` 的实际支持值单独记，默认组不承诺失败；两组都保留全部轮次，不能以重试抹掉丢失。

### 3.3 Safari 暂停与恢复

复用 P3 已核实的专用 Safari 场景，新增暂停驱动与具有恢复保障的原生控制。SIGSTOP 前仍须满足已解锁、连续空闲 120 秒、来源/窗口/场景/进程唯一、UID/父进程/启动时间一致；未能唯一认定就停止本次实验并记原因。

暂停动作前先安排独立的有界恢复保障；SIGCONT 只能发给已由本次暂停、身份未变的那个进程。主驱动异常、超时或用户活动时也要恢复；不能把暂停后的 UI 无响应当成新归属证据。记录原生进程状态确实暂停、期间页面执行/心跳没有继续、服务端租约实际到期。恢复之后核对页面说明、旧保存被拒、云端内容和修订不受旧页覆盖，本机草稿仍按既有权限/副本规则处理。

DEF-069 的请求方背景变体、保留期、后台 10 分钟取消分别列证据；可控时钟的校准与真实暂停报告分开。无法复现 Safari 自行暂停时如实写出，人工 SIGSTOP 的结果不改写为 Safari 自主调度的结论。不得结束 Safari 主进程或用户其他页面。

### 3.4 Safari 本地保存与存储边界

复用测试构建的样本、自动保存日志与发件箱读回能力，增加真实 Safari 可运行的端到端场景。三样本（约 1 MiB、约 5 MiB、perf-50k）× 在线/离线 × 20 轮；逐轮记录最后输入、公式完成、同步捕获、Worker 完成、本机完成、云端结果与真实解密正文。在线组确认服务端字节，离线组确认没有上传成功；不能仅采 UI 文案。

沿用 P2 指标：符合公式条件的修改到本机完成 p95 ≤ 2000 ms；约 1 MiB 同步捕获 p95 ≤ 100 ms。保留公式条件外样本及完整分布，不用排除慢轮次改善数字。性能测量不与门禁、归档或 VM 并行。真实 Safari 运行前按项目规则等待空闲，用户活动使该轮作废并保留原件。

隐私浏览 OPFS 需在独立测试隐私窗口读写、关闭后再开核对，记录实际浏览器版本，不泛化为永久持久。7 个使用日与持久模式依官方 WebKit 文档及当前实现核对，区分“可能免于驱逐”与永久保留保证；文档核对不能标成真实等待七日的实验。

### 3.5 生产容器主链路

实际枚举显示 US-M4-01、03、05 等生产目录为零，先补不依赖测试构建的离线编辑、重连快进和真冲突副本：经公开 UI 编辑，真实断网后持久草稿存在，恢复联网逐字核对服务端正文；冲突时原件不动且副本正确。既有 M4 探针用例保留。

维持既有外部配置默认范围和资源归属规则，增加明确选择的生产崩溃项目，仅纳入不依赖 `@test-build` 的产品恢复故事。专用持久 Chromium 资料、真实 HTTPS 后端与数据库、真实结束整个所属浏览器树后重开；恢复前只读且零自动申请，恢复后逐字核对最后本机正文、公式与唯一修订。ACK 丢失以及冲突副本各有独立原件。

禁止把低层探针页塞进生产构建；其余存储级 crash 项目留在原矩阵。本机/CI 的容器命令都必须运行新增项目，不能只在一次手工命令运行。重启后端项目必须排在这些项目之后，避免彼此杀掉资源。
