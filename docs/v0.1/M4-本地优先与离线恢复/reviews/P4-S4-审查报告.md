# P4-S4 启动维护与退出清理审查报告

> 日期：2026-10-14｜审查：实现者按规格和计划逐项自审｜基线：1fb1effc｜状态：Step 验收通过

## 1. 范围与结论边界

S4 接入明确退出、确证账户停用、文档不可读/密钥吊销/损坏和保留期清理，平台和编辑器共用维护协调。普通认证失效保留草稿；明确退出先预览和确认，分别报告本机与服务端结果。清理期间的新登录使旧确认和旧重试失效。

本报告是 Step 自审。S5 仍负责 Univer 内存存储、旧库/键及 M3 记号，US-M4-08 的完整本机数据清单尚未完成；当前成功文字只称本机草稿。整 Phase 独立审查、默认完整门禁、生产容器、合并及同 SHA 六项 CI 属于 S6。无头 WebKit 通过不代替真实 Safari 验收。

## 2. 逐项核对

- 请求发出前固定原许可与 CSRF；普通请求的本机副作用不延长网络时限、不吞原错误、不重发网络请求。主动取消携带 ApiError 也不能冒充服务端停用。
- 初始会话查询只认网络前的原 ticket 和精确代次，错误不能借 `activatedFrom` 穿过新登录；停用账户必须匹配原来源，未知格式、未决变更和退役来源均拒绝。重复 preserve 不反复换代发广播，随后真正停用仍可清理。
- 退出同时比较原用户、来源摘要、原许可和清理 cause；`cleared` 只是原来源已完成的事实，不授予新的删除资格。清理 pending/失败仍尝试结束原服务端会话，不隐式换 CSRF；新登录后必须重新预览确认。
- 预览只读本人元数据，取标题前后都核对来源；读取不完整明确告知。确认后撤下账户与标题，只显示两侧结果。pending 数组为空仍不能当作全部完成；320px、键盘取消/确认与稳定焦点均覆盖。
- 启动维护串行合并事件，换人同步释放旧目录、密钥与标题，迟到结果发布前再次核对持久许可。当前编辑文档和前台草稿页拥有自身恢复操作，后台只处理其余文档；全局到期与持久 clearing 不跳过。
- 主库到期删除与 expired 提示处于同一严格事务；保留键保护对应镜像。非空镜像先解析槽位，较新格式、未知时间或读取失败保留；镜像独有记录删除后再条件记提示。没有取他人的密钥或正文，提示按用户隔离。
- 确证停用独立说明原因，编辑器另说明内存修改及关闭风险；提示不提供清理权限、不声称清理成功。平台仍复核现在的登录，编辑器仅接受匹配用户的原因，采纳新会话后清除旧说明。
- 新的目录和维护入口没有引入 seq-only 删除。广播只加速停止，冻结页保留旧密钥和摘要仍被持久栅栏拒绝；晚到捕获与 force 登记不能重建草稿。

## 3. 发现、修复与保留的原失败

1. 启动维护与前台恢复并行，曾重复取钥、核对回执并提前清理。真实浏览器的损坏/吊销/过期提示及原件断言捕获问题；新增所有权和路径反例先失败再通过，后台在发起文档操作前排除当前前台所有者。
2. 已暂停来源重复 preserve 继续换代并广播，普通过期的精确请求数由 3 次变成 14 次。两个单元反例捕获后修为幂等暂停，同时保留后续真正停用的 clearing 路径。
3. 规格复核发现停用虽已清理，界面仍称普通过期；Phase §3.3 明确要求说明停用。8 项单元先失败，修复后 540 项相关单元通过，浏览器覆盖三个入口和开着的离线编辑页。旧管理员故事按真实后续查询区别已确证与未知；另加清掉 Cookie 后实际查询返回 UNAUTHENTICATED 的对照，登录失败仍使用统一错误。
4. WebKit 普通过期夹具先进入平台，后台目录抢先得到清 Cookie 的 401，使随后会话查询只能返回未登录。trace 中 `/api/documents/draft-facts` 于 10:32:34.729Z 返回 401 且带 Set-Cookie，之后两次 `/api/auth/session` 401 不带 Set-Cookie。改从不查询会话的公开页读原件、失效后才进入平台；没有放宽实际错误原因、完整原件字节或云端修订断言。WebKit 连续五轮、另外两浏览器增量及三浏览器 running 均通过。
5. 旧退出故事改用真实预览/确认；活跃编辑页异步释放镜像只允许一次有界清理重试。两条换人后旧成功响应迟到故事预先打开真实登录表单，以产品广播完成换人，不再用会主动删除原件的退出准备保留原件前提。
6. 早期夹具的过长用户名前缀、无真实文档的随机记录、未导航同源就读 IDB、故障注入前提和 WebKit 鼠标焦点假设均已定位修正；原始失败保留。生产判定、原件、唯一修订和焦点要求没有降低。
7. API 独立分块先于页面初始化契约造成 CSP 拦截，改为错误契约显式先初始化 jitless；按需退出页复用既有 auth 会话入口，恢复平台两文件首屏。完整能力和文字按需加载，没有改变构建规则或预算。
