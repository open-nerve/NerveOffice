## 1. 范围与结论边界

S5 完成 SDK 偏好的每编辑器内存替换、pending-save 的用户隔离，以及明确退出和确证停用的完整旧数据清单。US-M4-08 激活。清理仍使用原会话的持久许可和同源互斥；未完成不能报告 cleared，重新登录使旧操作失效。

这是 Step 自审。整个 P4 的独立审查、默认完整门禁、生产容器、no-ff 合并、推送和同 SHA 六项 CI 尚待 S6。无头 WebKit 不代替真实 Safari；P5/P6 尚未实施。

## 2. 逐项核对

- SDK 服务覆盖放在实际注册该服务的 UniverUIPlugin 配置中；核心 Univer override 不能替代此注入点。使用实际档案注册 Render/UI 插件的测试验证阅读、编辑实例隔离和销毁。内部 API 出口、登记与 lint 限制同步。
- 内存实现覆盖锁定 SDK 的全部异步接口。读写及遍历克隆值；销毁清空，旧回调不能重新留存。浏览器通过真实自定义数字格式验证当前实例能记住、重建后不继承，既有 SDK 数据库和 localStorage 不新增偏好。没有新增测试构建探针。
- pending-save 键包含已确认的用户与文档；旧未分用户键不读、不迁移。已知退出、换人或本机许可停写后，pagehide 不补旧记号；在途结果未知仍不提前释放编辑权。刷新自检的独立观察改为读取原用户的精确键。
- 旧数据清理只删除规定的 SDK 库/键、退役意图及本人 pending-save。其他账户、近似键、无关数据库保留；不读旧值，不用旧数据授予恢复身份，不调用 Storage.clear。
- Storage 清理先收集匹配键再删除。访问、枚举、删除失败保持 failed，仍尝试其他存储；删除允许重排索引的反例覆盖明确清理和启动清理。
- IDB blocked 立即返回 pending，无事件最多等待 3 秒；同一 Document 不重复排队。浏览器无法撤销已发出的删库请求，迟到回调只处理这个退役库，不续删用户键或草稿，也不把已经交回的 pending 静默变成成功。
- 附加清单位于原许可检查之后、同源锁之内。附加失败仍尝试主库/镜像清理，任何未完成都不调用 finishUserCleanup。退出、停用和启动补清统一从 browser-cleanup 组装，没有网络请求进入锁内。
- 结果文字改为“本机数据”，分别说明服务器退出与本机清理。保留编辑器页会占用 SDK 的模块私有连接；允许用户在待清理结果页明确前往登录，新登录不继承旧清理许可。

## 3. 发现与修复

1. 最初的三浏览器相关矩阵为 82/93 通过。每个浏览器的换人登录故事和两个迟到捕获故事，共 9 项仍假定保留编辑器/探针页时旧库可立即删除。改为先断言服务器已结束、本机 pending；换人故事明确前往登录，迟到捕获故事在旧宿主仍活着时验证拒写，之后关闭占用页并重试。没有提前关闭宿主或把 pending 冒充 cleared。
2. 同轮 WebKit 数字格式用例的现场仍在单元格输入态，连续点击 A1 后工具栏禁用。先真实保存输入，再选择单元格设置格式；不强制点击禁用元素。
3. 同轮 WebKit 完整清单在 OPFS 根目录访问处失败。P1 已确认其临时上下文不支持 OPFS，镜像用例改用既有持久上下文，并显式继承自动保存模式；真实非空镜像和删除后的空结果断言均保留。修正矩阵三浏览器 30/30 通过，包含刷新自检。
4. 自动保存首轮为 65/66 通过，Chromium 的 sessionStorage 残留本人记号。根因是边枚举索引边删除，而 Storage 删除允许重排剩余键。两个确定反例先失败，再改为固定键清单；随后相关 31 项单元、默认三浏览器新故事 18 项、完整 running 矩阵 66 项及 running 刷新自检 3 项通过。[HTML Storage 规范](https://html.spec.whatwg.org/multipage/webstorage.html#the-storage-interface)支持此顺序语义。没有通过重试或忽略残留掩盖问题。
5. Task 4 首次全组运行还有一项旧退出文字断言失效，改为完整数据清理的文字后相关 1,580 项通过。该次全组日志被 task-done 的同名日志覆盖，当前文件只证明后次通过，不将首次日志计作已保存原件；独立的 Task 4 RED 日志仍保留。

## 6. 已知边界与交接

SDK 模块求值仍可能打开空的 UniverLocalStorage，销毁编辑器不能关闭这个模块私有连接；没有修改依赖或拦截全局存储。占用时如实保持 pending，关闭编辑器页后重试。其他标签页私有的 sessionStorage 无法从本页遍历，各页启动自行清退役意图；这些旧记号不再提供任何身份。

SDD 账本在 `.superpowers/sdd/P4-S5-SDK内存存储与旧数据清理/`。浏览器原件、当时源码与 manifest 在主目录 `.codex/handoffs/m4-p4-20261014/s5-browser/`；变异在同级 `s5-mutations/`，最终 Step 汇总在 `s5-acceptance/`。S5 在唯一 P4 分支一次中文提交后继续 S6，主目录 main 不变，不提前推送开发分支。
