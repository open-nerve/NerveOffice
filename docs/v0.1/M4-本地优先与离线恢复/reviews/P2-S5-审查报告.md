## 任务 2：当前编辑权与实际发送

EditingSession 同步关闭上传许可，保留离线捕获与持久来源。重连实际 confirm；expired 沿原 lose 续上一轮，再次 confirm 才放行。旧心跳、旧确认、再次 offline、换租约/用户/来源/协调器、失锁和 dispose 均不能恢复旧许可。未知确认单飞按 2–30 秒退避，普通成功请求不清等待；Autosave 原 Retry-After 保持不变。

SendSave 区分 save 与终态 reconcile。mark/排队/lose 等待结束后的每次真实 HTTP 都重新检查许可。reconcile 只原样核对旧请求，租约拒绝不能触发续上。not-sent 对新请求释放 pin、清本次 unconfirmed，对旧 unknown 保留原编号、字节与原故障，不制造网络错误。
