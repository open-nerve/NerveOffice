## 关键发现与处理

| 根因 | 修复后的行为与反例 |
|---|---|
| 20 秒从 ack 重新起算；旧计时器拖迟后事件仍可成功 | deadline 固定为第一次 ask + 20 秒，各阶段最多使用剩余时间；done/failed/ack/busy/锁释放均核对截止。5 条首轮红灯和 3 条延迟事件红灯保留，定向 64 项通过 |
| 取消旧操作清掉新记号；UUID 大小写不一致 | 记号严格投影非敏感字段，读写使用规范 UUID；清理绑定实际观察/写成身份。没有取得身份的取消不删除任何记号，同实例换 writer 后旧清理无效 |
| 复制页首次认证或正文请求失败留下自动资格 | 普通导航在发请求之前同步清除继承的恢复命名空间；真实 window.open、第一次正文失败、原页关闭后再 reload 均不能冒充。显式恢复仍可处理原件 |
| 预检后原件改变；旧回执确认后空记录误进编辑 | 独立 Reader 只预检并释放；统一 prepare 二次核对自动约束。改变/空记录/未知/不兼容回阅读，旧请求确认后取最新云端且不再以空来源自动进入 |
| 未写成就记新 writer；迟到详情或同用户复核扰乱生命周期 | 只有当前代次实际写成/采用成功才通知记号；换钥、暂停、失权后旧通知无效。详情按最新请求轮次采用；取消自动尝试后只补新实例锁，重复同用户确认不取消有效补锁 |
| WebKit 重载后旧锁 AbortError 回调删除继承记号 | 真刷新轨迹证明：新页面初始化后，已退出旧页的回调仍到达。以 still() 限定旧所有者清理；活页失锁继续撤销资格。1 红→235 定向绿，随后三浏览器真实刷新通过；pagehide 不提前释放实例锁 |
| 共用 refresh-save 仍预期手动本人接管 | 测试构建在 load 前被动观察原 query、gzip SHA-256、是否带租约和状态，不改请求。新页普通申请后无租约精确确认一次、回阅读；HTTP 时序弥补数据库 100 ms 采样。8 红→64 绿，默认/生产自动保存模式均通过 |
| 浏览器夹具掩盖目标路径 | 缩短合法用户名；替换记录先按原观察条件删除；迟到 201 用真实时间与独立登录页，避免 page.clock 改写导航事实或提前请求超时。20 秒场景延后 2 秒 ack，核对旧请求确切的 EDIT_LEASE_LOST 和 A1/B1 正文 |
| 测试挂接引入运行时契约依赖改变分包，触发 Zod JIT 的 CSP | 移除该测试模块的运行时导入，保留头名常量并由单测以真实契约常量核对；不放宽 CSP。18 项单元、类型/lint、重建及 51 项定向浏览器通过，生产产物扫描仍通过 |
| 旧 CLIENT_OUTDATED 用例要求刷新必定阅读 | 夹具只伪造 HTTP 版本，磁盘原件仍兼容，S4 正确自动恢复。保留旧页拒绝、禁保存、释放租约和云端 revision=1；改为明确等待自动编辑，并在新输入前保存、核对 revision=2 与原 A1。独立复核 M1 闭合，整组 21 项及 running 模式 3 项通过；生产实现未因旧断言而改动 |
