## 5. 环境与准备顺序

实际环境在 `s1-environment.json`：Apple silicon、48 GiB 内存、macOS 27.0（26A428），盘点时磁盘约 12 GiB。Parallels 20.3.2 已安装，登记列表为空；`prlctl stop --help` 返回 Pro/Business 限制说明。没有把这一命令当成停止操作，没有 VM 被改变。新镜像下载、工具安装、VM 实验均为 0。

先处理不依赖新增 VM 的生产容器主链路；再对项目自己产生的历史展开报告按固定清单无损归档，核对恢复能力后回收空间。选型阶段逐项确认发行包架构、镜像摘要与突然停止语义，工具/镜像下载前告知需求方；不要求用户提供密码。

官方资料（2026-10-17 核对）：

- [Parallels macOS 客体安装](https://kb.parallels.com/en/125561)：IPSW 路径、64 GB 默认虚拟磁盘、CLI 需要 Pro/Business；本机 CLI 的实际限制与文档一致。
- [Chrome ARM64 Linux 公告](https://blog.google/chromium/bringing-chrome-to-arm64-linux-devices/)：官方已宣布 ARM64 支持，不能沿用“Linux Chrome 只能 x64”的旧假设；仍须核对选定版本实际安装包。
- [Edge 支持的系统](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems)：Linux 系统支持不等于所需 ARM64 包已经可用，实际包架构待 S2 锁定。
- [WebKit 存储政策](https://webkit.org/blog/14403/updates-to-storage-policy/)：持久模式可能免于驱逐；具体清理条件在 S4 核对，不写永久保证。
- [QEMU 磁盘选项](https://www.qemu.org/docs/master/system/qemu-manpage.html)：需要明确虚拟磁盘缓存/flush 语义；选型与实验报告必须记录，不能以宿主未断电模拟物理缓存丢失。
