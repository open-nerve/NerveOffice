## Codex 独立审查新增问题

首轮独立审查者没有修改实现，依据实际异步边界提出以下问题。D1/D2 都先以可控暂停复现，再修改生产代码。

| 编号 | 等级 | 根因与修复 |
|---|---|---|
| D1 | P1 | 临时读者持有 OPFS 句柄时，新页遇 busy 仍登记、写入，恢复者随后可能把从未被看过的镜像判为 seen。增加同源短期 Web Lock，登记等待完整恢复结束。 |
| D2 | P2 | IndexedDB 已提交、mirror.write 尚未开始时，清理可先完成，旧 Worker 随后重建镜像。清理三个入口与完整文档任务共用短期锁；句柄仍开着时保留墓碑并返回 pending。 |
| D3 | P1 | 主线程退路省略恢复，也可能复用仅存在镜像中的序号。工厂默认组装只读恢复；主线程不写镜像，但登记前仍先恢复。 |

锁覆盖完整的主库与镜像两段，以及平台单份恢复；内部 store/mirror/recovery 不重复加锁。长期 OPFS 句柄不持此锁，所以空闲旧页不阻塞接管。锁不可用或等待超过 10 秒时明确失败；超时只取消尚未开始的请求，执行中的任务以真实结束为释放边界。设计、ADR-020、总设计与架构总览已对齐。
