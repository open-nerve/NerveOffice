## 与设计的偏差和明确边界

- 继续执行 P3 已批准的纯网页方案：新 Document 使用新身份，先阅读并提示，无法证明原页身份时由用户明确恢复。P4 没有恢复自动继承的旧记号。
- SDK 偏好服务在 `UniverUIPlugin.override` 注入。核心 Univer override 不注册该服务，放在那里无效。SDK 模块仍可能打开一个私有空库；不改 SDK 或全局拦截，删库受占用时报告 pending，关闭本站编辑器后重试。
