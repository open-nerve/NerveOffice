## 与设计的偏差

都已回写到 P1 设计、M2 总设计、00 号计划书或 ADR。

- **签发重置时旧密码立即失效**（审查 A7，ADR-013）：账户被盗时直接签发重置即可切断旧密码；不采用"允许对停用的账户签发"。
- **改动账户的事务统一先锁账户行并复核**（审查 A1、A2，ADR-007 的补充）：验证密码在事务之外，事务里按凭据的版本（`users.password_version`，迁移 0008：换凭据时加一，按新参数重新哈希不变）复核；锁的顺序为 system-admins → 按登录名的锁 → 账户行 → 重置行或邀请行 → 限流计数 → 会话行。管理操作都在锁里复核操作者（停用与系统角色取排他锁，其他取共享锁）。
- **运维命令 `pnpm admin:reset-link`**（P1 设计 §3.9）：M2 总设计 §2.1 第 6 条与 00 号计划书 r8 的 §5.2 已同步正文（**请需求方确认**）；标准输出只有链接，日志写标准错误；容器里用 `docker compose exec`。
- **修改密码失败记审计**（新动作 `users.password_change_failed`，迁移 0008 同步）；登录与修改密码的复核不通过，审计原因记为 `credentials_changed`。
- **邀请带 `superseded`**：界面只对同一个登录名最新的一条给出重新生成。
- **前端**：接受或完成之后是单页内导航（与登录页相同），不是整页；行内操作用按钮，不用下拉菜单；选择框用原生的 `select`；弹窗不经 `shared/ui` 的桶文件导出（lint 守护）；会话复核给组件用（`SessionRecheckContext`），不让会话查询失效；登录页只认没有失败的会话查询。
- **首屏**：平台页面 156.4 KiB（审查之前 168.2 KiB）。

## 下一个 Phase 须知

- **改动账户的事务**（ADR-007 的补充）：第一步 `UsersService.lockAccount`（`FOR NO KEY UPDATE`），在锁里复核；凭据有没有变按 `password_version` 判断，只有 users 的仓储写密码（换凭据经 `changeCredentials` 加一，同一个密码重新编码经 `reencodePassword` 不加；服务层对应 `replacePassword`（复核旧凭据之后换）与 `resetPassword`（签发与完成重置）），新的写密码路径必须走这几条之一；管理操作先 `lockActingAdmin`（共享锁）或在排他锁下 `requireActingAdmin`。P2 在停用的事务里接上"收回写入权"与文档转移时，文档行排在账户行之后。
  - 不要对账户行用 `FOR UPDATE`：它与外键检查的 `FOR KEY SHARE` 冲突。
  - 不要锁操作者的行：两个管理员互相操作时会成环。
- **并发测试**：`tests/integration/src/support/held-lock.ts` 用两个连接构造确定的交错（持锁 → 等请求在锁上等着 → 改数据、提交），可以分几步发出请求；新测试要用变异确认检得出回归。
- **admin 模块**：只有控制器与编排服务；新的管理页（P2 的团队空间）也放在 `features/admin`，只经 `app/routes.ts` 动态引用（lint 强制）；管理接口的查询与变更带 `SYSTEM_ADMIN_ONLY` 元数据。
- **同事目录**：`GET /api/users?query=`，P2 添加成员、P5 分享都用它（只返回有效账户，最多 20 条）。
- **前端**：
  - 带第三方运行时的重组件不经 `shared/ui` 的桶文件导出（弹窗已有 lint 守护）；
  - 程序打开的弹窗用 `DialogContent` 的 `fallbackFocus` 给出焦点的去处；
  - 改了本人账户的操作经 `useSessionRecheck` 向服务端确认会话；
  - 一次性链接的公开页面上跳过的复核，离开时补上。
- **E2E**：
  - `anotherDevice` 收集 CSP 违规；trace 与截图由测试运行器对每个上下文自动做，不用手工开；
  - 行内按钮的可读名称是"操作 对象"，按开头匹配；
  - "下一次请求"在页面里新建表格；
  - 运维命令用 `support/admin-command.ts`（容器 E2E 经 `docker compose exec`）。
- **已知的坑**：
  - drizzle 在单表的查询与 RETURNING 里不给列加表名：相关子查询里的列要写全名（`sql.identifier`），否则被子查询里的同名列截走（邀请的 `superseded`）；
  - web 包没有 `test` 脚本，`pnpm --filter @nerve-office/web test` 什么也不跑：前端单元测试用 `pnpm exec vitest run --project unit-web`；
  - TanStack Query 在重新请求失败时保留旧数据：判断"已登录"要同时看 `isError`；
  - Radix 的模态弹窗只把焦点还给 `DialogTrigger`；它给弹窗以外的内容加 `aria-hidden`，按角色数弹窗要带 `hidden: true`（E2E 按 `role` 属性数）；
  - WebKit 点按钮时不聚焦按钮，焦点给最近的可聚焦祖先。
