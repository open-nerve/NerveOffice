## 与设计的偏差

都已回写到 P3 设计与 ADR-015。

- 只读守卫在设计的三件事之外又做了五件（E2E 与审查发现）：图片设为不可编辑（`IDrawingManagerService`，渲染读它的标志）、替换不开放（取消 `open-replace-dialog`，查找照常）、批注浮层只读且不能拉伸、编辑栏点不进去（拦指针事件 + 聚焦即放开）、冻结线拖不动（SDK 定义了拦截却没注册）。
- 守卫因此分三步装：创建工作簿之前 → `applyWorksheetPoints` → 就绪时 `applyRenderedGuards`、`clearUndoStack`。最后一步是渲染模块到位之后才能做的事。
- 不用 sheets-ui 的 `disableEdit`：实测它让复制与方向键失效，编辑栏照样点得进去。
- 权限提示改成只读的说法（语言包深合并覆盖 24 条；SDK 的 `mergeLocales` 只合并第一层）。
- 内部 API 共 17 项，其中 2 项是 SDK 的 DOM 标记（不是公开 API，由 E2E 回归）；界面的包拆到第二个出口 `internal-api/ui.ts`。
- 探针另有命令日志与补上的插件 Facade（`probe-facades.ts`，只在测试构建里）。

## 下一个 Phase 须知

- **编辑器能不能编辑在创建时决定**：`createSheetEditor({ access: 'edit' | 'read' })`，编辑器页按 `permissions.canEdit`。适配层不知道查看者、归档这些业务概念。P4 的回收站、P5 的分享里"只能查看"的文档照此打开。
- **只读守卫**（`editor/read-only/`）：防火墙与变更检测共用同一个判定，只读时检测不到修改；三步装上，M3 的原地切换复用 `applyWorksheetPoints`、`applyRenderedGuards`、`clearUndoStack`、`dispose`（退出时另外恢复权限点与图片的可编辑）。
- **内部 API 的两个出口**：数据的包进 `internal-api/index.ts`，界面的包（docs-ui、engine-render、sheets-ui）只进 `internal-api/ui.ts`。公式 Worker 引用 `index.ts`，界面包从那里再导出会整包打进 Worker（超预算近一倍）。加新符号前先判断它属于哪一类。
- **SDK 的 DOM 标记**（`internal-api/dom-markers.ts`）：编辑栏、批注浮层的处理依赖它们，SDK 升级先跑 `read-only.spec.ts`。
- **E2E 的探针**：`window.__nerveEditorProbe`（`univerAPI`、`snapshot()`、命令日志），只在测试构建里；依赖它的用例带 `@test-build` 标签，容器 E2E（生产镜像）按标签排除，生产镜像上另有一条不用探针的冒烟用例。
- **E2E 的修饰键**：`tests/e2e/support/keyboard.ts`。Univer 按 `navigator.appVersion` 判断苹果平台，Playwright 的 WebKit 在 Linux 上自称 Mac，用 `ControlOrMeta` 在 CI 上会对不上。浏览器原生处理的组合键（粘贴、改名时的全选）仍用 `ControlOrMeta`。
- **E2E 的同步点**（不用固定时长的等待）：探针的命令日志（某条命令已被尝试或已被取消）、权限提示关掉、名称框显示新的地址、光标的样式（拖动工作表标签、图片、冻结线）、两个动画帧（右键菜单与拖动的位置）。
- **样本**：`tests/e2e/support/read-only-sample.json`（M0 的综合样本收敛后的形式，打开与画完每张表之后逐字节不变）。SDK 升级后用 `pnpm --filter @nerve-office/e2e run update:read-only-sample` 重新生成。
- **CI 的时长**：`read-only.spec.ts` 本机每个浏览器约 4.3 分钟（对照组已并行）；CI 的 `pnpm verify --ci` 时限 45 分钟，合并前约 20 分钟，要留意，接近时考虑分片。
- **已知的坑**：
  - 命令被取消时，SDK 命令执行栈里的那一项不弹出（之后的 mutation 带上被取消的命令 id 作为触发来源，无实际影响，UR-005）；
  - 图片能否编辑，渲染读的是 `IDrawingManagerService` 的标志，不是 `ISheetDrawingService` 的（UR-024）；
  - 冻结线的权限拦截 SDK 定义了却没注册（UR-022）；冻结区域里的行列分隔线只读时仍显示调整光标，拖动会被权限检查拦下；
  - 编辑栏的上下文不复位（UR-023）：放开编辑栏要排一个微任务，同步放开会被 SDK 之后的设光标与 React 的提交覆盖；
  - 批注浮层的文本框没有只读开关（UR-025）；
  - 替换的快捷键在苹果的平台上也是 Control+H；删除图片的键在苹果的平台上是 Backspace；
  - 无头 WebKit 读不了剪贴板（复制的用例只跳过读取这一步）；
  - 查找的快捷键要等 SDK 的 Steady 阶段才可用。
