### S2 文档的整理

- [x] 1. 重命名与空间内移动（`PATCH /api/documents/{id}`）：权限、审计、不动 `write_epoch`，也不动 `updated_at`。
- [x] 2. 跨空间移动（`POST /api/documents/{id}/move`）：源空间管理员 + 目标新建权限；`write_epoch + 1`；同事务收回写入权；目标就是当前空间时按空间内规则。
- [x] 3. 复制（`POST /api/documents/{id}/copy`）：`INSERT … SELECT` 直接复制压缩字节，`unitId` 不变，新文档修订号 1；幂等按 `requestId`。
- [x] 4. 集成测试：复制的逐字节一致与两份互不影响；跨空间移动之后的权限变化；8 个变异全部检出。
- [x] 5. 顺带修好停用者文档转移不清 `folder_id` 的 bug（S1 加了这一列之后才暴露）。
