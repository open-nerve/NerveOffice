## 任务

### S1 适配层的只读

- [x] 1. 身份：`EditorAuthzIoService` 按 `access` 回答（只读时只允许查看与复制，动作取自工作簿的查看、复制权限点类）；`editorIdentityOverride(access)`；单元测试。
- [x] 2. 只读守卫 `read-only/`：防火墙（与变更检测同一个判定）、`BeforeUndo`/`BeforeRedo` 取消、`clearUndoRedo`、工作表权限点；销毁；单元测试（假的 Facade 事件与注入器）。
- [x] 3. 档案：按 `access` 组合 `UniverUIPlugin`、`UniverSheetsUIPlugin` 的配置与只读另外隐藏的菜单；档案的单元测试。
- [x] 4. `createSheetEditor({ access })`：只读时在创建工作簿之前装防火墙与撤销拦截，创建之后设工作表权限点，就绪时清空撤销栈；去掉 `setEditable`。（变更检测与防火墙共用 `command-event.ts` 的转换与同一份判定配置）
- [x] 5. 内部 API 登记（`IPermissionService`、`IUndoRedoService`、权限点的清单与类）与 lint 的受限符号、自测。

### S2 编辑器页与测试构建的探针

- [x] 1. 编辑器页按 `canEdit` 传 `access`，去掉就绪之后的 `setEditable(false)`；单元测试。
- [x] 2. 探针 `editor/testing/e2e-probe.ts`：只在 `import.meta.env.MODE === 'e2e'` 时动态引入；`window.__nerveEditorProbe = { univerAPI, snapshot() }`。
- [x] 3. 门禁 `artifacts`：探针的分块属于只在测试构建里的文件；生产产物里不能出现探针的名字；门禁的单元测试。

### S3 E2E

- [ ] 1. 只读的样本：5 张表（数据、汇总、隐藏、功能、筛选），浮动图片（data URL）、筛选、批注、条件格式、数据验证……直接写成快照，测试辅助写库。
- [ ] 2. `read-only.spec.ts`（US-M2-11）：
  - 界面入口与还能碰到的入口无效；
