## 任务

### S1 数据模型与有效权限

- [ ] 1. 契约：授权的角色与类型、分享的请求与响应、"与我共享"的响应。
- [ ] 2. 表定义与迁移 `0014_m2_document_grants`（`document_id` 级联删除、`(user_id)` 索引、审计三个动作）；`gate schema migrations`。
- [ ] 3. `DocumentGrantsRepository`（一表一仓储）。
- [ ] 4. `effectiveDocumentRole` 纯函数（空间角色与授权取较高者，归档一律降到查看者）与单元测试。
- [ ] 5. `EffectiveAccessPolicy.accessOf` 一条查询并上授权（空间事实左连接授权行）；`spaceAccessOf` 不看授权。
- [ ] 6. `accessible` 按"要哪几半"接受参数；三个调用方各自写明；转移仍只看空间那一半。
- [ ] 7. 永久删除连带删授权（级联）；集成测试。

### S2 分享的接口与"与我共享"

- [ ] 1. `DocumentSharingService`：列表、设置、取消；锁文档行并在锁下复核；审计；取消与降级时收回写入权。
- [ ] 2. 校验：不能给自己、不能给停用的人、被授权人必须有效；归档 403；回收站 404。
- [ ] 3. `workspace` 的控制器：`/api/documents/{id}/grants`（GET、PUT、DELETE）与 `GET /api/shared`；分享列表把用户换成显示名。
- [ ] 4. 集成测试：幂等、取较高者、按空间列出不受授权影响、搜索受授权影响、跨空间移动与移出空间保留授权。

### S3 前端

- [ ] 1. 分享对话框（按需加载，复用同事目录的选人组件）：搜人、选角色、调整、取消；进行中与失败的处理按既有约定。
- [ ] 2. "与我共享"页与左侧导航入口（按需加载）；显示所属空间的名称，不显示目录结构。
- [ ] 3. 按权限隐藏分享入口（只有空间管理员 / 个人空间所有者看得到）。
- [ ] 4. 前端单测与 E2E。

### S4 越权访问的全面验证（US-M2-14、A03）

- [ ] 1. 权限矩阵加两个角色（只有查看授权、只有编辑授权），六张表全部扩一列。
- [ ] 2. 生效时机：取消分享、移出空间、停用之后下一次请求即生效。
- [ ] 3. 无权与不存在一致：响应逐字节相同，语句数量相同（代替时间断言）。
- [ ] 4. 列表、搜索、"与我共享"、回收站都不出现无权的文档。
- [ ] 5. E2E 的关键路径：猜文档地址、取消分享后访问、移出空间后访问、停用后访问。
