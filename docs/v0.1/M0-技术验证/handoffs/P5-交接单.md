## 待办：macOS 真实输入法的人工核对（M0 结束评审前）

V13 的结论以它为前提（报告附录 A）。

- **负责人**：用户，需要人在真实的 Safari 与 Chrome 里用系统输入法操作，约 15 分钟。Claude 负责准备环境、汇总记录并用合成驱动回放。
- **截止**：M0 结束评审前，即 P6 完成之后、打 `v0.1-m0` 标签之前。
- **做法**：`spikes/m0` 下执行 `npx vite build` 与 `node scripts/ime-real.ts --open`，按页面右下角的清单操作。
- **结果不符时的处理**：
  1. **真实 Safari 的提交顺序与 Chrome 相同**（`compositionend` 的数据与最后一次更新相同）：事件归一不会介入，结论不变。报告 §3.3 第 1 条改写为"真实 Safari 没有走这个分支"，归一保留作防御。
  2. **Safari 走 WebKit 顺序，平台页面上撤销正确**：结论成立，把记录补进报告 §3。
  3. **平台页面上撤销或正文仍然出错，或者出现第三种事件顺序**：用记录回放定位，调整归一策略后重跑 `e2e/v13-ime.spec.ts`。平台侧无法解决的，按"意料之外的高风险发现"停下来请示，因为这会影响 V13 的结论。
  4. **英文标点状态下的 `/` 既不经过 `/` keydown，也没有 `insertText` beforeinput**：补上 input 阶段的处理，并重跑 C8。
  5. **候选框明显偏离输入位置**：提高 M6 缓解的优先级，写进已知限制。

## 下一个 Phase 须知

**验证工程的新能力**

- 页面参数：
  - `docpolicy=platform`：文字文档平台策略（`src/harness/doc-policy.ts`）。`PLATFORM` 常量为 `img=platform&docpolicy=platform`；
  - `imelog=1`：输入法记录页；
  - `outline=1`：大纲侧栏；
  - `tocblock=1`：注册目录块插件（只用于评估）；
  - `without=formula`：去掉公式引擎组。
- 环境变量 `M0_P5_QUERY`：给 V13 用例的每次打开追加页面参数，结果写进带后缀的目录（例如 `capabilities-worker/`）。
- 验证服务：`/__imelog`（`POST` 保存、`GET` 读取、`DELETE` 清空输入法记录）。
- 脚本：
  - `scripts/ime-real.ts`：人工核对（端口 4790，`--open` 在 Safari 与 Chrome 中打开）；
  - `scripts/p5-summary.ts`：汇总报告中的表格；
  - `scripts/p5-doc-bundle.ts`：`doc@1` 的包体积。
- `e2e/p5-helpers.ts`：
  - `imeCompose`：三种输入法驱动，`cdp` 只在 Chromium 内核上可用，`chrome`、`webkit` 为两种顺序的合成事件；
  - `plainInsert`：不经过按键的输入；
  - 光标与选区：`setSelection` 会聚焦隐藏输入元素，另有 `offsetOf`、`endOffset`、`caretPoint`；
  - 界面操作：`ribbonTab`、`clickToolbar`、`fillLinkPopup`、`imageToolbarButtons`；
  - 检查：`docSummary`（正文结构摘要）、`roundtrip`（保存重开比较）、`policyEvents`（平台策略的操作记录）、`pageHealth`。
- `e2e/perf-helpers.ts`：统计、Worker 监视与 JS 堆（从 V10 抽出）。
- `window.__m0`：
  - `docPolicy`：平台策略的操作记录；
  - `imeRecorder`：输入法记录页；
  - `activeTextRange()`：当前选区；
  - `editor.detector.composition()`：组合输入的状态。
- `waitForCapture` 的新选项：`respectComposition`（默认 true）、`compositionMaxWaitMs`（默认 3000）。

**已知的坑**

- **合成输入法事件**：浏览器派发原生事件时，每个监听器之后都会清空微任务队列，脚本里的 `dispatchEvent` 不会。合成驱动每次派发之后要清空一次微任务队列；同一次提交里的事件之间不能让出宏任务，否则会掩盖时序问题。
- **隐藏输入元素**：键盘事件只发给隐藏的 `div#__editor_<unitId>`，设置选区后要聚焦它。
- **`/` 键**：SDK 默认下，在正文里键入 `/` 会吞掉其后键入的字。写用例时，要么用平台配置，要么避开 `/`。
- **界面动画**：图片的浮动工具条、环绕方式的下拉有淡入动画，点击要等动画结束。
- **性能口径**：两帧的口径只在主线程模式下等于"画出来"；Steady 有约 3 秒的固定延迟，不能当作指标。
- **样本**：手写样本加载时会随机生成 `sectionId`，比较快照时要排除。Facade 的 `setStyle` 设置的标题没有 `headingId`，目录块用不了。
- **剪贴板**：无头 WebKit 不能读写剪贴板。
- **桌面会话**：本机断电重启后，如果没有登录桌面（只通过 SSH 连接），WebKit 无法启动，Chrome 间歇崩溃，只有 Chromium 可用。三个浏览器的用例要在登录桌面之后跑。
- **并行运行**：不要在用例运行时重新构建共用的 `dist`；性能用例单独运行。
