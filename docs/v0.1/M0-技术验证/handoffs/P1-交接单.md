## 下一个 Phase 须知

**验证工程怎么用**

- 页面：`sheet.html` / `doc.html`，参数 `sample=<fixtures 中的名称>`、`worker=1`；阅读模式（`mode=read`）留给 P3 实现，现在传入会直接报错。
- 验证脚本通过 `window.__m0` 访问编辑器：`ready`（进入 `Steady` 后兑现）、`editor.univerAPI`、`editor.save()`、`editor.timings`、`events`（页面内的违规与错误）、`workerStats`（Worker 的 RPC 往来）。
- 三个服务：`full`（4700）、`off`（4701）、`html-only`（4702），由 Playwright 自动启动；`/__csp-reports` 读取、清空违规报告；`/__selftest` 接收真实 Safari 自检结果。
- 共用的编辑场景在 `e2e/scenarios.ts`；违规的统一格式与三渠道采集在 `e2e/csp-reports.ts`。
- 真实 Safari：给编辑器页面加 `selftest=<场景>&next=<下一步>`，页面会用 Facade 完成编辑、把结果交回服务；`scripts/safari-selftest.ts` 是范例。

**已知的坑**

- 不要用 Playwright 的设备预设：它会改写 UA，而 Univer 按 UA 判断快捷键修饰键。
- `Steady` = `Rendered` + 固定 3 秒。首屏时间用 `Rendered`；判断"打开即有修改"要等到 `Steady` 之后。
- Chromium 的 `report-uri` 会把相同的违规去重，计数请用页面事件；WebKit / Safari 的 Worker 内违规只能在控制台看到跨源请求，动态代码违规完全不可见。
- 被 CSP 拦截的请求不会出现在 Playwright 的请求记录里；要核验网络行为，请用 `off` 服务。
- WebKit 会把 Worker 的控制台消息同时发给页面与 Worker 两个监听器；判断作用域要按脚本路径（`*.worker-<hash>.js`），不要按整个 URL（页面地址里可能带 `worker=1`）。
- 验证工程自己的页面资源也要遵守探测策略：例如 `data:` 图标会触发 `img-src` 违规，污染结论。

**P2 需要的源码事实**（`refer/univer` 已是 v1.0.0）

- `saveUnit` 用已注册插件的资源整体覆盖 `resources`（`packages/core/src/services/resource-loader/resource-loader.service.ts`）。晚注册的插件会给已有文档补加载资源。
- `loadResources` 在某个插件解析资源失败时，只记一条 `[ResourceManagerService] loadResources error` 日志就丢弃该资源，下次保存会以空值写回。所以"资源条目消失"的服务端检查拦不住这种情况，需要在打开时做客户端自检（P2 验证）。
- 资源名清单（源码）：表格有 `SHEET_AuthzIoMockService_PLUGIN`、数据验证、条件格式、图片、筛选、备注、定义名称、区域主题、区域保护、工作表保护（两项）等；文字文档有 `DOC_WORD_STYLES_PLUGIN`、`DOC_NOTE_PLUGIN`、图片、超链接等。P2 以运行时注册的 hook 为准生成正式清单。
- 保护相关的资源也会持久化在快照里；界面隐藏保护入口后，如果快照里带了保护规则，用户将无法解除。P2 需要给出处理建议。
- Univer UI 会在 IndexedDB 中建库 `UniverLocalStorage`，存用户习惯（最近用过的数字格式、自定义格式、表情）。它不按文档区分，不影响 V05；但 00 号计划书 §7.6"退出登录后清空本机数据"需要覆盖它，交给 P6 与 M4。

**交给后续 Phase 的事项**

- P3：变更检测应按 `unitId` 过滤（表格的单元格编辑器是一个内部文字文档，它的 `doc.mutation.rich-text-editing` 不属于表格内容）；性能基线以 `Rendered` 为首屏。
- P4：两条图片下载的 `fetch` 路径；CSP 定稿（`font-src data:`、`blob:`、样式哈希能否代替 `'unsafe-inline'`、违规上报只作抽样信号）。
- P5：文字文档能否去掉公式引擎（影响包体积）；是否启用排版 Worker；目录功能是否纳入。
- M1：报告 §7 的"M1 事项"清单。
