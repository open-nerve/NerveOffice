## M1 须知：编辑器适配层要沿用的结论

适配层是 SDK 与平台之间唯一的边界（00 号计划书 §9.4、§10.1）。下面每一条都有验证工程里的参考实现（`spikes/m0/src/`，只供参考，M1 按正式流程重写）和锁定 SDK 行为的用例（`spikes/m0/e2e/`，升级 SDK 时先跑）。

1. **插件档案**：按插件档案 v1 注册 `sheet@1` 与 `doc@1`，插件清单与影响数据的配置是数据格式的一部分。
   - 表格：默认启用公式 Worker（主线程三个公式插件 `notExecuteFormula: true`，注册 `UniverRPCMainThreadPlugin`）；Worker 创建失败时销毁重建为主线程模式，`intervalCount: 20`；`largeSheetOperation.largeSheetCellCountThreshold = Number.MAX_SAFE_INTEGER`。
   - 文字文档：不注册公式引擎与目录块插件；`toc: true`（大纲侧栏）；排版 Worker 暂不启用（DEF-007）。
   - 两种档案都不注册 `@univerjs/network`、线程评论、水印等，不注册任何 `ITelemetryService` 实现。
2. **变更检测**（插件档案 v1 §5.3，P3 §2.1）：监听公开的 `CommandExecuted`，只看 `MUTATION`；排除 `onlyLocal`、`fromCollab`、`fromChangeset`、`fromFormula` 与作用于其他单元的 mutation；排除名单只有 `sheet.operation.clear-drawing-transformer`、`doc.operation.clear-drawing-transformer`；**不排除**自动行高。适配层在捕获前不调用 Facade 的读取方法。
3. **捕获时机**（一条规则，P3 §3.4、P5 §1.2 第 3 条、P6 §1.2 第 5 条）：修改停止 1 秒后捕获；公式逐表收齐（没有排队的一轮、这一轮没有被 stop、每张有结果的表都写回）；组合输入进行中不捕获，失焦时复位；从第一处未保存的修改算起最长 3 秒，超过时照常捕获并标记"公式待更新"，收齐后补捕获。**只等 `onCalculationResultApplied` 不可靠**（Worker 模式下它在第一张表写回后就返回）。
4. **阅读模式**（插件档案 v1 §5.2，P3 §5）：表格 `setEditable(false)` 加本地权限点（保留查看与复制），文字文档公开的 `setReadOnly()`；`BeforeCommandExecute` 取消作用于本文档（或没有 `unitId`）的非本地 mutation，**不拦其他单元**（单元格编辑器的同步）；拦截撤销重做并清空撤销栈；界面按原地切换或销毁重建处理。不用 `FWorksheetPermission.setReadOnly()`。
5. **身份**：不调用 `setCurrentUser` 设置真实用户（本地授权服务按 id 前缀判断角色，真实 id 会锁死编辑），或者用"全部允许"的 `IAuthzIoService` 替换。二选一由 M1 决定；写入边界在服务端。
6. **打开自检**（P2 §3.3）：档案完整性（运行时资源 hook 与白名单比对）、资源比较（加载后立即捕获一次，原来非空的不得消失或变空）、资源加载错误捕获（覆盖 `IResourceManagerService`，包装 `parseJson` 与 `onLoad`）。失败时只允许阅读并上报。
7. **CSP**（P4 §3.4）：`default-src 'self'; img-src 'self' data: blob:; connect-src 'self'; font-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'; worker-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`。随所有响应下发，包括 Worker 脚本；生产构建不把 Worker 内联成 blob，不注入内联脚本；E2E 带页面与 Worker 两个作用域的阳性对照。M1 起就按定稿下发。
8. **图片**（插件档案 v1 §6，P4 §1.2）：`UniverDrawingPlugin` 的 `override` 替换 `IImageIoService`（表格与文字文档都注册）；图片格式对齐为 PNG、JPEG、GIF、WebP；文字文档剪贴板钩子与命令守卫对任何位置的 `source` 默认拒绝；`IMAGE()` 采用 `restricted`，主线程与公式 Worker 各装一次，Worker 要回报安装结果；表格复制补救由 M5 实现。
9. **文字文档平台策略**（插件档案 v1 §7，P5 §1.2）：`/` 键（keydown 与 `insertText` 的 beforeinput 两条路径，只在表格之外的空段落里放行）；输入法事件归一（WebKit 的提交顺序）；链接地址的白名单与规范写法（`normalizeLinkUrl`，命令守卫、粘贴清洗与服务端共用）；命令守卫（15 个不支持的命令、链接、单元格里的图片）；粘贴清洗；加载时规范为 MODERN，并补齐"去掉页眉页脚数据与表格之外多余的分节符"（验证工程只实现了版式一项）。
10. **内部 API**：按下列登记表集中封装，每一项都有回归用例：P3 §7、P4 §4、P5 §7、P6 §6（协同钩子只在纳入 V15 时需要）。
11. **工程底座**（P1 §7"M1 事项"）：
    - A01 的 CI 检查：以 `deps-report.ts` 为蓝本（版本一致、按安装路径检查单例、没有 Pro、许可分类），加上安装脚本白名单、产物关键字与动态代码扫描，扫描范围包括 Worker 自己加载的子块；
    - 显式配置 pnpm 的 `minimumReleaseAge`，豁免名单的变更纳入评审；
    - 生产构建开启 `build.license`，补齐缺少许可正文的 6 个包；
    - 按最终档案重新统计两种编辑器的包体积（P1 的统计基于候选档案，P5 只统计了 `doc@1`）；
    - 锁定 PostgreSQL 的大版本与镜像【待评审确认：M1】。
12. **E2E 的注意事项**：不用 Playwright 的设备预设（会改写 UA，Univer 按 UA 判断快捷键）；首屏用 `Rendered`，`Steady` 是 `Rendered` 之后固定的 3 秒；无头 WebKit 不能读写剪贴板；WebKit 需要登录的桌面会话；性能用例单独运行；DEF-001（Edge）在建立浏览器矩阵时补测。

## 后续 M 的事项

以 00 号计划书 r3 的 §13.2 为准，这里列出 M0 交出的具体事项。

- **M2**：复制文档原样复制快照，不改 `unitId` 与工作表 id（V05）。
- **M3**：
  - 服务端快照校验（00 号计划书 §11.2）：资源结构与白名单、条目不得消失、必须为空的资源、已知资源的结构校验；统一的地址提取器；图片 `source` 默认拒绝；链接等于规范写法；文字文档只接受 MODERN、不接受页眉页脚、表格之外只允许文末一个分节符、不接受目录块的区间；
  - 内容哈希按规范化口径，客户端与服务端同一算法；
  - 文档修订号与条件写入；
  - 变更检测、捕获时机与阅读模式【待评审确认：M3】；
  - 本机密钥的服务端管理（生成、主密钥加密保存、按会话下发、吊销与在线会话联动）【待评审确认：M3】。
- **M4**：本机发件箱按 P6 §1.2 实现：Worker 放置（WebKit 上 Worker 保持空定时器，DEF-011）、每份文档一条记录、`durability: 'strict'`、写入栅栏、公式待更新与恢复时重算、等锁与待恢复时只读、接手时对齐服务端、"自己追自己"的幂等重试、存储状态与写满提示；公式 Worker 创建失败的判定与重建；Worker 内让出间隔的评估；退出登录时清空 Univer 自己的存储；DEF-009，以及 DEF-003【按评审决定】。
- **M5**：DEF-002（A02）；资源服务按 P4 §1.2 实现；表格复制补救；宿主拦截 `drop`；粘贴时上传失败的提示；编辑栏粘贴图片不上传；表格粘贴"图片文件 + 只有外链图片的 HTML"；**表格超链接的地址白名单**（M0 只验证了文字文档，表格侧与文字文档用同一规则，见能力矩阵 §2.1）；表格能力逐项走界面入口与撤销重做（能力验收报告）；DEF-004。
- **M6**：粘贴的转换偏差；空段落里 `/` 菜单吞字；候选框位置的缓解；单元格里的表格按钮禁用、向前删除键删除图片；DEF-005 至 DEF-008。
- **M7**：以 V10 与 P5 的性能数据为起点；建议以"计算期间帧间隔 p95 ≤ 100 ms"作为界面不冻结的目标；用真实样本复核压缩率；5 MiB 文档在公式 Worker 模式下的内存。
- **上游报告**（M1 起跟踪）：P3 4 条、P4 3 条、P5 11 条（各报告"对设计的影响"一节），以及 DEF-002 的补丁候选。
