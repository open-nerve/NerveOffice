## 2. 范围变更（需要你决定）

|---|---|---|---|---|
| SC-1 | 目录 | 只读的大纲侧栏纳入 v0.1；目录块延期 | 大纲侧栏是公开配置，不写内容，阅读模式下也能用；目录块往正文写 FIELD、HYPERLINK、PAGEREF 区间，无分页版式下页码全是 1 | §4.3、§4.4、§17 |
| SC-2 | mutation 增量日志 | v0.1 不纳入，M4 只做快照；DEF-010 → v0.2 | 依赖不公开的协同钩子，每次升级都要重新排查；重放出错会悄悄写坏文档；快照已满足 §7.8（停顿后约 1 秒、连续输入最多约 3 秒） | D8、§7.5、§13.2 M4、§17 |

## 3. 需要确认的事项

| 编号 | 事项 | 建议 |
|---|---|---|
| 确认-1 | 版本基线 | 锁定 `@univerjs/*` 1.0.0 正式版；删除 §3.2 与 M5 的"正式版门槛" |
| 确认-2 | 插件档案 v1 定稿 | 表格默认启用公式 Worker（退路：主线程模式 + 让出间隔 20），关掉大表操作的拆分；文字文档去掉公式引擎与目录块、排版 Worker 暂不启用（DEF-007）、提供大纲侧栏 |
| 确认-3 | 能力矩阵定稿 | 文字文档部分（P5）与表格部分（M0 收尾汇总，口径见矩阵 §2）；表格超链接的地址白名单交给 M5 |
| 确认-4 | CSP 与 `IMAGE()` | CSP 定稿（去掉 `font-src data:` 与 `worker-src blob:`）；`IMAGE()` 只接受平台地址。P1 留下的两项没有评估：样式哈希能否代替 `'unsafe-inline'`（违规来自运行时生成的 `<style>` 与 style 属性，预先算哈希不现实），以及 `report-to`。建议 r3 写明"保留 `'unsafe-inline'`，违规上报只作抽样信号"，由 M7 的独立安全审查复核，不另登记延期 |
| 确认-5 | 阅读模式与身份 | 本地权限点 + mutation 防火墙；M1 在"替换 `IAuthzIoService`"与"不设置当前用户"之间二选一 |
| 确认-6 | 里程碑归属 | ① 变更检测、捕获时机、阅读模式按计划书原文放在 M3（M3 的在线保存与 A18 就需要），M4 只接入发件箱；DEF-003 里阅读模式与捕获时机的部分改为"M3 前"，性能部分留在 M4。② 本机密钥的服务端管理（生成、主密钥加密保存、按会话下发、吊销）放 M3，客户端加密放 M4。③ CSP 从 M1 起按定稿下发，M5 只复核表格场景。④ PostgreSQL 的版本锁定改到 M1（M0 不含服务端） |

## 4. 需要你完成的一项核对：macOS 真实输入法

V13 的结论以它为前提（P5 报告附录 A、P5 交接单"待办"）。约 15 分钟：

- 我会启动记录页，并在 Safari 与 Chrome 里打开；
- 你按页面右下角的清单用系统输入法操作（拼音输入、撤销重做、替换、中文标点、中英文标点下的 `/`、Esc 与切换中英文、焦点切走），每个浏览器做完点"上传记录"；再在平台策略的页面里重复几步；
- 我汇总记录、用合成驱动回放，按 P5 交接单的五种情况处理。结果补进 P5 报告 §3 与能力矩阵，并决定 SC-4 第 3 条。
