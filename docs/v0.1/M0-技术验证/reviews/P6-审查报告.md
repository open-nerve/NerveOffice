## 审查者的核对（摘要，审查时的 Chromium 数据）

- **管道成本**：与结果文件一致。
  - 1 MiB 表格合计约 50 ms，5 MiB 约 165 ms；加密不到 1 ms，写入不到 3 ms；
  - Worker 放置下，异步段最长阻塞约 6 ms；
  - 恢复路径合计 26–43 ms。
- **已确认成立的结论**：
  - 进程被杀（Chromium）能恢复到最后一次写入本机的内容；
  - Web Locks 接手在 0–15 ms 内；配额写满时已有记录完好；
  - 修订号冲突与密钥吊销的结果与报告一致；记录调换到别的文档或别的用户都无法解密；
  - "只删到已确认序号"是原子的。
- **V15**：
  - 文字文档不补全就逐字节一致；表格补全后逐字节一致；
  - 公式 Worker 模式下补跑 sheet-core 的重放也逐字节一致；
  - 静态排查抽查成立（样式、批注、区域主题的随机 id，文字文档段落 id 的写回）。
- **V16**：资源 hook 与浏览器一致；20 个样本都到达 Ready、没有错误。
- **对 P1–P5 的影响**：新逻辑只在带新参数时执行；Chromium 回归 319 个全部通过。
- **收尾**：临时用例、构建目录与输出目录都已删除，端口已释放，没有修改已跟踪的文件。

## 修复后的复验

- **功能用例**（`v14-crash`、`v14-locks`、`v14-quota`、`v15-mutation-log`，macOS 26.5.1）：Chromium、Chrome 各 49 个通过；WebKit 47 个通过、2 个按设计跳过（渲染进程崩溃与配额覆盖只能用 CDP）。
- **性能用例**（`v14-pipeline`，单独运行）：修正测试辅助之后，在 macOS 27.0 上三个浏览器各 10 个通过；WebKit 的离群值另做了复跑与诊断（报告 §2.2"WebKit 的离群值"）。
- **配额用例**：修正测试辅助之后，Chromium、Chrome 在 macOS 27.0 上重跑，各 2 个通过。
- **V16**：修复后在 Chromium 上重跑浏览器保存与 Node 加载，结论不变。
- **对 P1–P5 的回归**（修复后；`v03-roundtrip`、`v05-copy`、`v06-open-quiet`、`v09-read-mode`）：
  - Chromium 93 个通过；
  - Chrome 78 个通过、15 个按设计跳过（V03 的 Worker 模式只在 Chromium 上跑）；
  - WebKit：v03、v05、v06 在 macOS 26.5.1 上全部通过（15 个按设计跳过）；V09 跑到一半时桌面会话中断，在 macOS 27.0 上整套补跑，17 个通过、2 个按设计跳过（无头 WebKit 不能读剪贴板）。
  - 修复前 Chromium 上的全量回归 319 个通过。
- **系统升级后的冒烟**：本机在收尾期间升级到 macOS 27.0，WebKit 上"进程被杀之后恢复"的 2 个用例重跑通过，杀掉的进程（用户目录进程与 GPU、网络、渲染 XPC 服务）与恢复结果都与 26.5.1 相同（结果另存 `e2e/results/v14/crash-smoke-macos27/`）。
- **收尾自查发现并处理的两个问题**：
  1. 测试辅助 `edit` 在 P3 大样本上从第二次修改起写入同样的内容，捕获被去重跳过，表格样本的端到端少算了压缩、加密与写入。修正辅助，端到端断言每次捕获都真的写入，三个浏览器重跑（报告 §2.2）。
  2. WebKit 上 5 MiB 表格、发件箱 Worker 放置的端到端偶尔约 2.2 秒，超过 §12.2 的 2 秒。诊断构建把 Worker 往返拆成三段，定位在 Worker 空闲之后的第一次异步操作；Worker 里保持一个空定时器后，40 次都没有出现。写成 M4 的实现要求，登记 DEF-011（报告 §1.2 第 1 条、§2.3 第 11 条）。

## 结论与遗留

**结论：修复后通过。** V14 维持"通过"，并把 R1、R3、G1–G3 的做法写成 M4 的实现要求；V15 维持"可行，建议 v0.1 不纳入"；V16 维持"可行（记录）"。审查提出的 3 个重要问题、6 个一般问题与 8 条建议都已处理。

**遗留**（都已登记，不影响本 Phase 的结论）：

- DEF-009（M4）：真实浏览器的存储行为与断电持久性（含 `strict` 是否真正落盘）。
- DEF-010（v0.2，待 M0 结束评审确认）：mutation 增量日志。
- DEF-011（M4）：WebKit 上发件箱 Worker 的偶发停顿，在真实 Safari 上复核并处理。
- M3：密钥管理（服务端主密钥加密保存、按会话下发、吊销与在线会话的联动）；文档修订号与条件写入。
- M4：本机发件箱按 P6 报告 §1.2 实现，包括写入栅栏、公式待更新与恢复时重算、等锁与待恢复时只读、接手时对齐服务端、"自己追自己"的幂等重试，以及发件箱 Worker 的空定时器（DEF-011）。
