## 与设计的偏差

都已回写 P2 设计（§9 变更记录）、M3 总设计、00 号计划书（r15）或 ADR：

- **模式切换一律重建**（需求方 2026-10-04 决定）：计划书 §6.5、§10.2 与 M3 总设计 §6.5 的"原地切换""先 disposeUnit 再创建"改写（r15），DEF-036 取消。实测切换 p50 0.35–0.43 秒、最大 0.48 秒，内存不随次数增长。
- **查看者也显示谁在编辑**（US-M3-04 的"其他人"）。
- **DEF-040 的范围**：设计只写了编辑器页头，登记的四处平台页面详情一并补上；之后又把全部"第一次就没取到 → 重试"的地方统一（焦点不落到 body）。
- **编辑器页拆成四个文件**（审查 A1 的根因修法）：`edit-mode.ts` 之外有 `editor-slot.ts`、`reading-checks.ts`、`lost-copy.ts`。
- **离开提示的范围**：失去编辑权之后还有没保存的修改时同样提示（延续 P1 审查 B7）；退出的过程中按保存的状态机判断。
- **门禁 `artifacts` 按模块来源核对**（审查 B2）：新的构建元数据 `.vite/module-sources.json`。

## 下一个 Phase 须知

- **P3（保存协议加固）**：
  - 完整的快照校验同样接到另存为副本上（`DocumentConflictCopyService` 现在只做基本校验）；`requestId` 的 advisory lock 排在最前的名单里有另存为副本；304 的实现依赖 Nest 12 发送响应时不重设状态码（集成测试按状态码核对）。
  - 开工时先补 DEF-046、DEF-047（都是平台页面的小项）。
- **P4（自动保存与打开自检）**：
  - Safari 暂停看不见的页面（S1 复核 F1）：窗口被挡住或不在前台时页面一开始就是 hidden，计时器约 6 秒之后停止——心跳随之停止、租约 90 秒后到期（回到前台靠续上）；自动保存要在 `visibilitychange` 变成 hidden 时立即上传，只有几秒。开工前的真实 Safari 复核用 `safari:selftest --front`（窗口要露在外面；这台机器的外接显示器被远程桌面的窗口盖住时同样算看不见）。
  - 自动保存是编辑行为的结果，必须顺延登录，**不能标 `@BackgroundRequest()`**（`routes.test.ts` 锁定带标记的恰好是编辑状态与心跳）；过渡期（P4 之前）一直编辑不保存满空闲期限会掉登录。
  - 每次重建之后 SDK 到 Steady 还要固定的 3 秒（查找等快捷键在那之前不可用，打开页面时同样如此）；捕获时机的设计以 Rendered 之后可以操作为准。
  - 退出编辑等释放至多 5 秒（`EXIT_RELEASE_WAIT_MS`），自动保存的"退出时立即上传"接在 `exit()` 的保存那一步；退出的过程中离开提示按保存的状态机判断。
  - 改编辑器页头的保存状态时一并处理 DEF-045。
- **P5（交接规则）**：本人接管与强制接管要接上 `edit-mode.ts` 的失去编辑权（`lose`）与 `lost-copy.ts`；请求编辑的提示挂在页头（阅读与编辑的页头已拆成 `ReadingControls` 与 `SaveControls`）；释放没确认时阅读页的说法（审查 A13、复验 C4：90 秒时按读到的结果去掉）。
- **接口与约定**：
  - 编辑器只经 `editor-slot.ts` 的 `replace()` 换（单飞：同一个容器至多一个编辑器、至多一次创建在途）；新加的转移照这个做，先开始新的一件事（`begin`）再换，不直接调用 `createSheetEditor`。
  - 阅读时的检查只经 `reading-checks.ts`（带轮次）；页面隐藏、会话不是本人时暂停。
  - 新加的测试专用模块放在 `src/editor/testing/` 或 `src/entries/<测试入口>/`，门禁按来源认；与 E2E 共用的文件加进 lint 的 `SELFTEST_SHARED_FILES`，不引用任何模块（静态、动态都不许）。
  - 前端"第一次就没取到 → 重试"一律用 `useFirstLoadRetry` 与 `RetryButton`，"没能刷新"用 `RefreshProblem` / `DetailRefreshProblem`（带 `fallbackFocus`）；进行中的按钮不卸载（规范 §2.4）。
  - E2E：打开文档用 `openAndEnterEditing`（要编辑）或 `openReader`（只看）；`openEditor` 已去掉。阅读时的定时检查用 `page.clock`（页面的计时器是 `setTimeout` 与 `performance.now`）。
- **已知的坑**：
  - 带图片的粘贴在编辑栏里整次取消（文字也不贴），M5 开放图片时重新评估。
  - 测试构建里平台与编辑器入口的静态引入与生产只差一个 `dist-*.js`（探针带来的 React 与 radix 公共分块，M2-P3 起就有）。
  - 实测命令（`measure:switch`、`measure:memory`）与真实 Safari 的自检要在机器空闲、Safari 窗口露在外面时跑。
  - 主会话在主目录时续上的子 Agent，命令会被 worktree 的隔离检查拒掉：要先回到 worktree 再续上它。
