## 方案与取舍

采用在已有两个 SDK 包间传递 `autoFocusSearch`：编辑联动不自动夺焦，其他来源保持原搜索行为。两包已有共同参数通路和 pnpm 补丁链，不需要宿主全局拦截。

增加输入延时、换成 fill/insertText、全局关闭搜索或反复抢回编辑器焦点，都改变用户输入语义或依赖竞态胜出，不采用。`EditorContainer`、其焦点恢复以及全局焦点协议不改；不增加监督器、通用证据框架或 r10。

## 必须成立的行为

1. 两个包均保持 `1.0.1`。数据验证 UI 的 LIST / MULTIPLE_LIST 分支根据现有 `param.trigger` 传 `autoFocusSearch: param.trigger !== 'editor-bridge'`；没有该 trigger 的显式打开为 true。原其他 ListDropDown 调用不传新属性时默认 true。
2. sheets-ui 的 `IListDropdownProps` 增加 `autoFocusSearch?: boolean`；ListDropDown 原样传到 SelectList，SelectList 缺省 true。搜索 input 的 React `autoFocus` 和零延时 focus 使用同一策略；effect 依赖 showSearch 与该策略，卸载、隐藏搜索或切换策略时清本实例 timer。
3. `showSearch` 继续只控制搜索功能。联动列表仍显示搜索框，用户主动进入搜索后可过滤和选择；显式打开仍可自动聚焦并正常搜索。单选/多选既有值、onChange、关闭语义不变；不改校验、命令、撤销和存储算法。
4. E2E 原 `keyboard.type(value)`、Enter、提示文本及 5,000 ms 断言、历史/保存重开、240,000 ms 案例时限、标题/项目身份、worker/retry 保持。只为下拉非法输入增加有界被动 focusin 断言，不加分段、睡眠或主动纠正焦点。
5. 原留档源码快照、旧补丁副本和冻结证据不覆盖；W 中现有补丁在保留旧 hunks 的基础上受控更新。单元行为 RED 必须是实际组件/manager 的焦点断言失败，导入/夹具错误及纯字符串检查不算。旧 SDK 的宿主新断言只运行一次；若不 RED 据实记录，不循环寻找失败。

## 行为测试设计

组件测试沿用 `data-validation-panel.test.tsx:121–151` 的实际插件登记方式：取得 DataValidationDropdownManagerService 构造器、实际 sheets-ui ComponentManager 注册的 `sheets.dropdown.list`，在 RediContext 中渲染。组合真实 DataValidationDropdownManagerService → 真实 SheetCellDropdownManagerService → 实际 popup.extraProps → 真实 ListDropDown；只替代画布定位/挂载端口和本组不验证的外部计算/命令端口。不得复制 focus 函数、写假的 manager 策略或 mock HTMLElement.focus 为空操作。

焦点 RED 在编辑器夹具已聚焦时，以 editor-bridge 打开 LIST 与 MULTIPLE_LIST；从 React 提交前记录 focusin 到有界 timer 推进结束，断言搜索从未取焦、编辑器焦点保留。只看最后 activeElement 会漏掉本次实际竞争。显式入口和缺省调用验证搜索聚焦、过滤、选择；联动列表允许后续用户主动进入搜索；关闭、隐藏搜索、策略切换取消旧 timer，移除节点的迟到 focus 还要用调用原实现的 spy 检查。真实浏览器字符、持久值、历史与重开仍由原 E2E 负责。

E2E 观测只在 `example.type === 'list'` 的非法输入窗口启用：原 selectAddress(C3) 完成后、原 keyboard.type 之前安装，延续至原拒绝提示可见和文本断言完成后封存。记录该 document 中 `[data-u-comp="sheets-dropdown-list"] input` 的 focusin；最多 16 条、序列化快照最多 4 KiB、最长 15,000 ms，超限/过期标记使断言失败。记录相对时间和固定目标标记，不抓整页文本、stack、env 或登录数据；窗口内没有主动点击搜索，不能用 isTrusted 排除程序 focus。

原故事后半段照常执行，最终核各窗口 events 为空且无 overflow/expired；失败/异常在 finally 移除监听与计时器、保留有界附件。document/JS handle 已失效属于取证失败，不能回退成空列表通过。观测状态只在测试当前 document 内存，页面关闭或 finish 后释放，无产品探针或常驻服务。

小型 helper 将同一自包含 DOM 安装函数交给 page.evaluateHandle；单元校准执行这个实际函数，替换的仅是 document/时钟/页面 handle 边界。覆盖事件数上限与快照字节限额、过期、finish 重复调用与解除监听、页面 handle 异常传播。它不模拟 SDK 取焦，不能充当产品 RED；产品焦点仍由前述真实组件和页面证明。
