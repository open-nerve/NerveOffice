# P3-S3 数据验证生命周期与 Ready 路径

状态：已实现并完成 S3 定向验收；P3 阶段验收待办。日期：2026-10-21。代码基线：`f4c9bed4797a1ad05d58582ef939d444e8593415`。

## 1. 行为与范围

打开含非当前工作表数据验证的文档后，退出、阅读/编辑重建或打开自检失败，都必须终止旧实例的校验工作。旧工作簿或工作表销毁后，即使同 id 已被重新使用，旧任务也不能校验新表、读写新缓存或发送归属于新表的结果。

正常文档仍按既有 Rendered 与后续脏区调度执行数据验证，返回原 VALID/INVALID 语义；合并单元格和公开的单格、范围、工作表、工作簿校验方法保持。真实计算错误必须能被调用方或诊断通道观察，不能被当作“有效”或普通取消。退出时取消是预期结果，不制造未处理的 Promise 拒绝。

本 Step 处理 DEF-056，并准确复核 DEF-057 的 formula 路径。P2 已修复 drawing Ready 等待，不重做。固定 Univer 1.0.1、原保存协议、数据格式和浏览器范围保持。

## 2. 当前发布包事实

- `SheetsDataValidationValidatorService` 在 Rendered 前缓冲脏区，之后每 20 ms 合批；非当前表使用裸 `requestIdleCallback`，不记录/取消句柄，两条调度分支都不处理校验 Promise。
- `validatorRanges` 与 `validatorWorksheet` 在 await 后仍按字符串 id 读取或创建缓存；需要核对最初的 Workbook/Worksheet 对象身份。
- `SheetDataValidationModel.validator` 在异步 validator 返回后写缓存并发送状态，既无归属复核，也没有失败通道。仅取消 idle 句柄不能覆盖已经开始的计算；必须以实际模型反例决定补丁。
- 插件在 onStarting 直接登记两个类，未提供稳定服务替换配置。复刻插件会扩大维护面，因此在确认反例后使用登记的最小发布包补丁，ES/CJS/声明同步。
- `RegisterOtherFormulaService` 仍存在 `onStage(Ready).then` 的拒绝旁支；现有 UR-031 只证明直接调用反例，不能当作默认 Worker/主线程产品路径复现。

## 3. 所有权与错误边界

每份异步工作属于最初的 Workbook、Worksheet 对象和所属服务实例，不能只核对 id 是否存在。归属在排队前建立，在回调执行前和每个异步续体读取/写入前复核；Rendered 前及后续合批的脏区也不得从旧表转移到同 id 新表。

同一表对象内也要区分单元格的计算代次。值或规则失效时立即取消该格旧计算，不等 20 ms 合批或下一次计算开始；旧成功、旧失败都不能覆盖新格的 INVALID/VALIDATING，也不能恢复已删除规则的状态。仅取消覆盖脏区的任务，邻格仍照常返回结果。

尚未执行的空闲任务随实例/工作簿退役取消；已经开始的计算在退役后停止发布结果，其调用方得到明确的取消结果。取消不能伪造 VALID，也不能让服务的等待 Promise 永久悬挂。正常计算的同步异常与 Promise 拒绝都必须传回服务调用方；后台调度接住预期取消，其他错误明确报告。若旧同步模型接口需要保持返回值，增加向后兼容的可选失败回调，原调用方不传时仍明确报告真实错误。

调用方等待与共享模型分开归属：单独销毁 service 终结该服务的等待，仍活跃的模型可继续维护原表缓存；完整实例退役同时结束模型工作。计算在取消后才真实拒绝时，通过诊断通道报告原错误一次，不恢复已取消的等待；只有实际取消错误可以静默，不以“实例已经销毁”代替错误分类。底层公式计算没有提供取消接口，不承诺终止其 Promise。

失败后不能永久残留 VALIDATING 而阻止下一次真实校验。成功、失败和取消均清理本次任务记录；退役后的真实结果不再修改旧/新缓存或发状态事件。全局 Promise/console 过滤、忽略任意 Error、延时销毁、改重试/预算不属于可接受方案。

## 4. 证据与验收

1. 真实发布服务与模型、真实 Workbook/Worksheet/LifecycleService，窄控制空闲调度器与计算 Promise。先观察失败，再实施；不复制待测算法。
2. 初始 Rendered 和后续脏区；实例销毁、工作簿销毁、工作表移除、同 id 重建、已入队/已开始两类时机；错误不能写新表或产生迟到事件。
3. 正常有效/无效、合并区域和公开四类校验方法；普通函数同步 throw、异步拒绝及失败后可重试；同格新旧计算、合批空隙、规则删除与邻格对照；退役前拒绝但尚未处理、退役后拒绝均保留一次真实诊断；关键所有权/取消/错误分支有有效变异。

6. 相关单元、三浏览器兼容、类型/lint/构建/补丁门禁通过；独立审查、ADR/DEF/上游草稿与复核记录同步。S3 完成不代表整个 P3 验收或上游 issue 已发布。
