## 1. 目标与完成边界

让选文件、按键粘贴、右键粘贴、Finder 拖放与真实图片复制走同一套平台输入规则。用户粘贴 Excel 表格时保留表格；复制图片时取得当前选中的图片，不复制探针中的固定首图。上传、读取、权限、焦点或系统许可失败都有明确结果，普通文字和表格编辑继续可用。

本 Step 实现正式适配代码和受控测试接线。生产菜单与命令仍维持关闭，只有测试构建的显式开关可以用于验证该适配；S5 才开放正式入口。真实 Finder、Excel、获准 Chrome 右键粘贴三项必须全部有原件，S4 才可完成。环境未提供时保留未完成状态，继续独立任务，不用合成输入替代。

不改变 sheet@1、API/保存/资源授权、SDK 版本或支持浏览器；不加入远程抓图、离线上传、任意附件或文字文档图片功能。已有图片 IO、命令清洗、历史与受限快照位置沿用 S1–S3。

## 2. 固定包事实与方案取舍

- 1.0.1 的图片文件对话框列表含 BMP、缺 WebP；平台支持 PNG/JPEG/WebP/GIF，必须由平台控制文件选择的 accept 与上传前校验。原单次文件数量上限为 10。
- `SheetClipboardService.legacyPaste` 与 `paste` 仅在 HTML 被旧 `htmlContainsImage` 识别时优先文件。浏览器复制图片的 HTML 与二进制会走错分支；真实表格与图片文件并存时又必须保留表格。
- 浮图复制的 SDK hook 对 URL 图片在 200 ms 后写空文本；hook 依次全部调用后才合并布尔值，提高自定义 hook 优先级不能阻止它。不能用 350 ms 延迟补写作为产品方案。
- core 的 MultiCommand 按优先级串行选择实现，返回 false 会继续下一个实现。平台接管后的失败必须终止该条路径，不能跌回上述 SDK 行为；通过已存在的自定义命令错误终止，由外层返回 false。
- 原 paste 命令在读取剪贴板前捕获目标，并再次检查权限。平台适配同样在任何异步操作前固定书、表、选区和身份；读完后再次核对。
- S2 的 `IURLImageService.downloadImage` 每次重新鉴权、验证解码并返回原字节，失败拒绝，不交出占位。复制复用这条路径；画布转 PNG 只处理这些受管原件。

2026-10-19 原生补证追加固定包事实：桌面右键菜单先执行命令后恢复焦点，无法满足宿主焦点边界。沿 ADR-022 增加 ui 1.0.1 最小 ES 修复，在同一 scope 内先同步归还焦点再执行命令；不放宽宿主输入框或文字编辑排除规则。真实反例与复验见 [Chrome 原生复核](../reviews/P2-S4-Chrome原生补证与右键修复.md)。

选择平台纯输入分类、集中 SDK 桥接、系统事件控制三层。复制和右键粘贴使用集中登记的命令接管；表格/文字仍委托既有 SDK 处理。按键粘贴与拖放只接管目标编辑器内的图片输入，正常表格保持原事件路径。避免修改全局浏览器 API、私有 hook 数组或另外实现表格剪贴板协议。

## 3. 输入分类与预算

### 3.1 文件

每张 1 字节至 5 MiB，扩展名大小写按既有契约规范化，MIME 与后缀必须匹配 PNG、JPG/JPEG、WebP、GIF。在读取任何文件字节前检查整批元信息；一次最多 10 张，与固定 SDK 的现有上限一致。数量、格式、大小不合格时整批不上传。格式真实性继续由服务端解码判断。

SDK 与宿主共用同一个元信息函数，保留现有上传错误语义。剪贴板 Blob 使用平台自定的无用户信息名称和准确后缀；原文件名不进入请求、日志或错误。文件逐张串行处理，减少瞬时资源占用；已成功插入后的后续网络失败要明确报告，不能谎称整批成功或悄悄重传。

### 3.2 HTML、文字与文件并存

分类只能使用本次用户操作提供的数据，页面启动、焦点变化和后台轮询均不读系统剪贴板。

| 本次数据 | 路径 |
|---|---|
| HTML 中有实际 table 单元格结构，即使同时附图片文件 | 保留原表格 HTML、文字和公式剪贴板数据，交原 SDK 表格路径；不上传附带的预览图 |
| 无表格结构，有合法图片文件 | 图片路径；忽略图片旁的网页地址/外链 HTML，不据此抓取图片 |
| 无图片文件，普通文字或 HTML/SDK 表格片段 | 原 SDK 路径；S3 的写入规则继续兜底；不主动下载 HTML img 的来源 |
| 只有 HTML 图片而无可用图片文件/表格内容 | 明确提示改用“复制图片”或选文件；不声称已插入 |
| 仅不支持的文件或图片数量/格式/大小不合格 | 可见失败，不修改正文或上传 |

判断真实标签用未连接页面的惰性 HTML 容器；不执行脚本、不连接图片节点、不由分类触发请求。分类 HTML 上限 1 MiB（UTF-16 代码单元）；超过时不解析，也不猜它是图片，保留 SDK 原表格/文字路径，禁止因此接管文件并丢弃表格。普通大表格不被图片分类器新增拒绝。

委托带文件的表格时，保留 HTML、文字、公式专用数据与固定目标，但不把预览文件交回 SDK。固定包的 `htmlContainsImage` 会把表格单元格内的 data:image 预览也当成纯图片；原样放回事件仍会丢表格，必须在真实 SDK 回归中覆盖这一组合。

## 4. 焦点、目标与生命周期

内部桥接只向 images 层提供有限事实：当前书/表/选区、是否正在文字编辑、实际图片选集、当前读写/复制许可与操作期间是否仍为同一目标。不把 SDK 服务、模型或可写引用传给 feature/shared。

- 普通画布选区可接收图片；编辑栏、单元格文字编辑、名称框、查找框、批注和宿主输入控件不能触发图片上传。文字粘贴保留原流程。
- 事件必须属于目标编辑器。剪贴板命令核对当前 SDK 焦点与宿主焦点，不能凭遗留的图片选集中途接管别的输入框的复制。
- 文件对话框、剪贴板读取、上传、解码之前固定目标。切书、切表、选区改变、身份/权限失效、断网或销毁后取消；不能把迟到图片插到新的选区。
- 只读和离线输入在读取文件/上传之前拒绝；不影响只读复制已授权内容。复制仍要重新鉴权，离线无法取得原图时失败，不导出占位。
- 同一实例一次只进行一项图片输入任务；再次触发给出忙碌反馈，不创建重复上传。取消和销毁释放监听、控制器、图片元素及临时地址。

## 5. 系统复制与粘贴

### 5.1 复制

只有焦点属于当前表格且明确选中单张浮图或单张单元格图片时接管系统图片复制。多选或混合对象不能静默选第一张：明确提示先选择一张图片，保留原选集和内容。普通表格区域的复制继续走 SDK，区域内图片/内部片段仍受 S3 规则保护。

在命令的同步用户操作阶段调用 `navigator.clipboard.write`，以 `ClipboardItem` 的 PNG Promise 承载后续鉴权读取与编码。后续代码不可再向剪贴板写空文本。写入成功必须由外部受控接收方粘贴的实际像素证明，API Promise fulfilled 不能独自作验收。

PNG 直接使用有效 PNG 字节；其他格式用受管解码原件转换 PNG，遵守既有尺寸/像素上限，导出最多 5 MiB，编码有 10 秒上限。GIF 系统复制为 PNG 静态图，不新增动画剪贴板承诺。任务结束后释放解码资源，转换或写入失败可重试。

选中图片的剪切走同一系统写入，只有写成功、对象/目标/权限仍有效时才执行正常删除命令；失败或取消不删除图片。不得沿 SDK 的“先删除再延迟复制”路径丢内容。

### 5.2 粘贴与拖放

按键粘贴使用该次可信 paste 事件携带的数据；右键粘贴在用户命令同步阶段调用系统 read，处理许可拒绝、空值、取消、格式与再次尝试。实际表格委托原 SDK，并保留自定义公式剪贴板数据及捕获的目标，不复制一套表格粘贴实现。

Finder 文件拖入编辑器时，在 dragover/drop 的同步阶段阻止文件默认导航；捕获合法文件后走相同输入流程。编辑器外的动作不接管。只读、文字编辑、格式失败等拒绝路径同样不能先导航再报告；纯文字或链接拖动不作为图片上传。

## 6. 失败反馈与受控接线

复用编辑器顶部现有状态区域的布局，新增图片操作状态，区分忙碌、取消、上传/复制/粘贴失败及输入不支持；不把它们写成“图片加载失败”，不让重载图片按钮假装重试系统剪贴板。可见说明不包含文件名、原始 HTML、来源地址或异常堆栈。下一次用户操作可以重试；页面原会话错误处理继续有效。

正式开关继续关闭。测试开关只存在于 e2e 动态模块，允许安装相同适配、显示必要测试入口；生产模块扫描须证明开关和探针被移除。背景图片、文档图片与超链接入口继续按原范围受控。

## 7. 验证与原生矩阵

- 纯分类：四格式、后缀/MIME/大小/数量；文件加表格 HTML、img 包装 HTML、空值、超长 HTML、伪标签文本/注释；分类无网络和副作用。
- 实际 SDK：焦点、命令优先级、接管失败不回落、单张/多选、普通区域复制；真实修改/undo/redo；失效目标不写；上传前文字编辑拒绝。
- 浏览器：Chromium/Chrome/WebKit 上真实输入适配、插入像素/保存重开、PNG/GIF/WebP/JPEG、失败后普通编辑保存；两条粘贴入口和复制结果。合成数据明确标 synthetic。
- 原生 Safari/Chrome：自制 Finder 文件的默认路径及宿主拦截路径；真实 Excel 自有表格的 MIME/HTML 和单元格结果；Chrome 右键许可后的成功、拒绝、重试；Safari 一次性粘贴提示后的成功或准确失败说明；真实同步复制到另一文档和外部受控接收方。
- 每次原生记录绑定构建/锁文件/来源摘要、可信事件或明确 UI 操作、输入前后状态与实际像素。Safari 开始前解锁、空闲 120 秒，测试中非测试活动使该轮作废。只使用任务样本，不读取用户原剪贴板。
- 完整 Phase verify/容器/同 SHA CI 仍在 S6；任何三项原生缺口不能标为已通过或提前开放入口。
