## 已形成的工程能力

- 每个编辑器实例拥有图片请求、解码与清理；身份、权限和退役变化取消旧任务并清图。生产入口通过实际 SDK 桥接，不依赖测试面板。
- PNG/JPEG/WebP/GIF 可作为浮图或单元格图片插入，支持撤销重做、保存重开；单图复制、受控粘贴/拖放和当前文档副本沿平台资源授权。
- IMAGE 来源在定义名称展开之前及运行期 AST 两处核对；图片来源与普通表格剪贴板分开判断，普通离线复制/剪切/粘贴保持可用。
- 固定 Univer 1.0.1 的九份局部补丁覆盖实际 IO、坏图绘制、自动行高、drawing 取消和右键焦点等路径；升级时按 ADR-022 的实际入口与行为回归逐项判断移除，不修改只读 refer/univer。
- 上传大小、类型、内容与配额拒绝有固定反馈；不把失败原因、任意服务端文本或文件名直接搬入页面。
