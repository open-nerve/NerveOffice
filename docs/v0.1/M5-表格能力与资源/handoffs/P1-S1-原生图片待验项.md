## 已验证的输入约束

网页复制图片会同时给 HTML 和 PNG，默认 SDK 丢图；Finder PNG/GIF 可插入；受控 HTML 表格保持单元格；BASE64 浮图可复制到另一页；同源 URL 的默认复制丢图。延迟350ms补救在 Safari 被拒绝，同步原生按键接管后两浏览器均能在另一页粘贴 PNG。

正式复制适配必须判图片/单元格/编辑栏焦点，保留用户激活、防止 SDK 随后清空，并处理异步权限和写入失败。探针只复制唯一受控首图，不能直接迁入产品。Safari 右键选择一次性系统粘贴后仍未新增图片，API 内部读取内容未捕获，P2 仍需定位并修正正式路径。
