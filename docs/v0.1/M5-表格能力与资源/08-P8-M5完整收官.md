## 3. 设计

### 3.1 Q-10 收紧（S2）

- `open_paths` 只接受退出码 0 且 stderr 为空，退出码 1 一律判不完整、保留资源。
- `lsof_exit_sample` 与 CI 注解保留，作为新环境的观测。托管 Mac 不经 CI 资源核对，改由 `ci_mac_probe.py` 在 job 开始与结束时按运行器直接模式的同一条命令采样；门禁里真出现退出码 1，会写进本轮台账的 `cleanupError`。
- 单测改为三种情形：退出码 0 接受；退出码 1 且 stderr 为空判不完整；有警告判不完整。
- 资源规范与 P7 记录的 Q-10 结论同步。

### 3.2 托管例外（S2）

`hosted.py` 里 workflow_dispatch 的精确分支，由已退役的 `refs/heads/m5-p7-review-fixes` 改为 `refs/heads/m5-p8-final-closeout`。仓库、工作流文件与精确 ref 的其余条件不变，仍不是通用分支白名单。ADR-026 补 P8 附录。

### 3.3 托管 Mac 探测（S3）

新增 `.github/workflows/mac.yml`：

- **触发**：
  - push 到本分支，这是合并前唯一可行的方式（见 §2）；
  - workflow_dispatch，合并后可手动触发。
  - 不随 main 推送运行，不改 `ci.yml` 的原六项。
- **探测 job**：`macos-26`、`macos-26-intel` 各一个。只收集环境事实，不跑产品测试、不经运行器，结果不作验收证据。
- **探测内容**：
  - 系统、机型、CPU、内存与可用磁盘；
  - 图形会话与登录钥匙串的状态；
  - lsof 全量列举在普通权限与 sudo 下的退出码与 stderr 字节数；
  - Docker 能否启动（Intel 版尝试 colima）；
  - Homebrew 的 PostgreSQL 版本，以及能否启动；
  - Node、pnpm 与依赖安装的耗时和占用；
  - Playwright 三个浏览器的安装，以及最小启动核对：启动后打开空白页并截图（空白页拿不到 OPFS；OPFS 与 WebCrypto 由门禁里的 E2E 覆盖）；
  - safaridriver 能否启用。
- **结果输出**：写成 notice 注解，公开接口可读。
- **固定方式**：与 `ci.yml` 相同，Action 按提交 SHA 锁定，pnpm 版本与 `packageManager` 一致。

### 3.4 托管 Mac 上的原完整门禁（S4、S5，取决于探测）

探测可行时，先写 `plans/P8-S4-托管Mac门禁.md` 再实施。原则如下：

- **范围不变**：跑交接单所列的 Mac 原完整范围，即 `pnpm verify` 的全部步骤，以及本机 Chromium、Chrome、WebKit 与崩溃、重启项目。原步骤、用例、断言、重试判失败与覆盖率都不变。
- **数据库**：使用与 CI 同一大版本的 PostgreSQL，写明并核对版本与来源。
- **资源工具**：探测之后改为照开发机的严格本机模式运行（S4 计划 §2）。不设 `CI` 与托管 VM 资源策略，真实删除并核对；比方案 B 的“待宿主回收”更严，也就不需要为托管 Mac 另立合同，Linux 合同不变。
- **规格不足就停**：托管 Mac 的内存、磁盘或时长装不下原范围时，停下汇报，不改断言、时限或范围求通过。
- **生产容器组合**：Intel 版能起 Docker 就在上面跑，否则停下请需求方决定。探测结果：Intel 版能用 colima 起 Docker，Apple 芯片版不能，因此验收环境选 Intel 版。
- **分片**：本机模式的 `--scope` 分片，两片各自先启动开发数据库，合起来恰好是本机完整门禁；另加生产容器 E2E。详见 [S4 计划](plans/P8-S4-托管Mac门禁.md)。

### 3.5 原生交互补验（S6）

先写 `plans/P8-S6-原生交互补验.md`，内容包括：

- 查出的产品缺陷按根因修复并补回归。

## 7. 风险与未决问题

- **规格**：托管 Mac 只有 7 GB 内存、保证 14 GB 磁盘，可能装不下原完整门禁。ESLint 单独要 6 GiB 上限，运行器在可用磁盘低于 12 GiB 时停止。Intel 版内存较多，但架构不同。
- **没有 Docker**：PostgreSQL 要改为本机进程；生产容器组合可能需要另定。
- **托管 Mac 的会话**：图形会话、钥匙串与 safaridriver 的行为未知，以探测为准。
- **原生交互**：需要需求方的时间；ToDesk 远程操作算不算可信动作，待验证。
- **标签前的裁决**：Excel，以及其他仍未验证的范围。
