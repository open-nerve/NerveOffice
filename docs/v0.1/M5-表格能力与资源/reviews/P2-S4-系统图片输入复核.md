## 实现与审查

共用四格式、1 字节至 5 MiB、最多 10 张的整批预检；不合格时零字节读取和上传。实际表格 HTML 优先保留，附带预览不上传；普通零文件事件留给 SDK，公式剪贴板表示保持。惰性分类解析不发图片或脚本请求。

图片输入绑定实际书、表、选区、图像、DOM/SDK 焦点、用户和许可。宿主输入框或编辑栏不会因遗留图像选集而被劫持。切换目标、取消、撤权、断网、销毁后不迟到写入。上传、文件选择、paste、右键 read、drop 共用正式任务、IO 与正常 SDK 命令/历史。

系统复制在同步用户动作内发起 write，以 PNG Promise 承载鉴权读取和编码，图片接管失败终止旧 SDK 回落，避免其后空文本写入。剪切只在系统写成功且对象仍有效时正常删除。失败、忙碌与取消通过页面状态说明；身份/CSRF 错误复用原会话复核。测试入口仅在 e2e 动态模块开启，没有协议、快照、数据库、SDK 版本或补丁变化。

独立同模型报告位于主目录 `.codex/handoffs/m5-p2-20261019/s4/`：`task1-review.md`、`task2-full-review.md`、`task3-core-review.md`、`task3-wiring-review.md`、`task3-browser-review.md`、`read-only-fixture-review.md`。已确认问题均有反例与修复闭环；当前已审 Task 1–3 范围内无未关闭 Critical/Important/Minor。该结论不包含尚未执行的原生验证。

## 测试修正的根因与边界

WebKit JPEG 的原始比较失败来自 Sharp/libvips 和 WebKit 解码差异；同一服务端原件经独立 WebKit Image/Canvas 解码，与实际导出 PNG 的 6144 通道值完全相等。PNG 仍按字节比较，其他格式按当前浏览器独立原件解码像素严格比较，没有容差或产品转换器修改。宿主焦点复制哨兵记录全部 write/writeText 并等待 SDK 的迟到窗口，不能只查 image/png 调用。

旧共用只读样本仍使用 data: 图片，被 S3 来源规则先行拒绝，权限和正常编辑对照到不了原 SDK 路径。准备阶段通过作者独立 API 会话上传原样本、正常保存建立引用，初始修订固定为 2。只读零修改/零保存与历史检查保持；旧原始样本和非法来源反例保留。

change-detection 的移图、缩放、删图、复制工作表也必须使用合法样本。保留原逐动作/捕获/静默检查，末端只显式保存一次，以同次 flush 的 requestId 关联实际 HTTP 200，要求最终 editorSeq、完整正文和修订恰为 3。正文比较沿用既有语义，只排除视图状态和语义为空资源。中途测试把 editorSeq 与请求 contentSeq/localSeq 混比的失败保留在 final04；修正没有放宽正文或修订断言。

新增内部 API 登记使旧 lint 自测中“未登记类型”的样例失效。样例改为固定 SDK 实际导出的未登记符号，并加上已登记类型必须被拦截的断言；内部 API 清单、公开值白名单、豁免范围均未放宽。final02 的 4 项失败、final03 格式失败、final04 序号断言失败均保留，最终通过见 final05。
