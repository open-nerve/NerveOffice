# P2-S1 平台图片请求复核

> 日期：2026-10-19｜状态：实现与定向验证完成；作者自审，整 Phase 独立审查尚未进行。

新增 `shared/assets/asset-api.ts`，只处理平台原始字节上传和有界读取。复用现有 CSRF、会话归属、30 秒时限与取消；请求层只增加可选 `no-store` 和禁止重定向。没有 SDK 接线、解码缓存、用户入口或后端授权变更。

上传检查字节及四格式/后缀，响应用既有契约核对，不发送原文件名、不自动重试。读取只接规范相对地址，HTTP 与 X-Asset-Status 都必须明确成功；占位、部分响应、空正文和不支持类型均失败。实际流按 5 MiB 限制并取消超额/未使用正文，断流是网络失败。增长缓冲立即复制收到的字节，不保留任意数量的小块引用，也不受源流复用缓冲影响。

## 边界

这里的 Response/ReadableStream 用于验证字节与请求协议，不冒充真实浏览器像素解码、Safari、Excel 或拖放证据。SDK 的两条图片读取路径、权限重核/旧图清理、失败后画布持续绘制仍由 S2 证明；三个原生缺口及正式入口守卫保持。整 Phase 完整门禁、生产容器、同 SHA CI 与独立审查尚未执行。
