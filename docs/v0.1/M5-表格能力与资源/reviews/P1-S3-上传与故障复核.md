# P1-S3 上传与故障复核

> 2026-10-18；S3 Task 6 实现者自审与真实 HTTP、PostgreSQL、文件和进程验证。整阶段独立审查仍在 S6，本文不代表 P1 或前端图片入口已验收。

## 实现与保持的契约

`POST /api/assets` 已接入会话、CSRF 和 Origin 守卫，读取原始二进制。守卫通过后只装配延迟 reader，取得图片执行名额才开始缓存正文；等待请求不缓存正文。错误媒体、编码、后缀、空体、格式伪装和超限按既定契约返回，响应不含物理摘要或路径。四种格式均经正式一次性处理进程，而非探针实现。

0027 迁移新增 `asset_quota`、`asset_object_claims`、`asset_objects`、`assets`。预留与转正分别使用短事务，先锁配额单行；文件发布在两次事务之间。相同对象只计一次物理字节，每次上传建立独立 assetId 并计一次条数。第二次事务失败或提交回执不确定时，不撤销已提交预留、不删除完整文件。重试可复用同一预留/对象，不能借失败绕过配额。

两次事务在取得锁并完成本次写入后，都通过既有 `SessionService.requireActive` 复核会话。慢传、处理、文件写入或等锁期间已提交的退出/撤销使当前事务回滚；核对之后发生的撤销沿用 ADR-017/018 的线性化边界。文件写好后退出不建立 asset，已收费的预留和文件保留，新的有效登录可以恢复它。

客户端断开、排队取消、进程关闭均传播取消信号。应用开始排空在途请求时就通知上传服务，避免等到模块销毁才中断慢传。子进程回收后才释放执行槽；慢传/繁忙/取消后下一次正常请求能够成功。

## 临时文件恢复与启动

正式上传 `.tmp` 的 UUID 通过数据库已有 `ExclusiveRunner` 占用会话级 advisory lock；不持数据库事务或配额行锁做文件 IO。每次发布前尝试清理旧 UUID，仍有占用者的文件保留；无人占用时只删除私有普通临时文件并同步 staging。正式对象与持久预留不自动删除。同一卷必须属于同一数据库的一组应用实例。

真实 SIGKILL 覆盖 hard link 前、后两个断点：完整对象有或没有，都保留收费预留；重新启动并上传后清掉旧临时文件、复用原字节占用。另一个实例实际执行上传时会跳过活跃任务的临时文件。只断开占用连接、保留旧业务任务的交错也已测试：新实例能清理并成功发布，旧任务失去路径后失败，不能覆盖已恢复的对象。

自审发现数据库不可达时，启动回收原本会阻止整个应用初始化，破坏已有 `live=200 / ready=503` 契约。已有真实健康检查复现失败后，启动改为独立验证目录、权限、实际写入/fsync 与进程硬限制；只清理独立 `.probe`。probe 独占创建后先 unlink，再用已打开句柄写入与同步，从不参与对象发布；另一初始化清掉其名字也不影响探针。上传 `.tmp` 留到下一次发布时按数据库占用回收，未回收期间仍由持久配额覆盖。

`NERVE_ASSET_ROOT` 现在是服务端必填，迁移及运维 CLI 不要求它。启动前按真实祖先核对资源根与前端根互不包含（包括前端根为符号链接）；随后 FileStorage 拒绝非私有权限和资源路径符号链接。测试目录独立创建，随隔离库销毁。开发运行方式已写入部署说明；Compose 私有卷和镜像原生源码分发仍由 S6 完成。

## 失败证据与局部裁决

- 仓储最初不存在的 RED 见 `task6-quota-red-02.log`。更早一轮测试凭据用错导致连接失败，只记录为驱动问题，不当作产品 RED。
- 慢传中退出的 RED 实际返回 201，修复后返回 401 SESSION_EXPIRED；文件发布后撤销同样回滚转正。原件 `task6-revocation-red.log` 与 `task6-revocation-green-01.log`。
- 健康检查 RED 见 `task6-health-red.log`，FS 的数据库不可用 RED 见 `task6-probe-red.log`；22 项 FS GREEN 与最新全量集成均覆盖修复。
- 迁移约束首轮把 `ON DELETE RESTRICT` 的 SQLSTATE 误写为 23503；实际是 23001。保留生产 RESTRICT，改正测试并核对约束名。旧失败记录 `task6-integration-01.log` 保留，未作为通过回执。
- 采用延迟 reader 而非排队时缓存：1+4 限制的是在途任务，只有执行槽读取正文。接口与错误契约不变。
- 跨实例临时占用复用已有数据库会话锁，不新增锁服务或持事务做 IO；启动探针与上传任务分别处理，保持现有服务存活契约。
