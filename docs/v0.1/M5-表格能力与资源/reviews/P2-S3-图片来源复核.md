# P2-S3 图片来源与保存定位复核

> 日期：2026-10-19｜状态：S3 实现、组合回归、冷安装与独立审查完成。正式图片入口保持关闭，完整 Phase 门禁留在 S6。

## 实现与边界

IMAGE 在实际词法树、定义名称展开前证明平台地址来自字符串字面量；准确映射展开后调用位置，运行期 AST 和求值字符串再次核对。包装继续调用原 IMAGE 处理其余参数与错误；直接 calculate、引用、拼接、数组、函数和名称值均不能充当已证明字面量。注册时失效实际含 IMAGE 的 AST 缓存，保留无关 SUM 缓存。固定 engine-formula 补丁、清单和锁文件同步，未升级 SDK 或修改 sheet@1。

图片相关命令在写入前归一 source/base64Cache，混合批次先完整检查再提交；底层 JSON1 预演同时检查两个 drawing 服务，拒绝原地修改的 TextX。结构命令按真实目标预检，Undo/Redo 在首条 mutation 前检查整条历史。旧坏图删除是绑定实例、权限和对象版本的一次确认事务，成功后才清当前 workbook 的历史；S3 不开放该入口。不对普通键入捕获整份快照，不扫描普通 v/f。

后端在原有受限子进程的图片扫描中携带有限结构上下文，沿既有资源解析和 IPC 返回最多五项位置，原 source 判定与规则顺序保持。保存和副本共用检查；拒绝时内容、修订、引用和文档数不变。位置不进入日志，响应不回显来源、正文、名称或文件名。页面经当前编辑器实例只读查询工作表名称，保存/副本复用格式化器；旧响应、异常位置、无实例及非字符串名称均回退。

## 审查与发现

同模型独立审查者 `/root/m5_p2_s2_review` 只读检查 S3 最终实现、实际固定包、测试与浏览器原件；详细报告为 `task2-boundary-review.md`、`task3-review.md`、`task4-final-review.md`。审查者未执行测试，运行结论由主 Agent 核验。Task 2 的结构目标、双服务操作路径、清理确认及后续通知失败等问题已有行为反例并修复；Task 3 的非字符串名称问题以实际 SDK 插表接受 null 的事实补齐两层回退。

最终相关浏览器回归发现一项 Important：普通文字粘贴后 Enter 提交被图片规则取消。`browser-related-01/` 为 63 通过、6 失败，失败恰为两条正常粘贴故事 × 三浏览器。根因是 SDK 的富文本 pageSize 以 Infinity 表示无限画布，而图片片段清洗误将其视为非法结构。真实 `createDocumentModelWithStyle` 及实际写入命令先 RED 后 GREEN；修复仅保留普通数值，不改变来源规则、遍历预算或 JSON1 纯操作校验。最终 81 项组合浏览器中，原六项失败全部通过；独立审查核对归档原件和源码摘要后关闭 T4-1，无剩余可行动产品发现。

首轮新增浏览器的九项失败另属测试写法：六项 IMAGE 参数漏了 SDK 的 altText 位置且模式值错误，三项精确文本遗漏已有“保存失败：”前缀。原件在 `browser-01/`；只修测试，第二轮 12 项通过。Task 3 名称事实测试的早期夹具失败亦保留，不能记作产品缺陷或最终通过。

### lint 误扫辅助副本

初始全仓 lint 耗尽既有 6 GiB，分工程实验虽完成六个工作区，根补集仍 OOM。实际 ESLint `isPathIgnored` 与 Git 的对照查明：`.superpowers/sdd` 中约 122 MiB 的 S2/S3 SDK 解包副本由嵌套 `.gitignore` 排除，却仍被 ESLint 扫描。不能继续把本次根因写成生产代码规模或类型图容量不足。

将整个辅助目录迁至本轮 `auxiliary-superpowers/`，3,402 个文件、118,173,566 字节迁前迁后摘要一致；`auxiliary-relocation.json` 和 pnpm 编辑 state/路径映射保留原件位置。迁移后原始 `pnpm lint` 在原 6 GiB、原规则/文件范围下退出 0，耗时 118.710 秒。临时分批入口和三个工具文件全部撤回，实验源码及两轮失败日志保存在 `lint-batching-experiment/` 和原日志中。实验的 LINT-1 目录参数 Minor 随方案撤回，不记为修复上线。独立核验见 `task4-lint-review.md`。

最终提交的产品源码与相关回归/冷安装清单保持一致；收尾只补本报告、进度和辅助材料放置约定。提交回执另保存 Git 提交、钩子结果与最终文件摘要。
