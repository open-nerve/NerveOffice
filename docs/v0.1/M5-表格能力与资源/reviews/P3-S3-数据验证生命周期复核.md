## 交付行为

固定 Univer 1.0.1 数据验证的异步任务属于最初的 Workbook/Worksheet。Rendered 前后的脏区在合批前捕获对象，非当前表的 idle 任务在工作簿或服务退役时取消；迟到回调再复核归属，不按同 id 找新表。初始缓冲在 Rendered 之后退订。

已经开始的模型计算在模型/工作簿退役、工作表删除或本格值/规则失效时结束旧等待。按 Worksheet 和单元格索引待办，脏区发出时立即取消，不等下一轮调度；旧成功不能覆盖新结果，旧失败不能删除新 INVALID/VALIDATING，邻格继续正常计算。范围/工作表的 await 后再核对原对象，不能取得同 id 新表的缓存。

模型保持原三参数同步返回接口，增加可选第四参数失败回调；公开四类服务接口和 VALID/INVALID 语义保持。正常取消以 DataValidationCancelledError 结束，不伪造 VALID；真正的同步异常/异步拒绝传给调用方，调用方已取消时仍明确报告原错误一次。失败只清除当前任务自己的 VALIDATING，可再次校验。

单独销毁 service 只终结其等待，共享模型仍活跃时继续维护原表缓存；完整实例退役同时结束模型任务。未提供取消 API 的底层公式 Promise 不强行终止。工作表单独删除后，旧 idle 句柄由身份检查阻止执行，至 idle 触发、工作簿或服务退役时回收。补丁的 ES/CJS/两份声明及散列登记一致，详见 ADR-010 与 `patches/univer-data-validation.json`。
