## 结果

已按 `deploy/native-images/sources.json` 收集全部 **398** 份来源，共 **201,994,917 字节**。成品包含完整原件、两份索引、4,485,036 字节的许可正文和构建/替换说明，共 402 份受回执保护的文件，另有最后写入的 `BUNDLE.json`。没有执行归档里的代码，没有把裸 URL 当作已经分发。

收集只接收安全相对路径和不含凭据的 HTTPS 地址，至多四个流；每次下载连同重定向有 120 秒总时限、至多 8 次跳转，实际正文不能超过清单精确大小。逐流计算 SHA-256，缓存也完整核对。13 份仓库补件优先使用已保存原文；坏缓存不被网络重下覆盖。输出必须是全新目录，任一工作失败都等待其他已开始的工作收尾，且不生成可验收回执。

离线复核检查实际文件集合、普通文件与路径、逐件大小/摘要、版本、来源数量、两份元数据、逐节许可正文及构建说明。只改回执、缺件、增加文件或符号链接均不能通过。`licenses` 门禁同时核对已安装的精确 Sharp/绑定/libvips 包版本、平台、声明正文及仓库补件；完整源码字节由构建/成品复核另行检查，不把静态门禁描述为全量下载验证。

## 原件修正

S3 的 `native/GPL-3.0` 原文实际是 gnulib 的许可概述，原先汇总标题误写为 GPLv3 正文。本次只纠正标题及汇总文件的对应摘要，原文、来源 URL 和全部源码摘要未变。完整 GPLv3 正文原已位于 lcms 来源的 `plugins/fast_float/COPYING.GPL3` 对应节；索引与实际内容核对通过。pixman 的原始空 AUTHORS 保留零字节事实，没有冒充完整许可。

逐节校验同时保留原来的 Rust 包声明、来源归档摘要及原始版权；这些夹在许可节之间的说明没有被误算进前一节原文。无独立 LICENSE 的 13 个 crate 仍沿用既有明确声明/同提交正文补齐方式，`unresolved` 为空。
