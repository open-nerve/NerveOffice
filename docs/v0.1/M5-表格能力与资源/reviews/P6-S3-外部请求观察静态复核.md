# P6-S3 外部请求观察静态复核

2026-11-02，基线 `a69f90b6`。本轮完成测试辅助与浏览器用例的静态准备，**未启动真实浏览器**。US-M5-14 继续 planned；真实校准和完整故事必须在 S4 恢复路径确定后执行。

## 已落地的观察范围

将 `links.spec.ts` 原有的 context request 收集抽为 `support/external-requests.ts`，局部自动夹具在首次导航前安装，结束时撤销自身监听、保存数组附件并断言零 HTTP(S) 外站请求。不路由或拦截被测请求，不访问可能不属于 frame 的 Worker 属性。原链接地址/正文/撤销/重算/保存重开断言保持。

同一夹具接入 `image-policy.spec.ts`、`image-input.spec.ts` 与 `paste-images.spec.ts`。原特定资源的零读取/合法正例、零上传、模型及保存检查全部保留；非法 IMAGE 样本增加外部字面量与有效的 213 字节 PNG data 地址，和原六类来源一起检查 Worker/主线程、阅读/编辑/重开。data 地址不走 HTTP(S)，其拒绝以实际 `#VALUE!` 结果为准，不能只用请求数组冒充证明。

原 `security/csp.spec.ts` 的无 CSP localhost 对照增加相同观察器：页面与 Worker 两次真实请求须对应目标服务两次命中，再以新页导航核对第三次。原 CSP 生效的阳性对照不变；所有校准只访问本机服务器，不向第三方发送测试流量。正式链接明确点击仍由 `link-input.spec.ts` 分开检查唯一请求、opener/referrer，没有给无隐式请求夹具加白名单。
