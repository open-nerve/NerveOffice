# P6-S2 selftest 生命周期复核

2026-11-02，基线 `332fd8e4`。处理 P5-S4 已登记 M-01；本轮仅做非浏览器工程验证，真实自检页面与完整 Gate 留在 P6 集中验收。

## 原因与修复

原入口把“返回 mount”当作“完成准备”，提前撤掉准备期 pagehide 监听；此时 selftest 模块可能仍在下载。普通 dispose 也只阻止下一段 page.load，没有阻止 hook 安装监听、包装及订阅。受控 Promise 在旧实现命中 7 项失败。

现在准备期 pagehide 一直保留到实际调用正式 page.load；该调用同步安装正式页自己的处理，随后由原在途保存/未知回执和租约规则负责离开。本挂载在调用 hook、模块失败上报及最终 load 前检查是否已销毁；公开挂载接口不变，不改保存和租约协议。

selftest 传入本挂载 AbortSignal。挂接按逆序归还计时器、订阅、已准备的控制器、页面事件及其仍拥有的 console/fetch/BroadcastChannel 包装；取消后才返回的控制器在登记时立即释放。准备拒绝清理已安装的收集并保留原异常，另有失败先行回归。不会覆盖后来安装的包装，也不把取消信号传给正式保存请求。

范围不扩大为强行抢占已经开始的场景内部工作。LocalPause/LocalSave 原准备请求仍可能在其既有 10 秒期限内持有自身观察器，返回/失败沿其原 dispose 清理；独立 outbox/crash 探针和 SDK 不在本次修改范围。生产构建仍剔除 selftest 分支，正式 pagehide 的行为须在集中浏览器回归再次核对。
