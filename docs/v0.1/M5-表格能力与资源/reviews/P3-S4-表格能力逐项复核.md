> 状态：S4 完成；S5 组合已接续完成，P3 的 S6 阶段交付继续待办。日期：2026-10-21。基线 `a0a9344d576208c3e66425d8e27899bb62828350`；沿用唯一 Phase 分支 `codex/m5-p3-tables-links`。最终回执见下方 final03 核验。

## 行为与修复

本 Step 将 Phase §3.5 的既有表格能力补成正式宿主的 UI、服务器事实、逐项撤销重做、保存重开与查看者对照。没有增加插件、文档格式、接口或保存通道。

- UR-033：数据验证详情按实际输入顺序保留字段增量；连续同类编辑合并 1000 ms，跨范围操作不合并设置。确认、切类型、删除、关闭侧栏和组件卸载时处理归属与待办；失败保留可重试，真实异常保持可观察。本工作簿撤销/规则删除取消过期输入；退役后的同 id 对象不接收旧任务。
- UR-036：范围高亮不再把旧 token 序列写入新文本；执行时配对读取当前正文与解析结果。详情校验实际范围和工作表边界，支持整行/整列，无效输入保留原规则。
- UR-037：从编辑栏切回单元格，焦点切换的 blur 会发出旧渲染光标。补丁先保留新逻辑选区，再切焦点并按既有规则恢复，消除 `new-text`→`ew-textn`；不降低输入速度或增大等待来隐藏问题。

实现、边界及移除条件见 ADR-010、两份 S4 spec 与 UR-033/036/037/038；四个固定 1.0.1 包的 ES/CJS 补丁和散列登记在 `patches/`。四个上游报告均未外发；数据验证新增回归由 S3 本地补丁引入，单独注明归因。

- S3 补丁回归：区分公式结果与真正输入失效，按计算代次重新读取结果；同格所有等待者收到最终结论，取消与真实错误语义保留。
- UR-038：条件格式确认使用当前公式的原有有效性检查，不被展示用旧错误状态否决；不靠等待初始 500 ms 的验证抑制窗口放行。
