# M5-P1-S1 真实图片路径前置复核

> 日期：2026-10-18｜SDK：锁文件内统一 1.0.1｜状态：原生对照已落档；需求方批准按 §7 调整后的前置范围继续 P1，三项仍未测。P1 未验收。

## 1. 裁决

真实 Safari 与 Chrome 都证实：文件 PNG/GIF 可以进入表格；网页“复制图片”同时携带 HTML 与 PNG 时，默认路径没有插入图片；同源 URL 浮图的默认复制不能保留图片。Safari 的延迟 350ms 补写被 `NotAllowedError` 拒绝，不能照搬自动 WebKit 的成功结果。同步接管原生复制按键后，两浏览器在数秒后的另一页粘贴均得到真实 PNG。

这证明了图片输入/复制适配存在可行路线，不代表正式入口已实现。当前还缺真实 Finder 拖放、真实 Excel 来源，以及 Chrome 允许异步剪贴板读取后的右键路径。需求方审阅 `65ccba8b` 后批准 §7 的顺序调整，允许 P1 继续 S2–S5；三个缺口改为 P2 开放正式入口、验收及合并前的强制条件。不能把调整解释为原始前置全通过或关闭 DEF-004。

## 2. 环境与证据方法

- macOS 本机原生 Safari 27.0（22625.1.29.11.27），使用此前获批的 `NerveOffice M4-P3 验证` 专用场景；原生 Chrome 155.0.8059.80，独立测试标签组。Chrome 使用现有个人资料，现有扩展未更改，因此不声称是无扩展环境。
- 所有输入通过 CUA 的原生应用接口，样本来自本任务生成的 160×96 图片或页面自有 HTML 表格。没有读取用户原有剪贴板、真实账户或文档。Chrome 创建标签和导航经 CUA 浏览器接口，实际复制/粘贴经原生应用接口。
- 普通应用目录 `/Applications`、`/System/Applications`、`~/Applications` 未找到 Excel；没有以 HTML 表格冒充 Excel，也没有安装或登录 Office。
- 页面仅监听 127.0.0.1，使用当前锁定 SDK；默认 SDK IO 与同源诊断 IO 分开。正式平台入口守卫未开放，探针不进入产品构建。HTTP 使用现有生产安全头；诊断图片依赖专用测试 Cookie。
- 原件根：主目录 `.codex/handoffs/m5-p1-20261018/s1/`。`assessment-01/native-evidence.json` 保存输入回执、桌面判定、原件引用与逐项输出；`raw-artifact-hashes.json` 保存 686 个当时原件的 SHA-256。后续收尾记录另行留存，不覆盖原件。
- 当前构建 `a6188d1d45f21ae3262adea8ae6712bcdbc6d22594314d635ad5365d466090c6` 的 35 个来源文件哈希与当前源码一致。保留早期构建与所有 RED/失败记录。

原始方法必须区分：自动校准为 `synthetic`，真实输入为 `native-ui`。`nativeEvidenceOf` 只检查可信输入与 CUA 回执、受控来源、run/case/page/build/SDK/时间的一致性；它不根据 `isTrusted` 或没有异常推断功能成功。异步 Clipboard API 可以没有 DOM `copy/paste`，此时以原生动作、系统提示、SDK 前后状态和另一页实际粘贴共同判断，不伪造事件。

## 5. 给 P2 的实施约束

1. 粘贴分流必须同时看 HTML 和文件。保留真实表格 HTML，网页复制图片带外链 HTML 时不能让 HTML 分支吞掉图片，也不能直接采纳外站图片地址。编辑栏、名称框、页面外输入区必须单独判焦点。
2. 图片复制不能在普通 `copy` 监听器里盲等 SDK；真实快捷键可直接调用 Clipboard API 而不产生 DOM `copy`。当前350ms补写在 Safari 不成立。应在确认图片焦点的原生用户激活期间写入 PNG，并防止同一次 SDK 命令稍后清空；单元格复制必须保持原行为。
3. 本探针的同步方案只复制唯一受控首图，不是生产适配器。正式命令、右键、快捷键、只读/编辑权限、多图片、切换销毁、写入拒绝及无权占位图仍须设计与验收。
4. 右键粘贴与快捷键权限不同。Chrome 未授权应有明确反馈；Safari 选择系统粘贴后未插图的问题需在 P2 捕获 API 实际内容并定位，不能用按钮插图掩盖。
5. 真实拖放必须补齐默认导航与拦截后的插入。合成/协议事件无法回答浏览器默认行为；当前0个drop不是否定浏览器能力。
6. 当前版本的原生 GIF 文件可插入，不沿用旧版本未验证结论；四格式完整解码/重编码和动态 GIF 语义仍属于 S2/P2。

## 7. 已批准的顺序调整

保留已证实的输入/复制约束，将以下三项固定为 **P2 正式图片入口开放、Phase 验收及合并之前** 必须补齐的证据：真实 Finder 拖放、真实 Excel 来源、Chrome 异步剪贴板授权后的路径。P1 可以先做四格式处理、私有存储、授权读取和引用事务；正式入口继续关闭。
