## 实测修正与裁决

- 原 isSafeUrl 接受相对路径但只核对协议，故先加平台规范化、继续保留 SDK 原安全检查。无配置和旧配置行为有独立对照。
- 拒绝通知用公开 FUniver.showMessage；适配层文案放 profile/locale，不增加跨层依赖。readiness 同时要求 edit，地址合法不能代替权限。
- SDK 原快捷键排除活动编辑器；隐藏输入又不在 editorDOM 内。新增实例绑定按真实正常文档、非折叠选区、isFocusing 与 activeElement 判断；风险是误归属或旧实例抢键，已有实例/只读/组字/退役反例。
- 真实表单 autofocus 只改变 isEditing，文本/矩形数组和 segment 不变。桌面/移动两个 popup listener 仅忽略这种焦点通知；真实换区/清空/上下文变化仍关闭。风险是 SDK 改为原位修改数组，固定包的实际更新路径和回归明确锁住此依赖。
- 单元格编辑时鼠标应到上层 Docs，旧测试等待底层 sheet canvas 收事件不成立；仅 hover 使用既有 force 选项，同坐标后必须见到真实链接浮层，未强制点击产品控件。
- 内部导航产生 primary:null，完整选区从 getActiveRangeList 读取；定义名称预览显示解析后的引用。自制导航响应显式 UTF-8，避免把夹具乱码当产品问题。
- 连续快速点回同格会触发 SDK 双击重新进入折叠编辑态；用回车后的 ArrowUp 选择原格并核对名称框。保留原非折叠守卫，不加延时或扩大入口。新增时已有文字的表单不显示文字输入框；保存正文及区间是实际可观察证据。子串断言匹配必需字段，允许正常 refId/tooltip 元数据，未放宽文字/地址/边界。
