# M5-P1-S5 保存引用与副本复核

> 状态：实现与本 Step 自验完成；P1 独立审查及完整 Phase 门禁仍在 S6。日期：2026-10-18。

## 1. 已落地行为

保存检查子进程在完成原有 JSON、结构、资源与图片规则检查后，提取解析后字符串值中的全部规范相对图片标识。键名、资源 data 的原始转义文本、被重复键覆盖的值不产生引用；不从外部 URL、查询参数或附加路径截出一个平台地址。完整集合去重排序后通过 IPC 返回，未新增任意数量上限或静默截断。

真正写入正文时，只为目标已有的合法当前引用、本人严格 24 小时内上传、锁下仍可读的其他当前来源建立关系。未知和无权地址可以随合法正文保存，但不产生读权；删除正文地址会移除当前关系，物理对象保留。系统管理员没有额外内容权利，同物理对象的不同 assetId 仍独立授权。

普通复制保持原 gzip、unitId 和源的当前引用集合，不继承分享，也不提升正文里的其他地址。本机副本按上传内容重新判断合法 ID，仍须能读原文档，保持原位置选择、格式校验与幂等规则。副本建好后，源撤权或删除不会撤销副本自己的引用。

**unchanged 保持原 gzip 与原引用集合**。视图字段被规范化忽略，即使上传字节中的地址不同，也不能用没有存下的内容修改引用。前置重放和账本锁内重放同样不改引用，旧请求不能覆盖后来提交的关系。

## 2. 事务、权限与锁复核

固定候选来源在空间/文档锁之前选出，每个 ID 至多一个候选。保存一次性按 id 对全部既有目标和来源取 FOR UPDATE；副本按 id 取 FOR SHARE。空间行先按 id 持共享锁，最后持资源行。关系服务只使用调用方事务，不另开事务；带品牌的预选/持锁结果绑定原事务，跨事务复用会拒绝。

锁下重新读取实际位置、当前关系及 DocumentAccessPolicy 结果。来源移动到未持锁空间、删除、取消分享、失去成员资格或移除引用时，不从旧事实建立新关系；不会在持有后序锁之后补找和补锁另一个来源。归档仍按既有“可读”的政策处理。本机副本的原文档在取锁前就加入固定集合，可证明它自己的当前引用，不依赖另一预选来源继续有效。

正文、引用、修订、审计与回执使用原事务。关系写入后注入异常时，保存整体回滚；两种副本连新文档一起回滚，同一 requestId 能正常重试。无图片保存/本机副本维持原锁路径；隐藏、缺失、只读保存目标不会先查询图片候选。

Documents 只通过 Assets 的公开元数据/锁服务访问资源；Assets 不反向依赖文档。读取仍由 Workspace 编排，权限仍由原 policy 判断。内部关系仓储只给受限的集成测试入口导出，生产 app/workspace 的深层导入继续被 lint 规则拒绝。
