## 2. 实现选择

采用小型、有界的客户端状态机解析器及明确的 SDK 适配接口，不增加第三方解析依赖。CSV 只有逗号、双引号和换行规则，当前功能不需要自动编码/分隔符探测。引入通用 Office 转换器会扩大已批准范围；直接把 CSV 变成服务端快照上传会绕过现有编辑、租约与本地优先保存，两者均不采用。

模块边界：

- `shared/csv/`：纯格式、预算、错误分类；不引用 SDK、接口请求或页面状态。
- `editor/csv/`：SDK 数据与 CSV 数据的转换、候选快照容量校验、一次插表命令。所有 Univer 细节保留在适配层。
- `features/sheet-editor/`：用户操作、会话/租约/在线状态、取消与实例身份、保存管道协调。
- 空间列表只链接到 CSV 新建入口，不把 SDK 引入平台包。新建入口使用编辑器 HTML 的独立路由；同一页先解析和预览，确认后调用既有幂等新建 API，再在同一页面挂载正式编辑器。待导入数据只在内存，不把正文放 URL、localStorage 或未加密临时数据库。

## 3. CSV 格式与预算

以下是本 Phase 的实现选择，不冒称已有服务端行列限制。已有快照硬上限为 `SNAPSHOT_MAX_RAW_BYTES = 5 * 1024 * 1024`；服务端仍做自己的全部检查。

| 项目 | 约定 |
|---|---|
| 编码 | 只接受合法 UTF-8，可有一个开头 BOM；不猜 GBK/UTF-16。导出带 UTF-8 BOM |
| 格式 | 逗号分隔，双引号包裹与双写转义；导出 CRLF；导入接受 CRLF、LF、CR，保留引号内换行 |
| 空白 | 不 trim 字段；不把首行当特殊表头；不等宽行补空格单元格；末尾单个换行不产生额外行，其他空行保留 |
| 空文件 | 零字节或只有 BOM 拒绝；显式 `""` 是一个空单元格 |
| 输入/输出文件 | 各最多 5 MiB（包含 BOM）；输出转义增加的字节也计入 |
| 行/列/格数 | 最多 50,000 行、1,024 列；补齐后的矩形最多 100,000 格（包括空格） |
| 单字段 | 最多 32,767 个 UTF-16 code unit（导出保护前缀也计入）；拒绝 NUL 与孤立代理字符；原值不回显到错误/日志 |
| 调度/取消 | 解析按有界批次让出事件循环，检查 AbortSignal；取消或解析失败不产生可应用结果 |

格式依据 [RFC 4180](https://www.rfc-editor.org/info/rfc4180/) 的分隔、引号与换行规则；导入的 LF/CR 是明确的兼容扩展。语法错误（孤立引号、闭引号之后还有内容等）明确拒绝，不静默修复。

### 3.1 导入类型

解析器交出原始字符串矩阵。SDK 适配时，仅无空白、无前导零、有限且不超过 15 位有效数字的普通十进制数转成数字，还须确认转换后的最短十进制表示与输入数值一致；非零下溢成 0 或次正规数精度损失时保留文本。日期、长编号、指数写法和其他字符串原样作为文本。`-2` 是数字，`-2+3`、`=1+1`、`+1`、`@x` 是显式文本；不设置公式字段，不经 SDK 自动猜公式的粘贴通道。日期 `2026-11-01` 保持文本，不猜区域或时区。

### 3.2 导出值与保护

用户选择一张可见工作表，范围取包含内容的最小 A1 起始矩形（保留中间空格，不导出整张空网格）。只导出显示数据，不带图片、格式、链接目标、备注或插件资源。数字/日期使用当前显示文字，如 `1,234.50`、`2026-11-01`；不隐藏在本机时区中再次解释。公式导出计算后的显示结果，不导出公式源码。数组公式的溢出格来自 SDK 独立缓存，按当前文档/表实际存在的结果格补齐范围和类型，不凭意图范围扩张；空字符串结果保留位置。只格式格和已清除的数组缓存不扩大矩形。

字符串如以 `= + - @`、对应全角字符、TAB/CR/LF 开头（含前导空白后出现）时，在完整双引号字段内加 TAB 前缀。正常数字的负号不加前缀，但自定义数字格式生成的公式形态文字同样保护；一律正确转义引号。用户说明中明确可疑文本会多一个保护制表符，不提供去保护的危险下载选项。

[OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection) 提醒不同表格软件与二次保存行为存在差异；此策略采用其面向 Excel 阅读的 TAB 前缀建议，不宣称任意下游软件再次加工都安全。Excel 本机未安装，实际外部软件验证继续登记，不伪造证据。

导出前提交当前编辑输入、等待面板与公式；等不到公式结果或已有 `formulasPending`/Worker 故障时拒绝导出，说明原因，不把旧缓存当最终结果。会话/文档/编辑器实例变化使操作作废。

## 4. 原子写入与用户流程

### 4.1 导入新工作表

入口在正式编辑器页，只在当前持有有效编辑会话且在线时开放。选择文件→解析→显示行列和预览→确认。取消、文件失败、超限、会话变化、租约丢失不得改变原工作簿。

确认时再次核对会话、在线与编辑器身份；对最新快照构造完整候选工作表并检查最终快照字节预算，禁止使用开始解析时的旧快照。先验证全部内容，再以单个 SDK 插表命令提交，形成一次撤销；不得逐格写入后尝试回滚。导入成功只代表模型修改完成，保存状态沿用原指示器；不另外调用正文上传。中间已有输入不能被丢掉，导入后的单次撤销/重做和重开一致由真实浏览器验证。

### 4.2 从 CSV 新建文档

空间/文件夹可创建时提供入口，在创建前完成解析、类型转换和候选容量检查。确认后沿用既有 requestId 去重、创建权限、CSRF 和会话机制。创建返回后在同一页面挂载正常编辑器，取得编辑租约再应用一次导入，并沿用保存管道。

创建响应丢失时沿用同一 requestId；不得盲目覆盖重放返回的已存在正文。确认后若创建已经完成而编辑器加载、权限或保存失败，明确提供新文档入口及重试状态，保留本轮内存数据；不自动删除文档、不宣称“未创建”。取消在创建前有效，创建发出后不把关闭弹窗当撤销服务端事务。页面关闭按实际未保存状态提醒。
