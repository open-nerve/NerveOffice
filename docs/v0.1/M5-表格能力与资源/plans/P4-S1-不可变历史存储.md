# P4-S1 不可变历史存储实施计划

> 执行：使用 `superpowers:executing-plans` 在当前唯一 P4 worktree 原地逐项实施；先失败用例，再实现，Step 绿色后提交。阶段末按项目约定独立审查。

**目标**：为小时历史和运维检查点提供可原子提交、不可覆盖、保留原 gzip 与合法图片引用的内部存储入口。

**架构**：Documents 新增检查点仓储、数据库时钟和采样服务。正文和元数据在数据库内复制，资源关系只取已获权的当前关系；小时占位独立于正文删除。S1 注册内部服务，不改现有保存入口、不开放历史 API 或 GC。

**技术栈**：Node 24.21.0、TypeScript、NestJS、PostgreSQL 18、Drizzle、Vitest；不新增依赖。

**设计**：[P4 架构设计](../04-P4-历史与资源回收.md) §3.1–3.3。

## 全局约束

- 单一分支 `codex/m5-p4-history-gc`；主目录 main 不动。中文详细提交，不跳 hooks。
- 用户历史 7 天、运维检查点 30 天；UTC 自然小时首份不可变；后续写入不能覆盖。
- gzip 原字节、SDK unitId、格式信封与实际修订保存人保留。旧规范化哈希如实允许空，gzip 字节 SHA-256 始终存在。
- 不在 SQL 事务中做文件 IO、解压或网络；同一事务逐条 await。
- 工程与测试输出写主目录 `.codex/handoffs/m5-p4-20261022/`，不放 SDK 副本进扫描树。

## 审查重点

1. 清除之后同小时又保存：不能制造第二份；Task 2 直接删除正文后再捕获验证。
2. 在 UTC 换日、时区偏移或夏令时附近采样：按 UTC 自然小时和精确 7/30 天，Task 2 固定时间测试。
3. 检查点生成一半失败：小时占位、正文、图片关系整体回滚，Task 2 注入事务异常并真实查询。
4. 原文档永久删除与同物理图片的其他引用：检查点存续，引用的 assetId 不能被删除，Task 1/2 的真实外键及删除测试。
5. 旧存量正文哈希为空或当前正文缺失：不伪造规范化哈希，缺正文抛错且不留占位，Task 2 验证。

## Task 2：小时采样与运维快照的内部事务入口

**文件**：新增 `apps/api/src/modules/documents/document-checkpoints.repository.ts`、`document-checkpoint-clock.ts`、`document-checkpoint.service.ts`；修改 `documents.module.ts` 和测试专用出口；新增 `tests/integration/src/documents/checkpoint-storage.test.ts`。

**接口**：

- `DocumentCheckpointClock.now(transaction: Transaction): Promise<Date>`：只从该事务的数据库取实际时刻；测试以 Nest 覆盖 provider 固定时钟，生产无调时入口。
- `DocumentCheckpointService.captureHourly(documentId: string, transaction: Transaction): Promise<string | undefined>`：同小时已占位返回 undefined；新捕获返回检查点 id。调用方持有源文档锁或本事务新建私有行。
- `captureOperation(documentId: string, kind: 'before_delete' | 'before_upgrade', eventId: string, transaction: Transaction): Promise<string | undefined>`：同事件幂等，同种不同事件可生成新记录，30 天。
- 仓储消费固定数据库时刻与调用方事务，INSERT…SELECT 当前正文/信封/修订和当前图片关系；缺正文/修订按数据不一致抛错。

- [x] 先写真实行为测试：首小时生成、同小时不覆盖、下一小时新记录、清除后同小时不复生；UTC 边界、7/30 天；同事件幂等；两并发事务唯一和回滚再试；gzip/信封/保存人/当前关系逐项一致；未获权正文图片不建立引用；源删除后仍存；缺正文不留占位。
- [x] 观察相应 RED，再实现时钟、仓储和采样服务；注册为模块内部 provider，仅测试专用出口可直接引用。
- [x] 使用已有真实持锁辅助控制并发，不用固定等待；跑新存储测试和相关资产引用回归，保存 GREEN 原件。
