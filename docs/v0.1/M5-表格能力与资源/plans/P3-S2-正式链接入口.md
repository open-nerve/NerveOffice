# P3-S2 正式链接入口：实施计划

> 执行方式：主 Agent 用 `superpowers:executing-plans` 逐任务实施；Step/Phase 收口独立审查。状态：完成，见[复核报告](../reviews/P3-S2-正式链接入口复核.md)。日期：2026-10-21。

**目标**：开放可保存、可撤销、可重开的正式链接入口，所有明确输入与点击沿统一地址规则。

**架构**：SDK 增加可选规范化接点；平台在表单、写命令和导航三个边界调用现有 contracts；保留内部导航、只读和自动识别的原边界。

**技术栈**：TypeScript、Univer 1.0.1、pnpm patch、Vitest、Playwright。**Spec**：[正式链接入口](../specs/P3-S2-正式链接入口.md)。

## 全局约束与审查重点

- 唯一 P3 worktree；主目录保持 main，Step 完成后一次正常中文提交。
- 2,048 字符及既有地址规则不变；拒绝不回显用户 URL、显示文本或正文。
- SDK 默认行为兼容；只替换平台注册实例的配置，禁止改全局 `Tools`、吞全局异常或直改 node_modules。
- 不改变首个 Facade 监听和只读防火墙顺序；不用合法地址替代编辑权限。
- 重点：富文本更新不能先改显示文字再失败（Task 2）；相对路径与内部锚点不补错协议（Task 1/3）；粘贴清洗不破坏原文/图片（Task 2/3）；同页重建不留旧策略（Task 2/3）；默认无配置 SDK 的导航白名单保持（Task 1）。
- 所有重型验证串行；原始失败、RED 与变异分别保存；不通过重试/跳过/提高预算解决问题。

## Task 2：统一命令输入并开放入口

**文件**：新增 `profile/link-input-policy.ts`、同名测试、`internal-api/link-input.ts` 及测试；修改 `internal-api/ui.ts`、`registry.ts/.test.ts`、`profile/sheet-profile.ts/.test.ts`、`entry-guards.ts/.test.ts`、`menu-config.ts/.test.ts`、`sheet-editor.ts` 和对应生命周期测试。固定错误文案放适配层既有 profile/locale.ts（不跨到页面专属文案）。

**接口**：

- `normalizeLinkInput(value: unknown): string | null`。
- `linkUiConfig`：含 normalizeUrl 和 navigateToOtherWebsite；导航只接受合法非 `#` 地址，通过 `window.open(href, '_blank', 'noopener,noreferrer')`。
- `LINK_INPUT_COMMANDS`：四个实际 SDK command id；错误通过公开 `univerAPI.showMessage` 只显示固定中文文案。
- `installLinkInputPolicy(univerAPI): IDisposable`：只改四命令的 payload 地址；尊重既有 cancel，非法/畸形/只读仍取消。
- `installEntryGuards` 增加第三个默认 false 的 readiness 回调；两个链接插入菜单只在 read 隐藏。
