## 决策依据与限制

Q 的 `bulk-sql-plan-70000-01-summary.json` 已记录七万 SQL 诊断：四类外层 INSERT 约 1.04–1.81 秒，外键和语句级活动工作占主要部分，原活动触发器均每语句调用一次；排序节点约 13–15 ms。没有证据支持在此修改数据库结构。该样例不是原 HTTP 用例、不是 CI 宿主测量，不能排除旧 CI 的未知等待。采用分组的直接理由是建立明确的容量测量资源边界，执行用户串行政策；原 CI 原因继续按未完全证实保留。
