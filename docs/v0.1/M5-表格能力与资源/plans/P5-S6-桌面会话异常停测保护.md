# P5-S6 桌面会话异常停测保护实施计划

> 使用 `superpowers:executing-plans` 在现有 P5 worktree 直接实施；用户 2026-11-02 已批准补保护、小型模拟验证和只读定位，不再重复请求该范围许可。

**目标：** macOS 桌面会话消失、身份变化或无法可靠读取时，停止本轮受管测试，保留中断及清理事实，避免继续启动浏览器。

**架构：** 新增只读会话探针与不可自动恢复的监测状态，接入实际拥有测试子进程的资源运行器；外层 S6 门禁包装复用同一探针并留下 `needs-attention`。探针不发送信号，运行器沿已有本轮进程组停止及清理流程处理。此保护不预防第一次图形资源耗尽。

**技术：** Python 标准库、固定路径 `/bin/ps`、`/dev/console`、现有 `run.py`/`gate_helpers.py`、unittest 小型模拟。

**依据：** 已批准的[调查与接续边界](../reviews/P5-S6-WindowServer会话中断调查.md)。起点 `2b1dc03885616c74b2072999374c1bac476dca5f`；main 仍为 `884591c8`。

## 全局约束

- 仅现有 `codex/m5-p5-csv` 分支；不合并、不推送、不启动 full06/容器/真实浏览器复现。
- 原业务断言、浏览器范围、skip/retry/timeout 和清理边界保持。所有验证经受管 `unit` 入口，只创建 KiB 级样本与短命 Python 子进程。
- 不读取 argv/环境凭据，不提权，不改变系统设置，不向 WindowServer/个人应用发送信号；查询只保存目标进程身份与有界原因。
- macOS 浏览器相关 `e2e/container/measure/template/native/vm` 和外层 `gate` 启用；Linux/纯单元与集成明确记不适用，不伪称已观测桌面。
- 每 2 秒采样，单次 ps 超时 2 秒，仅接受不超过 1 MiB 的输出。实际停止受采样、查询、调度及原有退出等待影响，不承诺硬实时。
- 基线包含 console UID、唯一系统 WindowServer、当前 UID 的唯一 loginwindow 的 PID/UID/启动时间/固定可执行路径；读前后 console UID 一致。多会话歧义、查询失败或格式异常拒绝启动/停止当前轮，绝不重新认领新基线。

## 审查重点

1. 子进程返回 0 同时桌面变化，必须记录中断；Task 1 覆盖结束时复核。
2. 等待登记的启动屏障期间桌面变化，不得释放实际测试命令；Task 1 覆盖启动前拒绝。
3. PID 相同但启动时间变化、同名非系统程序、多用户或截断输出，不可误当原会话；Task 1 覆盖解析与身份比较。
4. 查询失败、中断、进程在发信号前已退出，不能触发全局 kill 或误报清理；Task 1 覆盖真实小子进程与旁观者隔离。
5. 外层包装失效不能只靠外层保护；内层独立监测，原事件和不适用平台分别记录；Task 2 覆盖桥接及失效后的启动指针。
