# P2-S4 系统图片输入：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 系统图片输入遵守焦点、目标与许可，真实表格不被图片预览吞掉；可靠复制、失败反馈与三项原生前置成立后才进入 S5。

**Tech Stack:** TypeScript、固定 Univer 1.0.1、既有 ClipboardItem/Blob/Canvas、Vitest、Playwright、真实 Safari/Chrome/Finder/Excel。

**Spec:** [P2-S4 系统图片输入](../specs/P2-S4-系统图片输入.md)。
