## Review Focus

1. 两种自动取焦只修一处或参数中间丢失：真实 manager → popup → 组件链的全程 focusin 断言同时挡住 React 与 timer，不能只查最终 activeElement。
2. 缺省调用、显式打开和用户主动搜索：搜索仍能聚焦、过滤、单选/多选；不能把 false 当作禁用搜索或持续抢焦点。
3. 弹层关闭、showSearch=false 或策略切换：原 timer 不得迟到 focus，包括已移除节点；清理只作用于本实例。
4. 观测器窗口、溢出、异常和 document 失效：有限输入范围、finally 释放、失败仍保留有界摘要，不能吞原错误或空记录放行。
5. SDK 重建/升级、ES/CJS/types 和原补丁共存：正常 pnpm 重装后实际行为成立，真实文件/patch/锁摘要一致，旧数据验证面板和表名/原生输入修复不回退。
