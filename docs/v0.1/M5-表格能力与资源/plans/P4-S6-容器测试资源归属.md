# P4-S6 容器测试资源归属实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking. 不重复实施已通过的容量调度任务。

**Goal:** 容器测试只清理本轮有创建证明且已停止使用的资源，并让崩溃后的未闭合环境进入已有资源运行器的保留/阻止重试流程。

**Architecture:** TypeScript 专门模块管理 Docker 意向、实际对象观测和本轮删除；Python 资源运行器预建持久台账并检查其闭合状态。共享 UUID、标签与已存在的运行锁，保留现有部署检查、进程控制、报告保留及方案 B 语义。

**Tech Stack:** Node 24 / TypeScript / Vitest；Python 3.9 标准库 / unittest；现有 Docker Compose。

**Spec:** `docs/v0.1/M5-表格能力与资源/specs/P4-S6-容器测试资源归属.md`

## Global Constraints

- 主目录 HEAD 保持 main；仅在 `.codex/worktress/codex/m5-p4-history-gc` 修改，不创建其他分支/worktree；正常中文提交由主 Agent 统一完成。
- 原案例、断言、容量、时限、覆盖率阈值、worker/retry 和方案 B 边界保持。full18/container07/r09 原件及工具不覆盖。
- 不启动真实 Docker 环境、数据库、浏览器或 VM 做机制小测；所有测试经受管入口，重型测试由主 Agent 串行调度。
- 名称使用已登记 `NERVE_TEST_RUN_ID` UUID；先登记后启动；身份/句柄/生产者不明时保留，不以 PID 或名称授权删除。
- 台账/回执单文件最多 64 KiB，不保存密码、master key、完整 Config.Env；既有日志和报告限额保持。
- 本轮可证清理失败必须传播非零，未闭合台账阻止同 Store 的同类重试；旧/外部资源不自动接管。

## Review Focus

1. 旧 PID 被重用、其他 worktree 与共享 daemon 上的活动资源：新入口不删也不覆盖。
2. 资源创建与进程中断之间的窗口：意向已持久存在，父进程不能丢台账或误报完成。
3. Docker 查询失败、daemon 改变、标签不符及外部卷引用：保留并失败，不能解释成对象不存在。
4. 应用/一次性容器被合法重建：仍属本轮，可清理且保存实际身份，而非要求最初 ID 恒定。
5. 同轮清理重复执行、步骤部分失败及生产者等待耗尽：幂等，保留未完成状态，不能继续删除活动资源。

**Interfaces:**
- 父侧 `register(directory: Path, run_id: str, repo: Path, scratch: Path)` 在 container 子命令启动前创建 `container-resources.json`，内容版本与身份见 spec；登记协议标记留在原 run.json。`assert_closed(directory: Path, run_id: str, repo: Path, scratch: Path)` 只接受未被使用的 `unclaimed` 或有实际删除证明的 `closed`，否则抛出，由已有 `Run.finish` 转为 `cleanup-pending`。
- 父运行器提供 `NERVE_TEST_RUN_DIR`；子侧导出 `ContainerRunResources`，构造时接收当前运行上下文、settings 与有界 capture 函数；`reserve()` 查询并登记空命名空间和 daemon，`producerStarted(pid)`/`producerStopped(pid, quiescent)` 记录真实活动，`cleanup()` 返回实际清理是否完成。实现可增加私有帮助函数，不扩展为通用全局 Docker 管理器。
- `SettingsInput.pid` 改为 `runId: string`；进程控制的 `E2E_RUNNER_PID` 保留。`RunResult` 增加实际 `quiescent: boolean`；原 wait 上限耗尽仍存活时显式 false 且命令不成功，CLI 不删除环境。同步命令仍受现有上限控制。
- Docker 归属标签使用 `org.nerve-office.test.run`（UUID）及 `org.nerve-office.test.repo`（真实源码根的 SHA-256）。单次测量容器同样归属本轮；手工 Compose 未设置时标为 `manual`，不可被自动清理认领。
