# P2-S3 图片来源与定位：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** IMAGE 只接受可证明的字面量来源；图片写入先清洗/拒绝；保存拒绝可定位且不泄漏内容。

**Architecture:** 在 SDK 定义名称展开前保留来源证明，既有公式包装经 AST 回调验证；纯片段规则与无副作用的 SDK 命令预演分层；后端在既有受限检查子进程中增加小位置结果；页面通过窄的只读名称查询显示位置。

**Tech Stack:** TypeScript、Univer 1.0.1 的公开 AST 执行接口和集中内部协议、现有 JSON1、Zod、Vitest、Playwright、真实 PostgreSQL。

**Spec:** [P2-S3 图片来源与定位](../specs/P2-S3-图片来源与定位.md)。

## 全局约束

- 只在现有 codex/m5-p2-images worktree；main 不动、不拆新分支。设计与代码分别提交，代码在整个 S3 通过后一次提交，正常 hooks、中文说明。
