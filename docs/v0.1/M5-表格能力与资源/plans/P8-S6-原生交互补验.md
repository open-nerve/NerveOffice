# P8-S6 原生交互补验：实施计划

> 日期：2026-11-07｜所属：M5-P8 S6｜依据：[P8 设计](../08-P8-M5完整收官.md) §3.5、[P2 原生待验登记](../handoffs/P2-原生环境待验登记.md)、[P1-S1 原生待验项](../handoffs/P1-S1-原生图片待验项.md)、[P6 Mac 平台待验交接](../handoffs/P6-Mac平台待验交接.md)（Q-13）

## 1. 目标

用真实系统交互补齐以下证据，补验结果写进实施记录与延期登记：

- DEF-004 表格部分的剩余原生项：真实 Safari 的粘贴、复制与右键一次性粘贴；Finder 拖放在 Safari 与 Chrome 上的剩余组合；
- Q-14：同时带正文 HTML 与图片文件的富文本剪贴板；
- Q-13：真实 Safari 的 CSV 下载落盘。

Excel 没有可用应用，按需求方决定继续记账到 M7 前裁决，本计划不涉及。Chrome 已闭环的右键成功、拒绝、重试与按键图片输入不重做。

## 2. 边界

- **由需求方操作**：真实动作由需求方在 Mac 前完成，属于“明确登记的人工操作”。开始时先用一次粘贴核对：用 ToDesk 远程做的动作，录制器是否同样记为可信事件（`isTrusted`）。核对不成立，就只认在 Mac 前的实体操作。
- **主审只做准备与核对**：主审不模拟用户输入，只经 Apple 事件读取页面上的录制结果、填写测试账户的登录表单。不读取任意系统剪贴板，录制器只读事件自带的数据。
- **样本**：只用自制样本，即仓库里的 `spikes/m5-assets/fixtures/sample.{png,jpg,gif,webp}`（摘要见同目录 `manifest.json`），以及当场自制的一段文字加一张样本图片的富文本。
- **不跑长测**：本机只启动宿主服务与开发库，不跑 Playwright 长测。本轮与 P2 一样属于短时人工会话，WindowServer 风险仍在，出现会话变化即停（`run.py native` 的会话保护）。
- **原件**：放在主目录 `.codex/handoffs/m5-p8-20261106/s6/` 的新运行目录，不覆盖 P2 原件；测试账户的密码只存在本机文件里，不输出。

## 3. 准备（主审）

1. **构建**：先构建 `@nerve-office/api...`，再构建 web 测试构建（`build:e2e`），记录构建身份（全部产物文件的摘要）。
2. **宿主服务**：由 P2 的 `serve-native-host.mjs` 改写，指向本 worktree 与本机开发库（`pnpm db:up`，端口 54318）。
   - 经 `python3 -B tools/test-resources/run.py native -- node <脚本> <新运行目录>` 启动，建本轮专用的测试库；
   - 创建一个测试账户和两份文档：编辑文档与接收文档；
   - 退出时停服务、删库，并写 `exit.json`。
3. **浏览器**：
   - Chrome、Safari 各开一个本任务标签，地址带 `?imageInput=enabled&nativeImageRun=<本轮>&nativeImageCase=<用例>`；
   - 主审经 Apple 事件填写登录表单。Safari 需要需求方先在 Mac 前打开“设置 → 高级 → 显示网页开发者功能”，再勾选“开发 → 允许 Apple 事件中的 JavaScript”；结束后取消勾选。
4. **录制**：进入编辑后点“开始记录受控样本”，每个动作前后点“记录当前状态”。页面重建后 pageId 会变，须重新开始记录。

## 4. 用例

| 编号 | 浏览器 | 需求方的动作 | 记录与核对 |
|---|---|---|---|
| N0 | 两者 | 在接收文档单元格里，用 ToDesk 做一次 ⌘V | 录制器的 `isTrusted`；决定能否远程做后续动作 |
| N1 | Safari | 在 Finder 选中 `sample.png` 按 ⌘C，在单元格按 ⌘V | paste 为可信事件；记下 types 与 files，文件摘要与样本对应；生成单元格图片；保存重开后像素一致 |
| N2 | Safari | 在网页图片上右键“拷贝图像”，到单元格按 ⌘V | 同 N1；同时带 HTML 与 PNG 时不丢图 |
| N3 | Safari | 编辑器右键菜单里的“粘贴”（系统一次性粘贴） | 出现 Safari 的“粘贴”气泡；点了才插入；不点或拒绝时有提示，不静默报成功 |
| N4 | Safari | 从 Finder 把 `sample.png` 拖到单元格，再拖一张到画布空白处 | drop 为可信事件；页面不导航、不开新标签；插入位置正确；保存后像素一致 |
| N5 | Safari | 选中图片按 ⌘C，到接收文档按 ⌘V，再到“文本编辑”按 ⌘V | copy 事件；接收文档得到同一图片；外部接收方得到 PNG |
| N6 | Chrome | 从 Finder 拖 `sample.gif`、`sample.jpg`、`sample.webp`（PNG 在 P2 已验） | 同 N4，逐个格式；不支持的格式按产品规则给出提示 |
| N7 | Safari、Chrome | 在“文本编辑”或 Pages 里复制一段文字加一张图片，到单元格按 ⌘V（Q-14） | 记下 types 与 files；按产品规则判断正文是否保留、图片是否上传。确认丢字就按根因修正分类，补回归 |
| N8 | Safari | 编辑文档里“导出 CSV”（Q-13） | 文件实际落进“下载”；内容与预期逐字节一致。失败就改为下一个任务再释放对象地址，补回归 |

每个用例记下动作开始与结束时间、浏览器版本，以及录制器的 `pageId`、`complete` 与 `pending`。`complete` 为 true 且 `pending` 为 0，只说明记录没有已知缺口，不代表功能成功。

## 5. 判定

- **通过**：可信事件到达，结果与核对列一致，保存重开后内容与像素成立。
- **动作未送达**（例如拖放没有收到 drop）：只算动作失败，校准后重做，不据此判断功能好坏。
- **产品缺陷**：保留原件，按根因修复，补单元或 E2E 回归，复验后重做该用例，不改写失败记录。
- **会话变化或无法归因的输入**：本轮作废，不放宽空闲或归因条件。

## 6. 收尾

- 服务正常退出、测试库删除，`exit.json` 退出码为 0；
- 只关闭本任务打开的标签与窗口；临时剪贴板权限恢复为“询问”；Safari 的 Apple 事件 JavaScript 由需求方取消勾选；Finder 恢复原来的视图；
- 结果写进 P8 实施记录；DEF-004、Q-13、Q-14 按实际结果更新登记。未验证的部分照实保留。
