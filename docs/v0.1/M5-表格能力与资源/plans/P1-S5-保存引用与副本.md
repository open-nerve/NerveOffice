# M5-P1-S5 保存引用与副本实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 正文真实写入与当前图片引用同事务；普通复制和本机副本在既有权限、租约和幂等规则中建立独立的合法引用。

**Architecture:** 快照子进程返回去重有序 assetIds。Documents 负责关系和候选来源，AssetReferenceService 提供资源存在/上传窗口与共享锁；引用编排在固定来源集合上按空间、文档、asset 顺序锁下复核，沿用 DocumentAccessPolicy。unchanged 与重放不改引用。

**Tech Stack:** 现有 TypeScript/NestJS/PostgreSQL/Drizzle、快照子进程池、RequestLedger、隔离集成/E2E。

**Spec:** [P1-S5 规格](../specs/P1-S5-保存引用与副本.md)。基线 `329a6472c0ee68c47346b05f6580b3d8b3e3515b`，S4 已完成。

## Global Constraints

- 一个 P1 worktree/分支，主目录 main；中文提交、正常 hooks；Step 不合并。P1 独立审查统一 S6。
- 只用 127.0.0.1:53522 隔离库，全面/压力/浏览器串行；不碰开发库或用户数据。
- 不复制主进程正文解析，不放宽原校验、会话/CSRF/Origin、租约、修订、幂等与数据库超时。
- 不同事务中的来源查询不是授权；必须在稳定且完整的锁集合内复核。无权地址不建关系但不阻止合法正文保存。
- 不开放 UI，不做历史和 GC，不把协议回归算作 P2 原生入口或旧图清理验收。

## 接口与依赖

- contracts：独立字符串中的规范相对地址提取纯函数；API 子进程：遍历解析后的快照和 resource data，`PassedSnapshot.assetIds: readonly string[]`，始终存在。
- Assets：`AssetReferenceService.inspect(ids, transaction)` 与 `hold(ids, transaction)`，返回仅含 assetId/uploaderId/withinUploadWindow 的记录；hold 按 id 共享锁，使用数组参数。
- DocumentsRepository：在已有 accessible 范围内批量选每个 asset 的一个当前来源；沿用 S4 的单图读取。内部关系子查询由 document-assets.repository 提供，不从 Documents 跨查 assets 表。
- DocumentAssetsRepository：当前 ID 集合、候选关联、目标集合替换与普通复制。替换基于完整授权集合，ID 用数组参数，关系插入顺序确定。
- SpacesService/Repository：批量按 id holdSpaces；DocumentsRepository：按 id 批量锁/持有既有来源与目标，不先共享再升级。
- DocumentAssetReferences：`prepare(userId, ids, transaction, preservedTarget?)` 返回带事务身份的固定集合；`hold(prepared, { mode, documents?, spaceIds? }, transaction)` 按空间/文档顺序加锁，返回不可由普通数组替代的 `HeldAssetReferences`。`authorize(held, transaction)` 锁下复核并最后持 asset 行，返回排序的合法 ID；`replace(documentId, ids, transaction)` 只在真正写正文时调用。普通复制 `copy(source: HeldDocumentRow, targetId, transaction)` 沿用调用方已经通过的空间/文档锁和权限，只复制当前集合。预选或持锁证明跨事务复用会被拒绝。

## Review Focus

1. 提取的是解析后的值，不能让资源 data 原始转义或键名生成引用；不能截断外部/带参数地址。
2. 当前引用与真正存下的正文一致；unchanged 与两个重放分支均不改关系。
3. 两个互相引用目标的保存是否按同一顺序取足所有空间/文档锁，不做锁升级或锁后补来源。
4. 每个来源都核对当前状态、位置、关系与有效权限；上传者窗口独立于物理对象去重。
5. 普通复制只承接当前关系，gzip 不变；本机副本只承接上传内容实际出现的合法 ID。
