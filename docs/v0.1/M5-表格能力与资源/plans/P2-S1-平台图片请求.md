# P2-S1 平台图片请求：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供有界、携带原会话且不把占位当原图的图片上传/读取客户端，供后续 SDK 适配使用。

**Architecture:** 图片模块复用现有 `apiFetch`，不持有 SDK、页面或全局解码缓存。输入/状态/字节处理集中在 `shared/assets`；请求层仅增加两个受限的 fetch 选项。

**Tech Stack:** TypeScript、现有 Fetch/ReadableStream、Vitest unit-web、既有 contracts；无新依赖。

**Spec:** `docs/v0.1/M5-表格能力与资源/02-P2-图片入口与可靠渲染.md` §3.1–3.2。

## Global Constraints

- 唯一 Phase 分支 `codex/m5-p2-images`；主目录保持 main，中文提交且正常 hooks。
- `ASSET_MAX_BYTES = 5 * 1024 * 1024`，PNG/JPEG/WebP/GIF；只交后缀，不交原文件名。
- 默认 30,000 ms 覆盖 HTTP 与响应正文；请求取消和来源会话仍由 `apiFetch` 负责。
- 不读取任意 URL、不跟重定向、不把占位 PNG 返回给下载者，不自动重试上传。
- S1 不开放 SDK 图片命令或 UI，不改变 P2 原生补证条件。

## Review Focus

- HTTP 200 实为占位：明确失败并保留 404/500/503 与 Retry-After，不能返回占位字节。
- 响应头谎报或不报长度：仍按流的实际累计字节拒绝超 5 MiB，取消剩余正文。
- 读取期间断流、取消或超时：不会报告成功、后台迟到结果不改变已结束结果。
- 旧请求遇到会话更换：仍采用发出时的来源，不把旧 401 归给新会话。
- 未知响应类型、大小写/查询/外部地址、扩展名/MIME 不匹配：不发非法上传/读取，不在错误中回显输入内容。

**Interfaces:**
- Consumes: `apiFetch<T>(path, RawRequestOptions, read)`、`readJson`、`retryAfterOf`、`AssetUploadResponse` 与既有图片常量/契约。
- Produces: `AssetUploadInput { readonly data: Uint8Array<ArrayBuffer>; readonly mimeType: AssetMimeType; readonly extension: AssetExtension }`。
- Produces: `AssetRequestOptions { readonly signal?: AbortSignal; readonly session?: SessionResponse }`；不给 session 时保留 apiFetch 的当前已关联来源。
- Produces: `uploadAsset(input: AssetUploadInput, options?: AssetRequestOptions): Promise<AssetUploadResponse>`。
- Produces: `AssetBytes { readonly data: Uint8Array<ArrayBuffer>; readonly mimeType: AssetMimeType }` 与 `readAsset(source: string, options?: AssetRequestOptions): Promise<AssetBytes>`，这里只接受规范相对地址。
- Produces: `AssetInputError` 的只读 `reason: 'address' | 'size' | 'type'`；`AssetReadError` 的只读 `status: 404 | 500 | 503`、`retryAfterSeconds: number | undefined`。其余认证/网络/格式错误沿用现有类型。
- Adds: `RawRequestOptions.cache?: 'no-store'`、`redirect?: 'error'`，只在调用方明确传入时改变 fetch 默认行为，不扩展 JSON 接口选项。
