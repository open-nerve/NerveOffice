# M5-P1-S6 部署与阶段验收实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 正式镜像具备私有持久图片存储和完整原生依赖交付材料；核对平台资源预算与公开流程，完成独立审查、Phase 门禁及交接。

**Architecture:** 沿用 S1–S5 的模块和服务，不新增图片 UI。构建工具按已审查清单校验并收集源码，原件随镜像放入非 Web 的 licenses 目录；Compose 只给应用挂载私有资源卷。部署验证沿用现有容器 E2E 编排与重启项目，独立审查覆盖整个 P1。

**Tech Stack:** 现有 Node/TypeScript、Vitest、Docker/Compose、Playwright、GitHub Actions；Sharp 0.35.5 与 libvips 8.18.7/原生包 1.3.4 保持。

**Basis:** 已批准 M5 总设计、P1 设计、ADR-021、S3/S4/S5 复核。基线 `01970cd6`，S1–S5 已完成相应范围，P1 尚未合并。

## Global Constraints

- 沿用 `codex/m5-p1-assets`，主目录始终 main，不拆新分支；中文提交、正常 hooks，最终 `--no-ff`。
- 本机数据库只用 127.0.0.1:53522；容器测试使用现有编排自己创建、自动回收的独立库及随机 loopback 端口，不触碰开发库或用户数据。
- 完整测试、压力与浏览器串行；可能覆盖输出前归档原件。失败、跳过、重试、平台和运行 SHA 如实记录。
- 只按 DEF-073/UR-035 已批准边界处理已证实的 M4 WebKit 导航依赖问题，不豁免新增失败。M4 完整验收/tag 保持挂账。
- P2 Finder/Excel/授权 Chrome 右键粘贴与 SDK 主动复核/旧图清理条件保持；不将协议验证当成正式图片入口验收。
- 许可材料不齐或无法核对时构建失败；不得用裸 URL、静默缺件或变更摘要来继续。源码和构建脚本只作为交付材料，不在应用运行或依赖安装时执行。

## 接口与交付

- `tools/src/deploy/native-image-materials.ts`：校验来源/声明清单、仓库补件及精确版本；对每份材料按原始字节核对大小与 SHA-256。材料路径必须为安全相对路径，重复/冲突/无来源/未解决声明均失败。
- `native-image-bundle.ts` / CLI：有界下载或读取显式缓存，核对后收集到全新的输出目录；缓存同样逐件验证，不盲目信任存在的文件。输出包括完整 sources、清单、声明索引、许可正文、构建/替换说明和分发回执。提供离线复核入口，验证输出中的实际文件；不修改已审查清单或覆盖既有成品。
- 现有 `licenses` 门禁增加原生材料与版本一致性检查，镜像构建实际收集并验证全部源码后才能复制到 runtime。runtime 的 `/app/licenses/native-images` 不在 Web 根内。
- Docker 镜像为 node 用户准备 0700 的 `/var/lib/nerve-office/assets`，核对 Linux prlimit 可用；Compose 以命名卷持久化，应用配置固定指向该私有根。数据库、迁移和 Caddy 不挂图片卷；应用根文件系统继续只读。
- 部署复核在真实镜像中检查卷、权限、根分离、源码回执/版本和重启后的真实图片读取。压力/平台测量使用正式处理链，不复用诊断实现作为产品代码；产出架构、耗时、失败和资源事实。
- 本机 ARM64 通过不能写成原生 x64 通过；原生 x64 由现有 Linux amd64 容器 CI job 执行同一检查并保存回执。Phase 最终验收等同一合并 SHA 的 CI 完成，仿真结果单列。

## Review Focus

1. 来源清单和实际二进制版本是否一致；是否完整携带源码、补丁、构建说明和全部许可正文；下载/缓存损坏必须失败。
2. 静态 Web 与私有图片卷是否真正隔离；非 root、只读根目录与容器重建时持久化是否成立。
3. 部署检查是否调用正式生产处理/公开 HTTP，而非只验证探针；失败与平台事实是否真实归档。
4. 整个 P1 的上传配额、文件/数据库一致性、只读权限快照、保存引用和并发锁顺序是否有遗漏。
5. 全量/容器/CI 与独立审查是否完整，不借 M4 例外掩盖新失败或降低 P2 条件。
