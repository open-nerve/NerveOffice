# M6-P1 S6、S7：共用编辑会话层（第 1、2 批）

> 日期：2026-11-18｜对应 [P1 设计](../01-P1-文字文档底座.md) §3.1、§3.5 与 S6、S7｜状态：S6 已定，实施中；S7 一节在 S7 开始之前补上

S6 把表格编辑器（`W/features/sheet-editor`）里与表格无关、也不引用留下的模块的部分，原样搬进共用编辑会话层 `W/features/document-editor`，同步改按路径写的规则，加上依赖方向的规则。不改任何行为。

## 1. 搬迁的范围

**判定**：一个模块能在这一批搬，要满足两条：

- 只引用这一批要搬的模块，以及 shared、contracts、`editor/testing/` 里零依赖的诊断格式；
- 不碰公式、CSV、工作表这类表格的概念。

脚本按每个文件的相对引用（含 `import type`、动态 `import()` 与 `vi.mock`）核对过：搬的文件不引用留下的文件，集合是闭合的。

**搬的（70 个文件：生产 39、测试 27、测试辅助 4）**：

| 职责 | 模块（各带自己的测试与测试辅助） |
|---|---|
| 编辑权、交接与请求编辑 | edit-lease、editor-api、reading-checks、idle-watch、takeover-location、holder-requests、handover-trace、same-browser、pending-save-marker、issued-request、edit-request、self-takeover |
| 本机锁 | local-lock |
| 草稿与发件箱 | outbox/outbox-session、outbox/persistent-working-draft、editing-draft |
| 恢复 | recovery/reload-marker、recovery/recovery-notice |
| 页面小件 | page-guards、interaction-barrier、image-access |
| 测试构建的探针 | outbox/testing/ 下 18 个文件、recovery/testing/ 下 2 个文件 |

另有 5 个测试文件随被测的模块一起搬：
- `editor-api-deadline.test.ts`、`recovery/replay-content.test.ts`：测 editor-api；
- `working-draft.contract.test.ts`、`outbox/persistent-draft-lifecycle.test.ts`、`outbox/restored-working-draft.test.ts`：测持久的工作草稿。

**留在 sheet-editor 的**：

- **S7**：保存层带着公式钩子（`settleFormulas`、`formulasPending`）。包括 capture-policy、snapshot-capture、lost-copy-flow、save-coordinator、autosave、saving-editor、editing-session、tab-handover、save-indicator、local-save-indicator、editor-slot。
- **S8**：
  - 编辑模式与页面：edit-mode、editor-page、editor-chrome、start、selftest-hook；
  - 引用它们或引用编辑器适配层的：editor-query-client、share-entry、open-check-report、image-input-notice、snapshot-problem。
- **表格专有，不搬**：CSV、公式恢复与回退等。
- **`lease-server.test-support.ts` 留下**：只给 edit-mode 与 editing-session 的测试用，S8 随它们再定。
- **`save-working-draft.test.ts` 留下**：它测的是 save-coordinator 与工作草稿的配合，S7 随 save-coordinator 再定。

**原样搬迁**：
- 用 `git mv` 保留历史。
- 目录深度不变，所以搬的文件之间、以及它们对 shared 与 `editor/testing/` 的相对引用一字不改。文件内容只改注释里写的路径。
- 名字与协议逐字节不变：
  - Web Lock 的 `nerve-doc:<id>`、BroadcastChannel 的 `nerve-office:doc:<id>` 与 `nerve-office:edit-request:` 前缀；
  - localStorage 与 sessionStorage 的键；

  - 发件箱的附加认证数据。
- 探针 Worker 里副作用导入的先后（先包住事务，再引入生产的 Worker 入口）不动。搬迁不对这些文件跑自动修正。

## 2. 公开入口与测试入口

**公开入口 `document-editor/index.ts`**：只放 sheet-editor 的生产代码用到的名字，逐个列出，不用 `export *`。

请求层 editor-api 整体以命名空间 `editorApi` 转出，原因是同名：
- editor-api 的 `acquireEditLease` 是申请编辑权的请求；
- edit-lease 的 `acquireEditLease` 是带重试的申请流程。

两者原来各在自己的文件里，并到一个入口就同名了。命名空间让组装处读作 `editorApi.acquireEditLease`，两个模块都不改名。editor-api 里别处也用到的类型（`LoadedContent`、`FetchedEditStatus`、`LeaseCredentials`）与 `CONTENT_UNCHANGED` 另外直接转出，引用它们的文件只改路径。

**测试入口 `document-editor/index.test-support.ts`**：sheet-editor 的测试经它取两类东西：
- 假件：`fakeBrowser`、`memoryIssuedRequest`、持久工作草稿的测试辅助；
- 只有测试用到的内部常量与函数：重试与轮询的间隔、锁与频道的名字、`onReply`、`keyOf`、`createPersistentWorkingDraft` 等。

这样公开入口不为测试加名字。写法照 api 的 `app/integration.test-support.ts`（只给集成测试的入口）。

**sheet-editor 一侧只改引用路径**：
- 生产代码改经 `../document-editor/index.ts`；
- 测试改经公开入口或测试入口；
- `start.test.tsx` 原来 `vi.mock('./page-guards.ts')`，改为对公开入口 `vi.mock(import('../document-editor/index.ts'), …)`，其余名字取原实现。不能写成 mock 内部文件：路径字符串不经模块边界检查，等于绕过了它。

## 3. 依赖方向与按路径写的规则

**依赖方向**（设计 §3.1）：sheet-editor → document-editor。document-editor 只由编辑器页引用：编辑器页的入口与 sheet-editor。P2 的 doc-editor 到时加进来。它带着本机发件箱与编辑权的协议，不进平台页面的包。

**eslint 的模块边界（boundaries）**：

| 规则 | S6 之后 |
|---|---|
| 功能之间只经公开入口（现有） | 不改。sheet-editor 的生产代码经 `document-editor/index.ts`，由这一条放行 |
| 新增放行：sheet-editor 的测试代码 → document-editor 的测试入口 | `fileInternalPath: WEB_TEST_CODE` → `index.test-support.ts`。只开这一个文件 |
| 新增放行：sheet-editor 的 `start.tsx`、`selftest-hook.ts` → document-editor 的 `**/testing/**` | 限动态 `import()`（`nodeKind: 'dynamic-import'`）。原来它们动态引入的是自己目录里的探针 |
| 现有放行：`recovery/testing/reload-diagnostics.ts` → `editor/testing/selftest-reload-diagnostics.ts` | 来源改为 document-editor |
| 新增禁止：应用层、编辑器页以外的入口、sheet-editor 以外的功能 → document-editor | 放在允许的策略之后覆盖；有自己的说明 |
| 新增禁止：document-editor → sheet-editor | 现有的“编辑器页只由编辑器页的入口引用”已经拦着。另加一条放在它后面，说明依赖方向（后者覆盖前者，报出的是这一条的说明） |
| document-editor → 编辑器适配层（`W/editor`） | 不放行，保持默认的禁止。这一批的模块用不到它。S7 搬保存层时，再按“只开类型、不开表格专有的”定口子 |

**其余按路径写的规则**：

| 位置 | 现在 | S6 之后 |
|---|---|---|
| eslint：编辑器页的功能 | 散写 `features/sheet-editor` | 新增常量 `EDITOR_PAGE_FEATURES = '{sheet-editor,document-editor}'`，下面几条都用它 |
| eslint：测试构建的探针只能动态引入 | 块名 `nerve/sheet-editor-probe-dynamic-only`；只管 sheet-editor | 改名 `nerve/editor-page-probe-dynamic-only`。管两个功能，忽略两个功能里的 `**/testing/**` 与 `selftest-hook.ts`。说明里的路径相应改写 |
| eslint：平台页面对发件箱的静态与动态限制 | 忽略 sheet-editor | 忽略两个功能 |
| eslint：`OUTBOX_DIRS` 的 feature、testing | sheet-editor/outbox(/testing) | document-editor/outbox(/testing)。相对 shared 的前缀深度不变 |
| eslint：探针不引用 zod 与请求层（`nerve/web-outbox-probes`） | sheet-editor 的 `**/testing/**` | 两个功能的 `**/testing/**` |
| eslint：按需加载的文案 `editor.ts` | 只由 sheet-editor 引用 | 两个功能都可以引用（recovery-notice 用它） |
| 门禁 artifacts：`TEST_ONLY_SOURCES` | sheet-editor 的 outbox/testing/、recovery/testing/ | document-editor 的这两个目录；`selftest-hook.ts` 不动 |
| vitest：覆盖率不计的探针目录 | sheet-editor/outbox/testing | document-editor/outbox/testing |

**不改的**：
- 确认的弹窗、弹窗文件、同事选择的豁免名单。document-editor 用不到它们；S8 搬页头时再看。
- 分享对话框与本机清理提示的放行。`share-entry.tsx`、`start.tsx` 不搬。

**注释里写的路径**同步改：`editor/testing/` 的 handover-log、selftest-outbox、outbox-review-api，shared/outbox 的 draft-writer、draft-record，`shared/i18n/zh-cn/editor.ts` 的开头，`tests/e2e/support` 的 outbox-probe、crash-probe，`tools/src/gates/policy.ts`。

**防止漏改**：按路径写的规则，指向不存在的路径时不报错，只是悄悄失效（设计 §7 的风险）。两处补上核对：

- **门禁 artifacts**：新增单元测试，`TEST_ONLY_SOURCES` 的每一项都要在 web 应用目录里存在（文件或目录）。
- **lint 自测**：在搬迁后的真实路径上检查。类型感知的检查只接受存在的文件，路径写错就解析失败。另核对 `OUTBOX_DIRS` 的两个目录都存在。
