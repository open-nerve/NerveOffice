# ADR-022：图片实例与 SDK 修复

> 状态：已接受并完成 S2 实现、三浏览器及冷安装验证；完整 Phase 验收仍在 S6｜日期：2026-10-19｜来源：M5-P2-S2｜上层：[P2 设计](../v0.1/M5-表格能力与资源/02-P2-图片入口与可靠渲染.md)、[S2 规格](../v0.1/M5-表格能力与资源/specs/P2-S2-图片实例与可靠渲染.md)

## 背景

固定的 Univer 1.0.1 中，仅替换图片下载器不足以约束完整图片路径：单元格富文本有独立的元素缓存，浮图更新及文件插入量尺寸会直接使用模型 source，读取失败还可能回退原 URL。撤销对象 URL 也不会自动擦掉所有已经解码的元素或图库预览。

SDK 已知的坏图绘制、自动行高锚点和 Ready 前销毁问题，分别影响后续绘制、重开后的图片尺寸及实例退出。它们按既定 P2 范围修复，保留原 SDK 版本及 `sheet@1`。

## 决策

每个编辑器实例拥有独立图片资源表。平台 API 读取必须携带页面提供的原会话对象，验证真实状态、完整有界字节并解码成功后才交出临时 URL。读取、解码、上传均属于该实例和身份代次；取消及时结束等待，迟到资源释放。模型和撤销数据仍只保存规范资源地址。

在 drawing 插件配置中完整替换 `IImageIoService`、`IURLImageService`。缓存、刷新、下载、文件校验、进度和 ID 生成由完整实现负责，不继承默认 URL 回退。页面只传 SDK 无关的 `EditorImageAccess` 和错误通知。实例绑定初始用户，不在旧实例内接纳另一用户。

已交给 SDK 的图片元素登记到资源表；身份/权限复核和退役先同步清旧图，再按许可重新读取。图库预览的独立元素通过本实例 `IGalleryService.close` 关闭并清空列表。资源变化只标记当前场景重新绘制，不写业务命令或保存序号。退役顺序早于等待公式退出。

发布包内的绕行点用 pnpm `patchedDependencies` 固定，不修改只读 `refer/univer`，不全局替换 Image/canvas，也不升级依赖。补丁工作目录由 `pnpm patch` 建立，应用由 `pnpm patch-commit` 和锁文件管理。

锚点刷新仅重算两份锚点的 from/to 坐标，保留原有旋转、翻转等属性及其缺省状态。最初直接使用转换函数的完整结果，会在撤销后补回已移除的默认属性，使 JSON1 重做插入同名属性时失败；实际显式行高命令及撤销/重做反例已证实并修正，禁止把这类冲突当作夹具问题或吞掉。

当前修改 ES 发布入口及对应声明；package exports 的 import、浏览器配置和 Worker 配置指向 ES。最终测试构建的 386 项、生产构建的 378 项 SDK 模块全部来自 ES；公式 Worker 的 11 项 SDK 模块与 P1 冻结产物一致，已有的数据几何依赖 engine-render 保持，平台图片 IO/主线程出口没有进入 Worker。最终工作区及无 node_modules 副本的两种构建均已核对；CJS 未修改或宣称通过。若任何运行入口使用 CJS，必须同步修复并回归，不能只靠配置推断。

八份补丁与当前原件/补丁/安装后 ES 摘要列在 `patches/univer-images.json`；修改文件保留原许可并添加 NerveOffice 修改声明。原始发布文件、ES/CJS 与 package.json 的 SHA-256、pnpm 应用日志和每次 RED/GREEN 原件保存在本任务 `.codex/handoffs/m5-p2-20261019/s2/`。最终摘要、构建清单、三浏览器 54 项及持续 401 重试 9 项、原版三项浏览器反例、冷安装复现已齐全，见 [S2 复核](../v0.1/M5-表格能力与资源/reviews/P2-S2-图片实例复核.md)与 `verification.json`。最终副本以冻结锁文件和已核对的 pnpm store 离线安装，17 文件/203 项实际包回归通过；不声称网络缓存为空。

IMAGE 快照保留公式与空字符串结果，不保存运行时图片信息。SDK 原先把空字符串当有效缓存，重建时跳过 IMAGE 计算；engine-formula 修复只在缺运行时图片信息时，通过既有词法器识别真实 IMAGE 函数节点（含共享公式、嵌套、大小写及 `_xlfn`），不把字符串里的 IMAGE 当函数，不全表重算或改动快照格式。

IMAGE 首次失败后量到的是本地占位图。仅恢复像素会沿用占位几何；真实竖图反例中恢复为 76×52，重开为 52×76。控制器现在优先使用本代有效原件的自然尺寸；无有效原件时保存受管元素，只有后续有效解码才重测，覆盖首次取消、普通占位与登记时撤回。占位 load 不会触发请求循环；批次提交前仍核对最新请求及原公式未被编辑，销毁后不更新。另有“量尺寸刚结束、真实缓存恰好到达”的回归，避免错过这一恢复时机。

页面详情与阅读状态检查共用图片许可代次，发请求时记录。身份/许可变化后，较早请求的成功不能重新授权；实际拒绝仍会清图，不会被并发成功掩盖。三组 deferred 交错已先 RED 后 GREEN；既有正文保存和服务端权限协议保持。迟到 401 通知若已撤回图片身份，用户明确重试先经原会话复核，再查询权限；断网、换人或合并复核最终失败都不能清提示/重启图片。stopped 本身不发起复核，防止持续 401 自动循环。

真实浏览器还证实 `FOverGridImage.setSource` 会先修改持有的当前模型，让后续差异命令无法发现换源。平台后续正式操作必须通过 `sheet.command.set-sheet-image` 与独立 payload；本 Step 不修改该 Facade，也不把绕开此方法的验证声称为其修复。

## M5-P2 S3 的补充

### IMAGE 展开前来源证明

实际 1.0.1 解析器会在构造 AST 前展开定义名称，因此仅检查 ValueNode 无法区分原始字符串字面量与名称值。engine-formula 补丁在原词法树中证明首参为字符串及透明括号；定义名称的实际文本拼接同步传递每个原调用的准确输出位置，再将证明附到对应 FunctionNode。名称内部产生的 IMAGE 不继承证明，多个相同地址、前置文本、嵌套名称不能靠调用序号配对。

平台包装同时核对证明、第一参数的实际 ValueNode、引号解码及求值字符串一致，再调用原 IMAGE；无 AST 的直接调用拒绝。普通参数数量、altText、sizing、尺寸和错误继续由原执行器处理。安装时清理 IMAGE 缓存还检查实际 AST 的规范函数名，覆盖大小写和定义名称展开；无关 SUM 缓存保持，不全库清空。标记只在运行期节点内，不进入工作簿或改变 sheet@1。

补丁仍由 pnpm 管理并更新原清单/锁文件，S2 的七个其他补丁保持。实际解析器和缓存反例先 RED 后 GREEN，新增三浏览器两公式模式在未有任何合法图片读取前验证六种非法来源零 GET；随后合法字面量有真实像素，并验证重开一致性。完整 S3 复核、最终入口摘要及冷安装证据统一记录在 [S3 复核](../v0.1/M5-表格能力与资源/reviews/P2-S3-图片来源复核.md)。上游升级须满足相同来源、名称、缓存及浏览器回归才可移除该扩展。

S3 最终组合浏览器 81 项、相关单元 5,550 项、真实 PG 73 项和冷安装 359 项通过。两种构建的实际 ES/Worker 入口再次核对，S2 的 386/378 个 SDK 模块及 Worker 的 11 项模块边界保持；正式输入与三项原生前置仍交 S4，不因本次回归提前验收 P2。

### 运行期片段与持久化格式

图片命令先规范 source/base64Cache，再预演完整相关写入；不扫描普通单元格 v/f。片段中的普通数字须保持 SDK 运行期语义：固定 SDK 用 Infinity 表示富文本无限画布，误将所有片段视作严格 JSON 会取消正常文字粘贴后的 Enter 提交。真实文档工厂和实际命令已复现并修复，保留原布局值；source/cache 仍只能是合法平台地址，JSON1 操作自身继续执行严格纯 JSON/子类型校验。这不增加持久化格式或允许外链图片。

## 备选方案与取舍

只注册 URL 下载器会遗漏直连、独立缓存和图库；只撤销 blob URL 不能清除已解码像素。全局重写 Image/canvas 会影响其他组件并掩盖异常。重写编辑器图片系统或升级 SDK 超出本 Phase 的必要范围。

选择实例资源所有权加固定发布包的局部修复，代价是 SDK 升级时必须逐项复核补丁。移除条件是上游对应版本已满足同一组行为回归、实际入口和全部支持浏览器通过，随后删除对应补丁并更新锁文件；不能仅凭相似提交或源代码改动判断可移除。

## 影响与尚未完成的条件

内部标识、渲染和图库操作从 `internal-api` 集中出口；UI 标识只从 `ui.ts` 导出，既有 drawing 的图元键辅助函数从 `index.ts` 导出；登记表递归检查所有依赖，公式 Worker 禁止引入界面包。web 直接声明已经锁定的 RxJS 7.8.2，仅用于完整进度契约，没有新增版本。

S2 的页面许可接线与可见失败状态已实现。Chromium、Chrome、WebKit 的 18 个故事各自通过，涵盖真实请求/像素/保存/撤销、自动行高、退出换人、撤权恢复与旧实例清理；最终冷安装及实际 ES 入口证明也已通过。正式图片入口保持关闭。Finder 拖放、Excel 来源、Chrome 获准右键粘贴仍是 P2 开放入口、验收及合并前必须完成的原生证据，DEF-004 未关闭。M4 DEF-073 及完整验收继续独立挂账。
