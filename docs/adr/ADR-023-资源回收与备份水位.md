# ADR-023：资源回收与备份水位

> 状态：已接受，M5-P4-S5 已实现并通过 Step 验证；本轮 full16/container05 同源双门禁已独立接受，S6 最终来源/同 SHA CI/实际关闭仍须后续完成｜2026-10-29

## 背景与选择

图片上传由持久 reserve、事务外 publish、finalize 三段组成。按 hash 复用同一文件名时，旧回收任务可能删除新上传；只加代次虽然能隔离新文件，却无法阻止长时间暂停的旧发布重新生成已经清账的孤儿文件。

采用不可复用的代次路径、持久退休任务和永久零字节标记。新 claim 用随机 UUID；存活同图仍去重。旧文件的 generation 为空，继续用原 hash 路径，迁移不移动文件或伪造代次。上传三段携带同一 `{ sha256, generation, storageKey }` 回执，旧回执不能借新 claim 转正。

退休在私有卷中写 0600 空文件并 fsync，原子 rename 覆盖精确旧路径，再 fsync 所在目录。迟到 publish 的不覆盖式 hardlink 失败，随后完整性校验也不能把空标记当成图片。完成回执和空标记永久保留；回收图片正文占用，不承诺清空每个 inode 或元数据行。

## 引用与时间

保留判断使用当前文档与全部仍存在的检查点关系，包括归档、回收站、其他空间、删除前和升级前检查点；无读取权限不等于可回收，过期但尚未清除的关系也保守保留。上传者的严格 24 小时窗口仍受保护。

assetId 与物理对象分别从首次观察到无引用时开始完整宽限。最后一个 assetId 删除后，对象另起宽限；失败 claim 同样从首次观察开始。reserve 清除对象或 claim 的候选，finalize 也处理这期间重新出现的对象候选。代价是最后一条资源记录删除后，文件最多再保留一轮完整宽限。

数据库在当前/历史关系 INSERT 或实际更换 assetId 时，按资源和事务号追加引用活动。同一事务重复写入去重，原值 UPDATE 不算活动；不把既有共享资源锁升级为逐资源排他更新，避免多文档捕获形成反向等待。GC 按 quota → 有序资源行锁取一页，在锁下读取 Documents 的有限保留集合并消费活动；两次扫描间出现又消失的引用也会重新开始宽限。

候选时刻在引用与活动查询之后取数据库实时钟，不能用旧调度时刻或事务开始时刻倒推。引用查询不反向获取空间/文档业务锁；并发新增引用由资源锁与 FK 保证互斥。旧 RR 快照、反向多文档捕获与两个先后均须真实库验证。

## 文件与数据库接续

对象/claim 满足条件后，原事务写入身份不可变的 `asset_object_deletions`，再删除原对象/claim，费用保持。已确认提交的任务才交给事务外文件 IO；IO 前重查当前备份政策、代次与没有存活同路径的事实。

文件同步完成后，另开 quota → task 短事务；首次 pending → completed 才释放字节并记录审计。身份及完成时间不能改写，未知提交先重读，失败不盲目补偿。配额不变量为：完整对象 + 持久预留 + 未完成退休任务；记录配额等于 assets 条数。

Jobs 组合 Assets 与 Documents，GC/保留服务不开放给 HTTP 或其他业务入口。整轮会话 advisory lock 防跨实例重复调度，按固定上界和有界页推进；失败停止本轮，下轮从持久状态继续。SIGTERM 完成手上文件及确认后停止，SIGKILL 留下的短事务和私有临时文件由重启接续。资源 GC 单独启用需要至少 2 个池连接，与回收站自动清理同时启用需要至少 3 个；配置在启动时拒绝不足的值。

## 备份与部署边界

GC 默认开启候选整理；备份保留期和恢复水位无默认值。宽限不得短于保留期。删除还要求候选经过完整宽限且严格早于恢复水位；水位相等仍保留。缺声明、未来水位或水位晚于“数据库当前时间减保留期”，均只整理候选，不删除资源记录、不排新任务，也不执行已有待办文件 IO。

水位由运维核实全部保留备份和 WAL 的恢复范围后统一声明。日期格式检查不能证明外部备份，不能用“现在”代替证据，M7 自动备份与恢复演练仍未完成。变更备份策略前暂停所有实例的 GC，核实后统一更新配置并重启；恢复数据库前停止所有旧应用，数据库与资源卷必须配套恢复。

首次上线代次路径前，停止全部旧实例，再迁移、启用新程序。旧二进制不能读取新路径，这次变更不支持新旧实例混跑。所有回收验证只用隔离测试库/私有卷；不得对真实用户目录试运行删除或手工移除回执、标记。
