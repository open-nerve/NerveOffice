# ADR-025：客户端 CSV 与保存边界

日期：2026-11-01。状态：M5 已批准范围内的 P5 实现决定；S1–S5 已验证，阶段完整验收按 S6 记录。

## 背景与决定

CSV 是客户端交换格式，不能绕过编辑权限、租约、本机发件箱及服务端快照校验。P5 只提供 UTF-8 CSV，不增加 Office 转换服务、自动编码探测或新的保存协议。

`shared/csv/` 负责有界 UTF-8 解析和 BOM/CRLF 编码，不依赖 SDK。输入输出各最多 5 MiB，矩形最多 50,000 行、1,024 列、100,000 格，字段最多 32,767 UTF-16 单位；最终工作簿仍受原 5 MiB 与 JSON 复杂度限制。错误只携带固定原因。前导零、日期、长编号和公式样式字段保持文本；只把无损的普通十进制转换为数字。

`editor/csv/` 是唯一 SDK 适配。导入先用当前完整快照构建候选并检查，再执行一条整表插入命令，保留一次撤销/重做；不通过粘贴自动识别公式。命令与数组缓存两个内部接点集中登记于 [ADR-010](ADR-010-编辑器适配层与内部API登记.md)，没有新增 SDK 补丁或 pro 依赖。

导出先结束当前单元格输入、等待面板和公式稳定，读取选定可见表的实际显示矩形，含数组公式的真实溢出结果。只格式格不扩大范围，图片/链接目标/公式源码不导出；危险文本加保护前缀，真实数字保留数字语义。下载不修改工作簿和服务端正文；只读及离线可导出已加载的有效内容，无法证明公式已收齐时明确拒绝。

`features/sheet-editor/` 管理文件读取、预览、取消、会话/租约/在线状态和实例身份。跨过异步边界后核对原实例，不能重新取得另一实例接着写；导入仅在在线且有效可写的编辑会话开放，成功修改沿原保存管道持久化，UI 不把“已插入”冒称“已保存”。

新建入口使用编辑器 HTML 的独立路由，在同一 Document 的内存中保留预览。确认后通过原幂等创建 API 建空文档，再挂载正式编辑器并调用同一个导入控制器；正文不进 URL、localStorage 或临时明文库。创建结果未知时保留原 requestId 核对，不重复新建；重放结果和失去授权不能被当作本轮新空文档自动覆盖。创建后加载失败保留文档链接，可重试打开。

## 代价、验证与边界

CSV 不保留格式、图片、超链接目标或工作簿多表关系；严守 UTF-8 和明确预算会拒绝其他编码及超限文件。平台列表只持有新建链接，SDK 与 CSV 实现留在编辑器分块，原平台首屏预算不变。

S1–S4 的单元/真实 SDK 回归与 S5 三浏览器、生产容器故事覆盖格式边界、撤销、保存重开、权限变化、未知创建及 Worker/主线程实际计算。S5 报告凭据 I-01 已按用户批准局部修复，并受限隔离历史原件；具体证据与阶段关闭条件见 [P5 交接单](../v0.1/M5-表格能力与资源/handoffs/P5-交接单.md)。原生 Excel 等环境欠账仍按原登记，不以 CSV 工程验证关闭它们。
