# UR-040 延后全选表名覆盖已开始的原生输入

状态：本地修正，发布包边界反例、S5 最终工程和真实三浏览器通过；P3 阶段独立审查与完整验证待完成。未发送上游。固定 `@univerjs/sheets-ui@1.0.1`，发现于 M5-P3-S5。

## 反例与根因

真实公式故事在依赖修改、插行及历史之后双击表名“数据”，原速输入“源数据”。final01 中 Chrome 保留旧名；追加实际焦点就绪检查后 final02 的 Chromium 两轮仍失败。原始 trace 的 DOM 快照表明回车前改名文字已经不正确，不是云端保存或公式引用失败。

输入后单次观察的 diagnostic06 复现三轮只剩“据”，另有完整输入后选区仍全选新名字的对照。此前逐事件监听的 diagnostic01–04 改变时序，均不计验收；独立原生小页面 80 轮正常，不能把本问题归为浏览器环境。diagnostic05 的观察定位器仍按旧名称寻找已改名标签，已停止并保留其诊断错误，不能归因产品。

`keepTextSelected` 在定时任务里无条件全选当前文字。原生双击已可能先把焦点放入表名，用户输入开始不等待这个任务；迟到全选若落在“源”和“数据”之间，后两个字覆盖首字，表现为旧名称没变；落在“源数”和“据”之间则只剩“据”。改名关闭或控件退役也不会取消旧任务。发布包 ES/CJS 的确定定时任务测试验证上述边界，旧逻辑 20 项失败、正常初始全选两项通过。

## 局部修正与边界

保留初始异步全选；调度时记录正文和所属 document，并临时监听键盘、beforeinput/input、组字开始、指针和失焦。任务运行时先释放监听，若发生过后续交互、正文改变、控件退役/脱离页面/换 document，则不再改变任何选区。正常未交互的改名仍全选。使用所属 document 的 Selection/Range，不触碰逻辑工作簿或其他输入框。

没有新增公开 API、持久化字段、宿主输入通道或权限例外。固定补丁两种格式对称，摘要在 `patches/univer-sheet-name-selection.json`。测试读取发布包唯一函数原文执行，不复制修复逻辑；真实 UI 覆盖正式入口及后续正文和历史事实。

22 项发布包边界加 UR-039 的 7 项实际 SDK 回归已通过；三项变异分别产生 10/2/2 项有效断言失败，恢复后 29 项通过。无诊断原速公式整链与既有工作表结构链三浏览器各三轮共 18 项通过；S5 final03 的 11,059 项单元、工程与 270 项浏览器组合全部通过。原 S5 独立审查早于本修正，本项仍须纳入 S6 阶段独立审查。上游提供等价的任务归属与输入保持后，须通过同一组反例、原始浏览器链及阶段门禁，再移除补丁。
